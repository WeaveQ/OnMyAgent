Questions, answered常见问题 这里有答案

What is OnMyAgent in one sentence?一句话：OnMyAgent 是什么？+
A local-first office AI workbench and control surface on your desktop - sessions, files, skills, automation, and approvals - with optional company control and IM digital employees.本地优先的办公 Agent 工作台：本机会话、文件、技能、自动化与审批；可选连接组织管控与飞书/钉钉数字员工。
Do I need to log in or connect a company?必须登录或连接公司吗？+
No. Personal / Mode A works fully offline from org services. Connecting OnMyCompany is optional depth for policy, catalog, and audit - not a login wall.不必须。未登录 / 未连公司时本机工作台完整可用。连接 OnMyCompany 是策略与配置加深，不是登录墙。
OnMyAgent vs OnMyCompany vs OnMyBuddy?和 OnMyCompany / OnMyBuddy 什么关系？+
OnMyAgent is the desktop workbench. OnMyCompany is the intranet control plane (identity, policy, gateway, audit). OnMyBuddy is the IM digital employee (Feishu/DingTalk). OpenConnector is gateway tech inside OnMyCompany, not a separate product line.OnMyAgent 是桌面工作台；OnMyCompany 是内网管控（身份、策略、Gateway、审计）；OnMyBuddy 是 IM 数字员工。OpenConnector 是 OMC 内 Gateway 实现，不单独对外讲第三条产品线。
Is it based on OpenCode?是基于 OpenCode 的吗？+
Yes as a local runtime foundation. OnMyAgent adds the desktop workbench for sessions, files, skills, automation, and approvals around that runtime.是的，OpenCode 是本地运行时基础之一。OnMyAgent 在外层提供会话、文件、技能、自动化与审批的桌面工作台。
Is it free / open source?免费吗？开源吗？+
The desktop product is developed in the open. See the GitHub repository for license and release assets. Public multi-tenant SaaS is not the current primary delivery.桌面产品开源演进，许可证与安装包见 GitHub Releases。公网多租户 SaaS 不是当前主交付形态。
Can my team pilot it?团队能试点吗？+
Yes. Start with desktop-only (combo A). Add OnMyBuddy for IM reach or OnMyCompany for intranet control when ready. Do not treat full IM-to-desktop dispatch or full org egress enforcement as already shipped defaults.可以。建议先只上桌面（组合 A）；需要时再加 Buddy 或内网 OMC。勿把「IM 一句话改本机文件」或「全企业出口强制」当成已默认上线能力。
Relationship with WeaveQ?和 WeaveQ 什么关系？+
WeaveQ is the team / org publishing OnMyAgent. Enterprise control is OnMyCompany; industry packs may use WeaveQ as a delivery name - that is not the same as OnMyCompany.WeaveQ 是发布 OnMyAgent 的团队/组织名。企业管控是 OnMyCompany；行业 Pack/交付仍可用 WeaveQ 称呼，但不等于 OnMyCompany。
