# 第一个任务

完成一次「**一句话 → 本机可见结果**」的闭环：创建任务 → 对话执行 → 文件验收。

## 准备

- 已 [安装并启动](./quickstart)  
- 已配置可用模型  
- 工作区可写  

## 步骤

### 1. 新建任务

在首页点击 **+ 新建任务**，或直接在当前会话输入。

![新建任务与会话列表](/images/home-session.png)

### 2. 写清需求

好的提示通常包含：**目标、输入材料、输出格式、落盘位置**。

**示例 A · 纯文本产物**

```text
请在当前工作区创建 notes/hello-onmyagent.md：
1）用三句话介绍本地办公 Agent 工作台；
2）列出我接下来可以尝试的两个办公场景。
```

**示例 B · 整理已有文件**

```text
查看工作区中的表格与文档列表，用条目形式总结目前有哪些类型的文件，
并建议优先处理的 3 件事（写入 notes/workspace-review.md）。
```

### 3. 执行中

- 可继续追问、补充约束  
- 需要高风险操作时按提示做 [审批](./guide/approvals)  
- 底部可切换模型与权限模式  

### 4. 验收结果

1. 阅读对话中的结论  
2. 打开 **文件**，确认 `notes/` 下文件是否生成  
3. 双击预览或「在应用中打开」外编  

![在文件区验收产物](/images/files.png)

## 常见问题

| 现象 | 处理 |
|------|------|
| 没有输出文件 | 提示词中明确「写入工作区路径」；检查权限模式 |
| 模型报错 | 检查 Key / 网络，见 [模型](./guide/models) |
| 找不到文件 | 确认工作区路径；在文件页刷新 |
