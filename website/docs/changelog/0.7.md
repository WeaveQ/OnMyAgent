# 0.7

0.7 把知识库做成可切本机文件夹、可用块编辑、能从会话存笔记的资料夹。桌面包版本已是 0.7.0，尚未打 tag。

完整资产以 [GitHub Releases](https://github.com/WeaveQ/OnMyAgent/releases) 为准。

## 0.7.0

### 多库与最近访问

知识库侧栏按 **我的资料 / 项目库 / 专家库** 分组，打开过的笔记会出现在 **最近访问**。

- 个人库可以 **新增文件夹**，只加入列表，不会删除磁盘上的文件；移除文件夹也一样
- 可以把个人库指到已有的 Obsidian 目录
- **项目库** 和 **专家库** 在没有对应范围时显示 **暂不可用**

### 块编辑器

写 `.md` 笔记时默认用块编辑。输入 `/` 就能插入标题、列表、待办、引用和代码块，不用先记 Markdown 语法。

- 笔记属性里可以改标题、标签和关联；你另外加的自定义字段保存时会留下
- 仍可切到 **纯源码**，需要手改标记时再用

### 新建、上传、网页书签

工具条的 **新建** 不再只是一篇 Markdown。

- 可新建笔记或表格，也可 **上传文件** / **上传文件夹**
- `.html` 用只读预览打开，页面经过消毒，不能当编辑器改
- **添加链接** 把网页存成 Markdown 笔记，网址写在属性里

### 会话存入知识库

对话告一段落时，点会话顶栏的 **存入知识库**，把当前会话写成一篇笔记。

- 可改文件名，并选择保存位置
- 仅桌面端；存好后会打开知识库里那篇笔记

### 修复

- 打包安装后，会话里的内置终端可以正常打开
- 桌面出错时直接显示原因，不再套一层看不懂的远程调用提示
- 首页的工作区和权限弹出层更紧凑；访问权限改成 **完全访问** 开关，需要审批时再关上
