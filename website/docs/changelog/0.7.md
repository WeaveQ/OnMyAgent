# 0.7

0.7 把知识库做成可切文件夹、可块编辑的本机资料夹，并在输入区加上提示词增强。桌面包版本已是 0.7.0，尚未打 tag。

完整资产以 [GitHub Releases](https://github.com/WeaveQ/OnMyAgent/releases) 为准。

## 0.7.0

### 知识库更好用

主栏知识库可以挂多个本机文件夹。打开过的笔记进 **最近访问**，`.md` 默认用块编辑（输入 `/` 插标题、列表、待办）。

- 侧栏按 **我的资料 / 项目库 / 专家库** 分组；后两组没有对应范围时显示 **暂不可用**
- **新建** 可建笔记或表格，也可上传文件、添加网页书签
- 会话顶栏 **存入知识库** 把当前对话写成笔记（仅桌面）

### 增强提示词

输入区新增闪星按钮 **增强提示词**。先写一点草稿再点，会改写得更清楚、更好执行；不满意可 **还原原文**。需要已选可用模型。创建专家时的嵌入输入栏没有这个按钮。

### 推荐问我可以关掉

设置 · 偏好 增加 **推荐问我**。关掉后，回复结束不再在对话里出现后续提问建议（首页和专家会话一起关）。

### 修复

- 打包后，会话里的内置终端可以打开
- 桌面出错时直接显示原因，不再套一层远程调用提示
- 首页的工作区和权限弹出层更紧凑；访问权限改成 **完全访问** 开关
