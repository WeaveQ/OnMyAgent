# 0.6

0.6 线聚焦桌面配置底座、双运行时边界、专家 / 会话冷启动稳定性，以及本地技能与模型供应商体验。

完整资产以 [GitHub Releases](https://github.com/WeaveQ/OnMyAgent/releases) 为准。

## 0.6.0

### 自己的专家可以带走

自定义与导入的专家归到「**市场-专家-我的专家**」页面，支持整包导出、导入和跨机器迁移。

- 导出为 zip：含人设、知识、头像和声明的技能，**不带会话和凭据**
- 导入 zip 或文件夹，冲突时可选择 **覆盖重置** 或 **保留并复制**，导入后自动召唤
- 「我的」卡片提供 **编辑 / 导出 / 删除 / 去对话**

### 模型供应商一键开关

设置 · AI 的供应商行新增 **电源开关**，只停用不删配置；开关成功直接热更新，不再提示重启。会话里的模型选择器底部按钮改为「**去设置**」，直达 `/settings/ai`。

### 忙碌时排队追问

会话正在跑时不用干等——继续在输入框写下一条，按 **Send** 就会排队，当前回答结束后自动依次发送。

- 队列条挂在输入框上方，最多 **20 条**；每条显示正文预览和附件数
- 每条支持 **拖拽排序**、**提前发送**（提到队首）、**编辑**（弹回输入框）和 **删除**
- 发送失败的条目会自动回到队首，不会丢
- 按 **Stop** 会暂停自动放行；下次成功发送后恢复
- 队列只保存在内存里，关闭 / 删除会话或重启应用会清空
