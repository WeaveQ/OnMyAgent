# 常见问题

### OnMyAgent 是什么？

本地优先的办公 Agent 工作台：派活、执行、交付文件，而不是只聊天。

### 必须登录或上云吗？

**不必。** 默认本机可用；连接公司是可选项。

### 和飞书 / 钉钉机器人是什么关系？

IM 数字员工属于 **OnMyBuddy**；本机工作台是 **OnMyAgent**。见 [平台三分](./platform/)。

### 支持哪些模型？

BYOK：兼容 API、本机模型等。见 [模型](./guide/models)。

### Windows 能用吗？

有开发者预览路径；主支持 macOS。见 [Windows](./install/windows)。

### 文件会不会被改坏？

默认在工作区内操作；导入为工作区副本。重要文件请自行版本备份。

### 如何下载？

见 [下载与安装](./download)。

### 专家和技能有什么区别？

**专家**偏角色与方法论；**技能**偏可执行能力包。都可在市场安装。
