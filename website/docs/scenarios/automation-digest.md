# 场景：定时汇总

把已验证过的「汇总 / 早报 / 周报」提示词交给 [自动化](../guide/automation)，按固定周期产出草稿。

## 目标

- 每个工作日或每周固定时间生成汇总文件  
- 输出路径稳定，方便在 [文件](../guide/files) 中查找  
- 失败可查运行历史，不依赖你当天是否打开应用（需本机在线且任务已启用）  

## 准备

1. 在普通 [会话](../guide/sessions) 里**手动跑通**同一提示词至少一次  
2. 确认产物路径合理（如 `notes/daily/`、`notes/weekly/`）  
3. 模型与工作区已可用（见 [快速开始](../quickstart)）  

## 步骤

1. 打开主栏 **自动**  
2. **从模板添加**（若有合适模板）或 **+ 添加** 新建  
3. 填写：  
   - **调度时间**（如每天 08:00、每周五 17:00）  
   - **提示词**（与手动跑通的版本保持一致）  
   - **输出位置**（写死路径，避免散落）  
4. 将任务设为 **已启用**  
5. 到点后查看运行次数 / 历史；在文件区打开产物并外编

## 推荐节奏示例

| 节奏 | 调度建议 | 输出示例 | 提示词要点 |
|------|----------|----------|------------|
| 工作日早报 | 每天 08:00 | `notes/daily/YYYY-MM-DD.md` | 今日待办、风险、需跟进的人 |
| 业务调度早报 | 每天 08:00 | `notes/ops/morning.md` | 固定栏目结构；缺数据时用占位并标注「示意」 |
| 周报草稿 | 每周五 16:30 | `notes/weekly/YYYY-Www.md` | 完成 / 进行中 / 阻塞 / 下周计划 |
| 材料巡检 | 每天 18:00 | `notes/audit/stale-files.md` | 列出工作区久未更新的关键文件 |

## 示例提示词（可直接贴进自动化）

**工作日早报**

```text
生成本日办公早报，写入 notes/daily/（文件名用当天日期）.md。
结构：
1）今日必须完成的 3 件事
2）待他人回复 / 阻塞
3）一眼风险
中文，短句条目；不要写寒暄。
若工作区 notes/ 下有昨日文件，可简要对照未关闭项。
```

**周五周报草稿**

```text
根据本周会话与 notes/ 下相关材料，生成周报草稿：
本周完成 / 进行中 / 阻塞 / 下周计划。
面向直属领导，800 字内。写入 notes/weekly/ 并以 ISO 周编号命名。
```

## 验收清单

- [ ] 手动会话已产出过同类文件  
- [ ] 自动化任务显示 **已启用**，调度时间正确  
- [ ] 到点后运行次数增加，或历史中有成功记录  
- [ ] 文件区能打开最新产物，内容可外编  

## 注意

- 本机睡眠过久、未开机时，定时任务可能错过；重要汇总可加「补跑」习惯  
- 高风险动作、外发类任务配合 [审批](../guide/approvals)  
- 需要群里催办时，再考虑 [试点组合 B（+ OnMyBuddy）](../platform/pilot-combos)
