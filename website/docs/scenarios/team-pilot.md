# 场景：团队试点

用 2–4 周验证 OnMyAgent 是否进入**真实办公路径**（而不只是装了没人用）。

## 目标

- 选定试点组合与成功标准  
- 全员跑通安装 → 模型 → 第一个产物  
- 每个岗位至少 1 个高频场景（专家或技能 + 固定输出路径）  
- （可选）再接 IM / 公司管控  

## 先选组合

见 [试点组合 A/B/C](../platform/pilot-combos)：

| 组合 | 包含 | 适合 |
|------|------|------|
| **A（推荐起步）** | 仅 OnMyAgent | 先证明本机交付 |
| **B** | OMA + OnMyBuddy | 群里催办 + 本机干活 |
| **C** | OMA + OMC（± OMB） | 要组织策略与审计时 |

**建议从 A 起步**，2–4 周有稳定产物后再加深 B/C。

## 建议节奏（四周）

| 周 | 动作 | 完成定义 |
|----|------|----------|
| **0 准备** | 定组合、定 3–5 名种子用户、写成功标准 | 书面标准：如「每人每周 ≥2 个落盘产物」 |
| **1 安装** | 全员 [快速开始](../quickstart)；统一工作区约定（个人目录或项目空间） | 每人完成 [第一个任务](../first-task) |
| **2 岗位场景** | 市场安装 1 个岗位 [专家](../guide/experts) 或 [技能](../guide/skills)；固定输出路径 | 每岗位 1 条可复用提示词 |
| **3 加深（可选）** | 加 [自动化](../guide/automation) 周报；或接 [公司](../platform/onmycompany) / Buddy | 至少 1 条自动任务或 1 次组织连接演练 |
| **4 复盘** | 统计采用率、阻塞、是否扩大试点 | 去/留/扩决策 |

![市场中的岗位专家](/images/marketplace.png)

## 成功标准示例（可改）

- **采用**：种子用户中 ≥70% 在第 2 周末仍有产物落盘  
- **质量**：产物可被同事直接二次编辑（不是纯闲聊）  
- **风险**：无未审批的危险本机操作投诉；密钥未进聊天  
- **支持**：阻塞有清单（模型、权限、路径、技能来源）  

## 岗位场景示例

| 岗位 | 场景 | 入口 | 输出示例 |
|------|------|------|----------|
| 项目经理 | 周会纪要 | [报告与纪要](./office-docs) | `notes/meeting-summary.md` |
| 运营 | 工作日早报 | [定时汇总](./automation-digest) | `notes/daily/….md` |
| 财务 / 法务 | 领域专家审材料 | [专家](../guide/experts) + `@` 文件 | `notes/review/….md` |
| 全员 | 个人偏好与记忆 | [设置 · 个人/记忆](../guide/memory) | 减少重复交代语境 |

## 周 1 安装日清单

- [ ] 从 [下载](../download) 安装对应平台包  
- [ ] 启动后能 **+ 新建任务**  
- [ ] [设置 → 模型](../guide/models) 至少 1 个可用服务商  
- [ ] 写入一个 `notes/hello.md` 并在 [文件](../guide/files) 中打开  
- [ ] 知道 [审批](../guide/approvals) 与权限模式在输入区底部  

## 复盘会提纲

1. 各人展示 1 个真实产物路径  
2. 列出 Top 阻塞（模型 / 权限 / 不会写提示词 / 找不到文件）  
3. 决定：扩大 A、引入 B/C、或暂停  
4. 把可复用提示词收进共享文档或专家配置
