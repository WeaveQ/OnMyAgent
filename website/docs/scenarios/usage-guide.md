# 场景使用说明（通用）

本文是 OnMyAgent 的**通用工作法**：把「聊天」变成「在本机可验收的交付」。不绑定某一行业或客户，适用于报告、表格、内容、自动化等各类场景。

一句话：**说清目标 → 给材料 → 小步执行 → 文件验收 → 能重复的再自动化。**

![首页：新建任务、会话列表与输入区](/images/home-session.png)

---

## 1. 先建立正确预期

| OnMyAgent 擅长 | 不该默认指望 |
|----------------|--------------|
| 按你的材料规划并**执行**多步任务 | 读心；信息不给全仍一次完美 |
| 在**工作区**读写、生成可打开的文件 | 静默改系统目录、跳过确认的高风险操作 |
| 用**专家 / 技能**固化方法 | 未安装的能力「假装已有」 |
| **多轮**改到满意 + **定时**重复劳动 | 第一轮就定稿、从不备份 |

本地优先：密钥与文件默认在你机器上；连接组织或 IM 是可选项，不是使用前提。

## 3. 下任务的标准公式

每次尽量写全三要素（详见 [高效技巧 · 第 1 条](../guide/efficient-tips)）：

```text
【做什么】目标 + 交付形态（表 / md / pptx …）
【有什么】@文件 或 工作区路径；没有就说「无素材、请按假设并标注」
【怎么样】受众、篇幅、语言、禁忌；输出路径（如 notes/xxx.md）
```

**反面：** 帮我整理一下上次会议。  

**正面：**

```text
把 @notes/raw-meeting.txt 整理成纪要：结论、行动项（负责人+日期）、未决事项。
表格输出行动项，写入 notes/meeting-summary.md，不要开场白。
```

不确定时先问：「我想做 XX，你需要哪些信息？」再执行。

## 4. 通用执行循环（任何场景通用）

```
① 新建任务（或专家下新会话）
      ↓
② 导入材料 → @ 引用（或写清路径）
      ↓
③ 一小步：只要可验收的中间结果
      ↓
④ 在「文件」页打开检查 → 不对就改提示词再跑
      ↓
⑤ 定稿另存；原件尽量不覆盖
      ↓
⑥ 若每周重复 → 同一提示词交给「自动」
```

| 环节 | 界面 |
|------|------|
| 派活 | 首页 **+ 新建任务** |
| 材料 | [文件](../guide/files) 导入；对话里 `@` |
| 能力 | `/` 技能 · [市场](../guide/skills) · [专家](../guide/experts) |
| 验收 | 主栏 **文件** |
| 重复 | 主栏 **自动** |
| 风险 | 输入区 **权限** · [审批](../guide/approvals) |

## 6. 专家与技能：什么时候用

| | **技能** | **专家** |
|--|----------|----------|
| 本质 | 可执行能力包（工具/流程） | 角色 + 方法 + 可选技能组合 |
| 适合 | 「处理这类文件 / 打开网页 / 找技能」 | 「按某岗位方式完整做一件事」 |
| 入口 | 市场 · 技能 · `/` | 市场 · 专家 · 主栏专家 |

- 不知道用啥：先说「列出合适技能并说明区别」（Find Skills）。  
- 行业话术要稳：用专家，或 [个人/记忆](../guide/memory) 写死常驻指令。  
- 常见能力一览：[技能](../guide/skills)。

## 7. 质量与安全清单（每次可过一遍）

**质量**

- [ ] 第一轮只要方向，不要求完美  
- [ ] 大任务已拆成 2～3 步  
- [ ] 产物在文件区能打开，路径符合约定  
- [ ] 缺数据时标注「原材料无」，而非编造  

**安全**

- [ ] 改重要文件前已备份或要求「另存」  
- [ ] 批量重命名/删除已看过预览并口头确认  
- [ ] 权限模式与风险匹配（[审批](../guide/approvals)）  
- [ ] 密钥不进聊天；搜网页注意来源与版权  

**自动化前**

- [ ] 同一提示词手动成功 ≥ 1 次  
- [ ] 提示词不依赖「上面的对话」  
- [ ] 输出目录固定

## 8. 提示词模板（可直接改）

**通用交付**

```text
目标：…
材料：@… 或 工作区路径 …
约束：受众… 篇幅… 语言… 不要…
输出：写入 notes/….md（或 xlsx/pptx 路径）
若信息不足：列出待补充项，不要编造。
```

**先预览再改文件**

```text
…（同上）
先给出变更对照表/预览，等我回复「确认执行」后再写入磁盘。
```

**分轮推进**

```text
本轮只做第 1 步：… 输出到 …
不要做第 2 步，等我确认。
```

## 9. 和「只聊天的 AI」差在哪（场景视角）

| 只聊天 | 按本说明使用 OnMyAgent |
|--------|-------------------------|
| 结果在对话框里 | 结果在**工作区文件**里 |
| 一次说完求完美 | **小步 + 多轮 + 文件验收** |
| 无角色无工具 | **专家 / 技能 / 浏览器 / 办公** 可组合 |
| 重复劳动每次手敲 | 跑通后交给 **自动** |
