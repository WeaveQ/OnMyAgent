# 实践 8：会议纪要与行动项

把录音转写稿、聊天记录或议程变成**纪要 + 行动表**，并落盘到工作区。

主界面用于发起任务与粘贴记录；整理完成后到 **文件** 页打开产物。

![主界面：新建任务、最近会话与输入区](/images/home-session.png)

![文件区：验收生成的纪要与其它产物](/images/files.png)

## 场景与目标

| 输入 | 输出 |
|------|------|
| 会议记录文本 / md / docx | 结构化纪要 |
| 多轮聊天导出 | 决议 + 未决 |
| （可选）腾讯会议纪要能力 | 需 [tencent-meeting](../../guide/skills) 类技能并授权 |

## 一句话示例

```text
把 @notes/raw/周会记录.txt 整理成会议纪要：
主题、参与人（若有）、结论、行动项（负责人+日期）、风险。
行动项用表格。写入 notes/meeting/周会-日期.md。
```

## 有录音时

1. 先得到文字稿（本地转写技能或外部工具）  
2. 导入工作区后用上面指令  
3. 需要会后自动跑：材料稳定后进 [自动化](./daily-brief)  

## 和腾讯会议

若已配置 **腾讯会议** 相关技能/连接器：

```text
拉取本周已结束的腾讯会议列表，对「项目周会」取智能纪要要点，
合并写入 notes/meeting/腾讯会议-本周摘要.md。
```

以你客户端市场中实际技能名为准。
