# 实践 1：文件识别与整理

用 OnMyAgent 批量理解本地文件、整理命名与归档，并**先预览、再执行**。

## 场景与目标

| 场景 | 目标效果 |
|------|----------|
| 文件夹命名混乱（合同、票据、截图） | 按「日期 + 主题 + 类型」统一命名 |
| 零散会议记录 / 聊天导出 | 结构化纪要（议题、结论、待办） |
| 外文材料要中文要点 | 摘要 + 术语表（有字幕/文本时） |

涉及读取或改写本地文件时，使用较严 [权限](../../guide/approvals)，高风险动作先确认。

![文件区：工作区列表与类型](/images/files-list.png)

## 批量重命名（先预览）

### 示例指令

```text
请读取工作区 inbox/ 里的文件内容或属性，按「日期 + 主题 + 类型」规则生成重命名方案。
先输出新旧文件名对照表，不要直接改名。等我回复「确认执行」后再改。
跳过系统/加密/正在占用的文件。
```

### 准备

1. 把目标文件夹放进 [工作区](../../guide/files)，或先导入副本  
2. 重要目录先整夹复制备份  
3. 先拿 3～5 个样本试跑  

### 验收

- [ ] 对照表可读，规则符合预期  
- [ ] 你明确确认后才真正改名  
- [ ] 跳过项有说明  

## 整理会议纪要

### 示例指令

```text
根据我提供的会议记录（粘贴文本或 @notes/raw-meeting.txt），整理正式纪要：
主题、关键结论、行动项、负责人、截止时间。有争议的标「未决」。
写入 notes/meeting-YYYYMMDD.md，表格输出行动项。
```

录音需先转成文字（本机若无 Whisper 类技能，可先外部转写再导入）。更多见 [会议实践](./meetings) · [报告与纪要](../office-docs)。

## 使用建议

- 先说清输出格式（Markdown / 表格 / 对照表）  
- 批量写入前：备份 + 预览 + 「确认执行」  
- 敏感/财务目录不要直接全量批处理
