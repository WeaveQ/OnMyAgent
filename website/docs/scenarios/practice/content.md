# 实践 4：内容选题与分发

适合运营、编导、内容团队：选题包、脚本、多平台改写，**产物落盘**。

## 场景与目标

| 场景 | 交付 |
|------|------|
| 周选题 | 选题表 + 钩子 + 形式 |
| 单条脚本 | 60–90 秒口播稿 |
| 一稿多发 | 小红书 / 短视频 / 公众号 三套文案 |

可配合 [专家](../../guide/experts)（内容/达人运营类）或自建「编导专家」。



![市场：专家 / 技能入口](/images/marketplace.png)

## 示例：周选题

```text
达人/账号：美妆垂类，风格口语测评。
本周：小红书 3 条 + 短视频 2 条。
输出选题表：痛点、钩子、形式、预估难度；并写 1 条完整口播脚本（60–90 秒）。
写入 notes/content/选题-WXX.md。
```

## 示例：一稿多平台

```text
基于 @notes/content/原稿.md，改写成：
1）小红书种草体（标题+正文+标签建议）
2）短视频口播 45 秒
3）公众号小标题版 800 字内
分别写入 notes/content/分发/ 下三个文件。保留事实，不编造数据。
```

## 建议

- 先定人设与平台，再写正文（[高效技巧 · 三要素](../../guide/efficient-tips)）  
- 品牌项目可改用「策略简报 / 达人评估」类提示（固定模板 + 落盘路径）  
- 批量外发、投放相关操作保持人工确认
