# 实践案例总览

把高频办公任务写成**可照做的端到端案例**：不只「知道功能」，而是「按步骤做出可验收的文件」。

![主界面：新建任务、最近会话与输入区](/images/home-session.png)

先读总工作法：[场景使用说明](../usage-guide)。

## 案例一览

| # | 主题 | 文档 | 说明 |
|---|------|------|------|
| 1 | 文件识别与整理 | [文件识别与整理](./files) | 重命名预览、纪要整理 |
| 2 | 文档生成与编辑 | [文档生成与编辑](./docs) · [报告与纪要](../office-docs) | 落盘 md/docx/pptx |
| 3 | 表格分析与汇总 | [表格分析与汇总](./data) | 清洗、汇总、结论 |
| 4 | 内容选题与分发 | [内容选题与分发](./content) | 选题、脚本、多平台 |
| 5 | 每日/每周自动简报 | [每日/每周自动简报](./daily-brief) · [定时汇总](../automation-digest) | 自动化托管 |
| 6 | 创建与进化技能 | [创建与进化技能](./skills-evolve) · [技能](../../guide/skills) | find-skills / 记忆 |
| 7 | 自动化持续推进 | [自动化持续推进](./self-drive) | 自包含提示词 + 定时 |
| 8 | 会议纪要与行动项 | [会议纪要与行动项](./meetings) | 文本纪要落盘 |
| 9 | 云文档协作（可选） | [腾讯文档协作](./tencent-docs) | 需安装并授权对应技能 |

未覆盖「远程遥控本机」「零代码搭本地应用」等路径：OnMyAgent 以**桌面工作台 + 本地交付**为主。

习惯类技巧见 [高效使用技巧](../../guide/efficient-tips)；能力说明见 [技能](../../guide/skills)。

## 推荐阅读顺序

1. [文件识别与整理](./files) — 先会动本机文件  
2. [文档生成与编辑](./docs) — 会落盘交付  
3. [表格分析与汇总](./data) — 会洗表  
4. [每日/每周自动简报](./daily-brief) — 会自动化  
5. [创建与进化技能](./skills-evolve) — 会沉淀能力  

## 统一结构

每篇实践通常包含：

- **场景与目标**  
- **开始前准备**（工作区、权限、技能）  
- **示例指令**（可复制）  
- **预期效果与验收**  
- **安全提示**（预览、备份、审批）
