# 实践 7：自动化持续推进

不是闲聊，而是**定时/触发后静默推进**，你只验收产物。入口：主栏 **自动**。

![自动化：任务列表与调度](/images/automation.png)

## 场景与目标

| 场景 | 目标 |
|------|------|
| 重复日报/周报 | 到点生成文件 |
| 规则明确的巡检 | 输出异常清单 |
| 与专家固定流水线 | 会话跑通后改自动化 |

## 原则（先稳后快）

1. 桌面会话里**看见全过程**再托管（对标「先本地后远程」）  
2. 提示词自包含：不依赖「上面聊天记录」  
3. 输出路径固定，便于 [文件](../../guide/files) 查找  
4. 删改类操作默认「只报告不执行」或要确认  

## 示例：自驱动周报

```text
【自动化提示词】
角色：项目助理。扫描 notes/ 下近 7 天 md，
输出 notes/weekly/auto-周报.md：完成 / 风险 / 需负责人拍板 3 条。
无材料时写「本周 notes 无更新」不要编造。
```

主栏 **自动** 中设每周五 17:00，启用后只看文件与运行历史。

## 和「专家 / 技能」组合

- 复杂方法：先 [创建专家](../../guide/experts) 或技能，再在自动化提示词里写「按某专家规范」  
- 浏览器抓取：先手动验证 [browser 技能](../../guide/skills#浏览器-agent-browser)，再考虑定时（注意站点 ToS）
