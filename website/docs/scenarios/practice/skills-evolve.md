# 实践 6：创建与进化技能

把重复流程沉淀为可调用技能，并让系统记住你的偏好。入口在主栏 **市场 · 技能**（也可 `/` 调用）。

![市场 · 技能相关入口](/images/marketplace.png)

## 场景与目标

| 场景 | 目标 |
|------|------|
| 同一套提示词每周重复 | 做成技能或自动化提案 |
| 不知道用哪个能力 | 先 Find Skills 再执行 |
| 经常纠正同一偏好 | 写入个人/记忆或 self-improving |

## 路径 A：找到已有技能

```text
我想处理网页采集、截图和摘要，请用 find-skills 列出已安装里合适的技能，
并说明 browser-automation 与 browser-skill 的区别。
```

见 [技能](../../guide/skills) · [浏览器](../../guide/skills#浏览器-agent-browser)。

## 路径 B：创建/改进技能

使用捆绑 **skill-creator**（市场/技能列表中可见时）：

```text
帮我创建一个技能：输入品牌资料包路径，输出「本品三维诊断」Markdown 模板。
先写 SKILL 草稿，再给我 3 条测试提示词。
```

## 路径 C：自我进化与记忆

- **self-improving**：任务失败或你纠正后，沉淀经验  
- [设置 · 个人 / 记忆](../../guide/memory)：称呼、自定义指令、事实记忆  

```text
记住：对外客户沟通默认中文、先结论后细节、不要用「赋能」这类空话。
写入个人偏好/记忆。
```

## 验收

- [ ] 新技能可在 `/` 或自然语言中触发  
- [ ] 测试提示词跑通至少 1 次  
- [ ] 偏好在新会话仍生效
