# 实践 9：云文档协作（可选）

在已授权前提下，用技能创建/读取/整理云端文档。**未安装对应技能或未登录时，本节不适用**——请改用 [本地文档实践](./docs)。

本页不附云端专属截图（界面随授权与版本变化）；安装入口与其它技能相同，见下。

![技能安装入口（市场）](/images/marketplace.png)

## 前置

1. 市场或技能列表中安装并授权 **tencent-docs**（或当前版本文案中的腾讯文档技能）  
2. 完成账号/Token 引导  
3. 先在小范围文档试读，再批量  

详见 [技能](../../guide/skills) 中的捆绑技能表。

## 示例指令

```text
在腾讯文档创建一个「项目周报」在线文档，写入本周三条进展与两条风险，
把链接发我，并同步一份 Markdown 备份到工作区 notes/weekly/腾讯文档备份.md。
```

```text
读取我提供的腾讯文档链接，提取待办与负责人，整理成表格写入 notes/todos-from-docs.md。
```

## 本地优先备选

不走云文档时：全程 [工作区文件](../../guide/files) + [文档实践](./docs)，同样可完成协作底稿，再人工粘贴到腾讯文档。

## 安全

- 企业文档权限以腾讯文档侧为准  
- 不要在提示词里粘贴长期密钥  
- 批量删除/移动云文件务必确认
