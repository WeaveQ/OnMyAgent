# 实践 5：每日/每周自动简报

用 **自动化** 做定时早报/周报草稿（先手动跑通，再托管）。

## 场景与目标

| 场景 | 目标 |
|------|------|
| 每日工作早报 | 固定路径生成当日 md |
| 周五周报草稿 | 汇总本周 notes 后落盘 |
| 项目巡检 | 检查关键文件是否更新 |

![自动化任务与调度](/images/automation.png)

## 步骤

1. 在普通 [会话](../../guide/sessions) 用同一提示词**手动成功一次**  
2. 主栏 **自动** → **+ 添加** 或 **从模板添加**  
3. 设置时间（如每天 08:30 / 每周五 17:00）与提示词  
4. 任务设为 **已启用**  
5. 到点后在运行历史与 [文件](../../guide/files) 中验收  

## 示例提示词（可贴进自动化）

```text
生成本日办公早报，写入 notes/daily/（文件名用当天日期）.md。
结构：今日必须完成 3 件事 / 阻塞 / 一眼风险。中文短句，不要寒暄。
```

```text
每周五：根据 notes/ 下本周材料，生成周报草稿（完成/进行中/阻塞/下周），
写入 notes/weekly/，面向直属领导，800 字内。
```

## 注意

- 本机睡眠/关机可能错过调度  
- 需要外发邮件/IM 时，以你环境已接连接器为准；默认以**落盘文件**为验收  
- 详见 [自动化](../../guide/automation) · [定时汇总](../automation-digest)
