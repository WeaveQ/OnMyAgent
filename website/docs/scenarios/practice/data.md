# 实践 3：表格分析与汇总

导入 Excel/CSV，清洗、汇总，输出新表或简报（不编造源表没有的数）。

## 场景与目标

| 场景 | 目标 |
|------|------|
| 台账有重复/空值 | 清洗后另存汇总表 |
| 要按客户/月份汇总 | 透视式汇总 + 结论 3 条 |
| 给领导看的简版 | 一页文字结论 + 关键数字 |



![文件中的表格类文件](/images/files-list.png)

## 示例指令

```text
读取工作区 @应收台账模板.xlsx（或实际文件名）：
1）列出字段与明显数据质量问题；
2）按客户汇总金额，降序；
3）标出 Top5 与合计；
4）另存 notes/台账-客户汇总.xlsx，并写 5 行文字结论到 notes/台账-结论.md。
不要编造原表没有的数字；缺失标「原表无」。
```

## 准备

1. 把 xlsx/csv **导入工作区**（副本）  
2. 说明主键字段（客户名、日期列）  
3. 需要公式/复杂编辑时可用 [办公技能 / OfficeCLI](../../guide/skills)

## 验收

- [ ] 汇总行数/合计可与原表抽查一致  
- [ ] 结论文件与表文件都在工作区  
- [ ] 原表仍在（未覆盖）
