# 实践 2：文档生成与编辑

从素材到可外编的 Word / Markdown / PPT，产物落在工作区。

## 场景与目标

| 场景 | 目标 |
|------|------|
| 有大纲/要点，要正式稿 | 生成结构化文档并落盘 |
| 已有长文要改短、改语气 | 另存新版本，不覆盖原件 |
| 要汇报幻灯片 | 生成 pptx 或大纲再扩写 |



![主界面：新建任务与输入区](/images/home-session.png)

## 从零生成

```text
根据以下要点写一页纸方案（背景、目标、三步计划、风险），
中文，面向业务负责人，800 字内。写入 notes/方案-客户A.md。
要点：…
```

## 基于已有文件改写

```text
参照 @notes/周报-好样本.md 的结构和语气，
根据 notes/daily/ 本周内容写周报，另存 notes/weekly/本周.md，不要覆盖样本。
```

## 生成演示文稿

```text
基于 notes/方案-客户A.md，生成不超过 10 页的汇报 PPT 大纲并做成 pptx，
输出 deliverables/客户A-汇报.pptx。每页标题 + 3 条要点。
```

办公能力见 [技能 · 办公文档](../../guide/skills)（`document-processing` / `pptx` / OfficeCLI）。

## 分步建议（对标「小步快跑」）

1. 先只要**目录/大纲**  
2. 确认后再扩某一章  
3. 最后再转 PPT / 套模板  

## 验收

- [ ] 文件区能打开产物  
- [ ] 原文件未被意外覆盖  
- [ ] 格式符合约定（标题层级、表格、字数）
