# 场景：报告与纪要

把「写报告 / 整理纪要」从聊天草稿变成**工作区里可预览、可外编的文件**。

## 目标

- 用一句话（或少量素材）生成工作报告、会议纪要  
- 产物落在固定路径，便于版本管理与二次编辑  
- 需要时 `@` 引用已有材料，避免空写  

## 准备

1. 已 [安装并配置模型](../quickstart)  
2. 工作区可写  
3. （可选）把会议录音摘要、议程、邮件导出等先 [导入文件](../guide/files)  

## 步骤

### 1. 新建任务

在首页点 **+ 新建任务**，或打开现有会话继续写。见 [第一个任务](../first-task)。

### 2. 写清需求（四要素）

好的提示通常包含：

| 要素 | 示例 |
|------|------|
| **受众** | 给直属领导 / 项目组 / 客户 |
| **结构** | 决议、待办、风险；或背景-进展-下一步 |
| **篇幅** | 一页纸 / 800 字以内 |
| **落盘路径** | `notes/meeting-summary.md` |

若已有素材：先导入，再在输入框用 `@` 引用文件或文件夹。

### 3. 执行与追问

- 可要求改语气、补待办负责人、压缩为 bullet  
- 涉及覆盖已有文件时注意 [审批与权限](../guide/approvals)  
- 底部可切换模型与权限模式  

### 4. 验收

1. 对话里看结论是否完整  
2. 打开主栏 **文件**，确认目标路径已生成  
3. 应用内预览，或「在应用中打开」用系统编辑器外编  

![在文件区查看文档类产物](/images/files.png)

## 示例提示词

**会议纪要（有素材）**

```text
根据工作区中与「周会」相关的材料（可用 @ 引用），整理一页纪要：
1）决议（带负责人）
2）待办（负责人 + 截止日期）
3）风险与需升级事项
输出 notes/meeting-summary.md，中文，条目优先。
```

**周报（无素材、凭对话补全）**

```text
帮我写本周工作周报草稿，结构：本周完成 / 进行中 / 阻塞 / 下周计划。
面向直属领导，800 字以内。先根据我下面补充的要点写，再写入 notes/weekly/2026-W32.md。

要点：
- …
```

**把散落笔记收成报告**

```text
阅读 notes/ 下本周相关 md，合并为一份对外可读的进展报告，
输出 notes/status-report.md：先结论后细节，并列出 3 条需要决策的问题。
```

## 常见问题

| 现象 | 处理 |
|------|------|
| 只有对话没有文件 | 提示词写明「写入 `notes/….md`」；检查权限模式 |
| 没引用到材料 | 先导入，再用 `@`；或写清相对工作区路径 |
| 格式太散 | 要求「条目优先 / 表格 / 固定四级标题」 |
