# 场景：报告与纪要

## 目标

用一句话生成或整理工作报告、会议纪要，并保存到工作区。

## 步骤

1. [新建任务](../first-task)  
2. 说明受众、结构、字数、输出文件名  
3. 若有素材，先 [导入文件](../guide/files) 再 `@` 引用  
4. 在文件区打开 Markdown/文档预览并外编  

![在文件区查看文档类产物](/images/files.png)

## 示例提示词

```text
根据工作区中「会议纪要」相关材料，整理一页纪要：
决议、待办（负责人+日期）、风险。输出 notes/meeting-summary.md。
```
