# Windows 安装

Windows 为 **开发者预览**，功能与稳定性可能弱于 macOS。

## 步骤

1. 从 [GitHub Releases](https://github.com/WeaveQ/OnMyAgent/releases) 获取 NSIS 安装包（若当次发布提供），或按 monorepo 根目录 `BUILD.md` 本地打包  
2. 运行安装器，从开始菜单启动 **OnMyAgent**  
3. 未签名构建可能触发 **SmartScreen**：选择「仍要运行」  
4. 启动后按 [快速开始](../quickstart) 配置  

## 兼容性

详细已知限制与说明见仓库 `docs/windows-compat.md`。
