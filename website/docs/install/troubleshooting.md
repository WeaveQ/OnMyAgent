# 排障

| 现象 | 处理 |
|------|------|
| 模型无响应 | 检查 Key、Base URL、代理与额度；见 [模型](../guide/models) |
| 无法写文件 | 工作区路径是否可写；磁盘空间；权限模式是否过严 |
| 权限类能力不可用 | macOS：辅助功能 / 屏幕录制 / 完全磁盘访问等；在 [设置 → 系统设置](../guide/settings#系统设置) 查看 |
| 升级后技能异常 | 重启应用；确认技能仍已安装 |
| 界面空白 | 重启；检查代理是否干扰本地服务 |
| macOS 提示应用已损坏 | 预览包未公证。执行 `xattr -cr /Applications/OnMyAgent.app` 后再打开 |
| 检查更新后没有安装按钮 | 开发构建只能打开 Releases。打包版后台下完后才会出现 **重启并安装** |
| 设置打不开 | 使用 **⌘ ,** / **Ctrl ,**；或从齿轮菜单进入 **设置** |
| 自动化不跑 | 确认任务 **已启用**、系统未睡眠过久；见 [自动化](../guide/automation) |

仍无法解决：携带 **版本号**（设置 → 更新）、系统版本与截图，提交 [GitHub Issue](https://github.com/WeaveQ/OnMyAgent/issues)。
