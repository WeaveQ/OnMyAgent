# 知识库

知识库是本机笔记文件夹：左侧按库分组，右侧阅读或块编辑。它不是技能，也不是工作区文件，也不是记忆。

## 1. 和相近模块的区别

| 模块 | 放什么 | 入口 |
| --- | --- | --- |
| **知识库** | 你要查阅、以后让助手检索的笔记 | 主栏 **知识库** |
| **技能** | 助手怎么做事 | 市场 · 技能 |
| **记忆** | 你是谁、已确认事实 | 设置 · 记忆 |
| **文件** | 工作区资料与任务产物 | 主栏 **文件** |

笔记不会进入「已安装」技能列表。会话里的 `knowledge_search` 只查这份本机库。

## 2. 入口

主栏 **知识库**（书本图标）。仅桌面端。默认笔记在 `~/.onmyagent/data/user/knowledge/`。可以把个人库指到已有的 Obsidian 文件夹。

## 3. 界面

| 区域 | 作用 |
| --- | --- |
| 左侧搜索与工具条 | 搜索、**新建**（笔记 / 表格 / 上传）、打开文件夹、展开/收起、**同步索引** |
| 分组列表 | **我的资料 / 项目库 / 专家库**；可新增或移除本机文件夹 |
| **最近访问** | 打开过的笔记 |
| 文件树 | 文件夹和笔记在同一棵树；可拖拽、右键重命名/移动/删除 |
| 右侧标签 | 多笔记并开；在查看和编辑之间切换 |
| 阅读 | 渲染后的 Markdown；`.html` 为只读预览 |
| 编辑 | 默认块编辑。输入 `/` 插入块；可切到纯源码 |

第一次打开会看到「使用说明」。没有打开标签时提示从左侧点开或新建；这个范围里一篇都没有时提示先建笔记。

## 4. 能做什么

### 多库与最近访问

**新增文件夹** 只把目录加入列表，磁盘文件不会被删；**移除文件夹** 同样只改列表。打开过的笔记会出现在 **最近访问**（本机另存一份最近列表）。

**项目库** 和 **专家库** 在没有对应工作区或专家时显示 **暂不可用**。不要把它们当成已经能随便建的第二套库。

### 块编辑与属性

`.md` 默认用块编辑。`/` 可插入正文、一到三级标题、无序/有序列表、待办、引用、代码块。笔记属性可改标题、标签和关联；你另外加的自定义字段保存时会留下。

需要手改标记时，切到 **纯源码**。

### 新建、上传与书签

**新建** 可以建笔记或表格，也可以 **上传文件** / **上传文件夹**。`.html` 只读预览，页面经过消毒，不能当编辑器改。**添加链接** 把网页存成 Markdown，网址写在属性里。

### 从会话存入

会话顶栏的 **存入知识库** 把当前对话写成笔记：可改文件名并选择保存位置。仅桌面端；存好后打开那篇笔记。

## 5. 会话里引用

助手用 `knowledge_search` / `knowledge_read` / `knowledge_create` 操作与主栏同一份磁盘笔记（不是市场里的 Obsidian 技能）。检索或读到笔记后，对话里会出现 **来自知识库 · 某.md**。点一下会跳到知识库并打开该笔记。

## 6. 建议

- 检索覆盖 `.md` / `.txt` / `.csv`。Excel / Word / PDF 这一版不进索引。
- 改完笔记后若搜索对不上，点一次 **同步索引**。
- 不要把密钥、客户原件整库拷进演示用的公开文件夹。
