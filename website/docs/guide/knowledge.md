# 知识库

知识库是本机 Markdown 笔记文件夹：左侧一棵文件树，右侧阅读或源码编辑。它不是技能，也不是工作区文件，也不是记忆。

## 1. 和相近模块的区别

| 模块 | 放什么 | 入口 |
| --- | --- | --- |
| **知识库** | 你要查阅、以后让助手检索的笔记 | 主栏 **知识库** |
| **技能** | 助手怎么做事 | 市场 · 技能 |
| **记忆** | 你是谁、已确认事实 | 设置 · 记忆 |
| **文件** | 工作区资料与任务产物 | 主栏 **文件** |

笔记不会进入「已安装」技能列表。会话里的 `knowledge_search` 只查这份本机库。

## 2. 入口

主栏 **知识库**（书本图标）。桌面端可用；笔记默认在 `~/.onmyagent/data/user/knowledge/`。可以把个人库指到已有的 Obsidian 文件夹。

## 3. 界面

| 区域 | 作用 |
| --- | --- |
| 左侧搜索与工具条 | 搜索、新建笔记/文件夹、打开文件夹、展开/收起、**同步索引** |
| 文件树 | 文件夹和笔记在同一棵树；可拖拽、右键重命名/移动/删除 |
| 底部切库 | 切换默认库或已添加的文件夹 |
| 右侧标签 | 多笔记并开；铅笔在阅读和编辑之间切换 |
| 阅读 | 渲染后的 Markdown |
| 编辑 | 默认 **源码 \| 预览分栏**（右侧随打随刷）；可收成纯源码。不是所见即所得画布 |

第一次打开会看到「使用说明」。没有打开标签时提示从左侧点开或新建；库里一篇都没有时提示先建笔记。

## 4. 会话里引用

助手用 `knowledge_search` / `knowledge_read` / `knowledge_create` 操作与主栏同一份磁盘笔记（不是市场里的 Obsidian 技能）。检索或读到笔记后，对话里会出现 **来自知识库 · 某.md**。点一下会跳到知识库并打开该笔记。

## 5. 建议

- 检索覆盖 `.md` / `.txt` / `.csv`。Excel / Word / PDF 这一版不进索引。
- 改完笔记后若搜索对不上，点一次 **同步索引**。
- 不要把密钥、客户原件整库拷进演示用的公开文件夹。
