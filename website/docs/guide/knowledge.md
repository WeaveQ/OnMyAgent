# 知识库

本机笔记：左侧按库分组，右侧阅读或块编辑。不是技能、工作区文件，也不是记忆。

## 1. 和相近模块的区别

| 模块 | 放什么 | 入口 |
| --- | --- | --- |
| **知识库** | 要查阅、以后让助手检索的笔记 | 主栏 **知识库** |
| **技能** | 助手怎么做事 | 市场 · 技能 |
| **记忆** | 你是谁、已确认事实 | 设置 · 记忆 |
| **文件** | 工作区资料与任务产物 | 主栏 **文件** |

会话里的 `knowledge_search` 只查这份本机库，笔记不会进「已安装」技能。

## 2. 入口和界面

主栏 **知识库**，仅桌面。默认在 `~/.onmyagent/data/user/knowledge/`，个人库可指到已有的 Obsidian 文件夹。

| 区域 | 作用 |
| --- | --- |
| 左侧 | 搜索、新建/上传、同步索引；**我的资料 / 项目库 / 专家库**；**最近访问**；文件树 |
| 右侧 | 阅读或块编辑。输入 `/` 插块，可切纯源码。`.html` 只读 |

**新增/移除文件夹** 只改列表，不删磁盘文件。项目库、专家库没有对应范围时显示 **暂不可用**。

## 3. 能做什么

| 操作 | 说明 |
| --- | --- |
| 块编辑 | `.md` 默认；手改标记时切纯源码 |
| 新建 / 上传 | 笔记、表格、上传文件或文件夹、**添加链接** |
| 存入知识库 | 会话顶栏，把当前对话写成笔记 |
| 会话里打开 | 点 **来自知识库 · 某.md** 会跳到这篇笔记 |

## 4. 注意

- 检索覆盖 `.md` / `.txt` / `.csv`。Excel / Word / PDF 不进索引
- 搜索对不上时点一次 **同步索引**
- 不要把密钥、客户原件拷进演示用的公开文件夹
