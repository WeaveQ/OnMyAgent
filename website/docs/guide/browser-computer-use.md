# 浏览器与 Computer Use

浏览器工具用于网页导航和读取；Computer Use 用屏幕、辅助功能或平台驱动操作桌面应用；Appshot 则把当前应用画面作为会话附件。三者能力和权限不同。

## 1. 能力对照

| 能力 | 主要对象 | 典型用途 | 关键权限 |
|------|----------|----------|----------|
| 内置浏览器运行时 | 网页 | 打开页面、点击、输入、截图 | 网站登录与网络 |
| BrowserSkill / `bsk` | 外部浏览器桥 | 复用 Chrome/Edge 扩展和真实浏览器会话 | 外部 CLI、扩展和浏览器权限 |
| Computer Use | 桌面应用 | 识别界面并操作控件 | 辅助功能、屏幕录制，视平台而定 |
| Appshot | 当前应用窗口 | 把可见界面附到当前任务 | 屏幕捕获权限 |

内置浏览器与 BrowserSkill 是两条不同链路；检测到浏览器并不代表外部 `bsk` 已安装或扩展已连接。

## 2. macOS 与 Windows

| | macOS | Windows |
|--|-------|---------|
| 产品定位 | 主版本与日常 dogfood | Electron / NSIS 未签名开发者预览 |
| Computer Use | HandsFree helper、AX、Skysight（helper 就绪时） | staged Cua Driver，MCP 默认关闭 |
| Appshot | 支持 | 支持 |
| 额外限制 | 需要辅助功能和屏幕录制授权 | 不具备 HandsFree/Skysight 完整 parity |

Linux 桌面不是当前产品发布目标；CI 或沙箱使用 Linux 不等于提供 Linux 客户端。

## 3. 首次配置

1. 打开 **设置 → 系统设置 → Computer Use**。
2. 按向导连接 helper 或平台驱动。
3. 在系统设置中授予屏幕录制、辅助功能等必要权限。
4. 回到 OnMyAgent 检查运行状态；系统权限刚修改时可能需要重启应用或 helper。
5. 用无隐私的测试窗口执行一次只读识别，再测试点击。

不要在真实生产应用、支付页面或管理员控制台中做首次自动点击测试。

## 4. 浏览器使用建议

- 登录检查优先复用已有、明确授权的浏览器会话。
- 网页有专用 API、MCP 或连接器时，语义工具通常比屏幕点击更稳定。
- 页面刷新后重新获取控件引用；不要继续使用旧坐标或旧 DOM ref。
- 验证码、系统弹窗和安全确认必须交给用户处理，不能把它们藏在录制外继续操作。

## 5. Appshot 与附件

在会话输入区选择 Appshot 后，先检查截图中是否含聊天、邮件、通知、账号、路径或密钥。Appshot 是当前画面附件，不代表 Agent 自动拥有整个系统的操作权限。

## 6. 安全边界

- 屏幕可见不等于允许读取或外发其中全部信息。
- 辅助功能权限很强，只给可信的本机应用和测试用户。
- Computer Use 执行写入、发送、删除、购买或发布时保留人工审批。
- Windows 预览能力必须按实测范围说明，不能照搬 macOS 承诺。

## 7. 排障

| 现象 | 检查 |
|------|------|
| 看不到画面 | 屏幕录制权限、目标窗口是否最小化/被遮挡 |
| 能看不能点 | 辅助功能权限、helper 状态、控件是否在另一个进程 |
| 点击错位置 | 缩放/多显示器、窗口移动、旧坐标或布局变化 |
| BrowserSkill 不可用 | `bsk` CLI、浏览器扩展、浏览器进程和版本 |
| Windows 找不到驱动 | Cua Driver 是否已 staged、MCP 是否显式开启 |
