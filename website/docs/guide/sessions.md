# 会话

会话（任务对话）是一次可恢复的办公协作：你描述目标，Agent 执行并回复，可多轮追问。

![主界面：最近任务列表与输入区](/images/home-session.png)

## 能做什么

| 操作 | 说明 |
|------|------|
| 新建任务 | **+ 新建任务** 开启新会话 |
| 继续旧任务 | 在「最近」列表点选 |
| 多轮追问 | 在同一会话补充约束或改目标 |
| 引用上下文 | `@` 引用文件或对话片段 |
| 调用技能 | `/` 打开技能与指令 |
| 切换模型 | 输入区右侧模型选择 |
| 权限模式 | 控制自动执行与确认强度 |

## 任务状态

列表会展示相对时间；对话区可显示执行进度（如「已完成 · 用时」）。

## 与文件的关系

当 Agent 写出文档/表格时，请到 [文件](./files) 验收，不要只依赖对话气泡。

## 建议

- 一个会话聚焦一个可交付结果  
- 长任务拆成多步，每步可验收  
- 敏感操作前收紧权限模式
