# 会话

会话（任务对话）是一次可恢复的办公协作：你描述目标，OnMyAgent 的 OpenCode 主运行时在当前工作区执行、流式返回过程，并把主会话与产物记录到对应存储。

![主界面：最近只列出主任务](/images/home-session.png)

<p class="oma-shot-caption">「最近」只显示你发起的主任务。并行子任务不会单独占一行。</p>



## 1. 新建、继续与定位会话

| 操作 | 说明 |
|------|------|
| 新建任务 | **+ 新建任务** 在当前工作区开启会话 |
| 继续旧任务 | 在 **最近** 列表点选主任务；确认它属于当前工作区 |
| 多轮追问 | 在同一会话补充材料、约束或修改方向 |
| 搜索 | 在长会话中定位消息和命中位置 |
| 回退 | 从指定用户消息重新推进；先确认之后的分支是否仍需要 |
| 停止 | 结束当前正在流式执行的任务，不等于删除会话 |

会话和 workspace 身份来自 URL。目标工作区或会话不存在时，产品应显示未找到或选择提示，不能静默打开列表中的其他工作区。

### 最近列表只显示主任务

**最近** 只列出你发起的主任务（点 **+ 新建任务**、从首页输入，或从文件「加入任务」打开的会话）。Agent 为并行拆解而创建的子任务会话**不会**单独占一行，避免同一件事在列表里铺开好几条。

子任务进度在当前对话里看，见 [并行子任务](#并行子任务)。不要把列表变短理解成子任务被删掉了。

## 2. Composer 输入区

| 控件 | 用途 | 注意 |
|------|------|------|
| 附件 / 拖放 | 添加本机文件、图片或支持的产物 | 远程工作区会先上传；检查副本位置 |
| Appshot | 把当前应用画面作为上下文 | 发送前检查隐私和系统通知 |
| `@` | 引用工作区文件、目录或上下文 | 引用不等于绕过目录权限 |
| `/` | 打开命令、技能和提示入口 | 能力取决于已安装目录和当前运行时 |
| 技能 / MCP / 连接器 | 给 Agent 增加动作 | 第一次调用时核对账号和目标资源 |
| 工作模式 | Ask / Craft / Plan 等协作方式 | Plan 模式先确认方案再执行 |
| 模型 / 推理档位 | 选择本次任务的模型和推理强度 | 服务商能力、费用和上下文不同 |
| 上下文用量 | 查看当前窗口占用。上限优先取模型**目录**里的上下文窗口（百万级显示为 **1M**，不会写成 1048.6K）；占用按系统提示词、工具及子智能体、对话消息、技能、缓存命中等拆开 | 接近上限时可新开任务或压缩上下文。「回复 / 推理」是上一轮生成，**不计入**上方占用 |
| 正文右键菜单 | 对话正文可选中；右键 **剪切 / 复制 / 粘贴 / 全选** | 与系统剪贴板一致 |
| 访问权限 | 决定哪些动作自动执行、哪些询问 | 外发、删除和敏感写入建议保留审批 |

![上下文用量：目录窗口与占用拆分](/images/session-context-usage.png)

<p class="oma-shot-caption">点输入区模型旁的圆环可打开「上下文用量」。条形是当前占用；「回复 / 推理」是上一轮生成，不计入占用。</p>

## 3. 执行、Plan 与 Goal

- 普通任务会显示流式文本、工具调用、状态和完成原因。
- Plan 模式可先生成方案，再由你确认执行或取消。
- Goal 可用于较长目标的暂停、继续和清理；暂停不会自动删除已经产生的文件。
- Agent 需要业务选择时，会弹出单选、多选或自由输入问题。
- 遇到权限请求时，可允许一次、按当前范围允许或拒绝；具体选项以弹窗为准。

不要把“计划已生成”当作任务完成，也不要把工具调用成功当作最终产物已经验收。

### 并行子任务

Agent 把一项工作拆成多个子任务时，时间线会收成一组，标题为 **N/M 个子任务**（已完成 / 总数）。

- 展开可看每条子任务的说明与状态（运行中 / 完成 / 失败）。
- 子任务返回的正文会直接展开阅读，不再包一层难读的 `task_result`。
- 同一说明、紧挨着的失败再重试，会折成一条，避免连续重复卡片。
- 中间插入了你的追问或 Agent 旁白后，下一轮再跑的同类任务是**新的一组**（新回合），不会和上一组硬并在一起。

不要把「子任务卡片变绿」当成整件任务已验收；仍要按下一节检查产物。

## 4. 产物、浏览器与侧栏

会话可展示文件、diff、图片、Office 文档、网页和浏览器结果。支持的类型可在应用内预览；不支持或过大的文件会下载或交给系统应用。落到工作区的 Markdown 文件在对话里按**文件链接**展示，点开走文件预览，而不是「打开产物」药丸。

验收顺序建议：

1. 在对话中确认 Agent 声称完成的目标；
2. 打开产物侧栏或 [文件与产物](./files)；
3. 用独立应用打开文档、表格、演示、音视频等；
4. 检查文件名、格式、内容、引用和实际保存位置；
5. 不合格就在同一会话明确指出需要修改的地方。

## 5. 状态、错误与恢复

| 状态 | 含义 | 建议 |
|------|------|------|
| 运行中 | Agent 或工具仍在执行 | 等待、查看步骤；必要时停止 |
| 待审批 | 有动作等待你的决定 | 核对命令、路径、外发目标 |
| 已完成 | 当前 run 正常结束 | 继续验收产物，不只看绿色状态 |
| 已停止 | 用户或系统取消当前 run | 检查是否留下半成品 |
| 模型不可用 | Provider、认证或模型目录异常 | 打开 [模型与 BYOK](./models) |
| 工作区未就绪 | Server/OpenCode 或远程连接异常 | 运行工作区诊断 |
| 上下文到达限制 | 模型无法继续完整输出 | 让 Agent 从未完成点继续，或开新会话携带摘要 |

应用重启后，应从主会话存储恢复已知会话；短暂列表过期可等待 SSE 同步或刷新。不要用 Personal Local Agent 的对话文件手工补写主 Archive。

## 6. 和 Agent 对话的区别

| | 首页会话 | Agent 对话 |
|--|----------|------------|
| 运行时 | OpenCode 主轨 | Electron Personal Local Agent 辅轨 |
| 典型用途 | 工作区办公任务、主归档、Server API/SSE | 直接使用本机 Codex、Claude Code、Hermes 等 CLI/ACP Agent |
| 存储 | Server session / archive | Personal conversation store |
| UI | 可共用时间线外观 | 可共用时间线外观，但不共享写存储 |

若要直接驱动本机 CLI 智能体，请用账号菜单里的 [Agent 对话](./agent-chat)；安装、检测和修复见 [Agent 管理](./agent-management)。

## 7. 使用建议

- 一个会话聚焦一个可交付结果，标题和工作区保持可识别。
- 先用小样本和只读权限验证，再扩大文件范围或自动化。
- 对高成本模型、长任务和外部服务明确预算与停止条件。
- 敏感操作前收紧权限；对结果文件做独立打开/解析验证。
