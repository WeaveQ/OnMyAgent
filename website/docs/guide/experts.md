# 专家

专家是带**角色、方法论、技能与记忆**的配置：不是通用聊天，而是按岗位/场景「换一位同事」来干活。

下面按真实界面说明：**从市场装专家 → 主栏里用专家 → 自己创建专家**。

## 1. 专家是什么

| 维度 | 说明 |
|------|------|
| **角色** | 定位（如创业教练、财务管家），决定怎么想问题 |
| **角色提示词** | 运行时核心：简介、能力、规则、禁止项、流程、交付结构、沟通风格（七段） |
| **技能** | 可挂载 Skill，让专家能执行具体动作 |
| **专家记忆** | 稳定背景（行业、项目、偏好），不经常变的事实 |
| **会话** | 在主栏「专家」里与某位专家多轮协作；产物可进 [文件](./files) 的专家来源 |

和 [技能](./skills) 的区别：技能是能力包；专家是**带着偏好与流程去调用能力**的角色。

## 2. 从市场发现并选用

入口：主栏 **市场** → 顶栏 **专家**（与技能、连接器并列）。



![市场 · 专家：分类、搜索与专家卡片](/images/marketplace.png)

### 界面要点

| 区域 | 作用 |
|------|------|
| 顶栏 **专家 / 技能 / 连接器** | 切换能力类型 |
| 分类标签（全部、OPC、产品研发、金融…） | 按行业/场景筛选 |
| 搜索框 | 按职称或描述搜索 |
| **我创建的专家** | 查看自己沉淀的专家 |
| **+ 创建专家** | 进入创建流程（见下文） |
| 专家卡片 | 名称、简介、标签；点击进入详情或使用 |

### 建议用法

1. 先按岗位选分类，或搜索「财务 / 纪要 / 法务」等关键词  
2. 读卡片简介，优先选与真实工作匹配的专家  
3. 安装或选用后，到主栏 **专家** 里开会话（不要只停在市场浏览）

## 3. 在主栏使用专家

入口：左侧主栏 **专家**。



![主栏 · 专家：列表与空状态](/images/experts-rail.png)

### 空状态时

若还没有专家会话，会看到：

- 顶部 **搜索智能体…**、**+ 创建专家**  
- 提示「暂无专家会话」  
- **+ 选择专家** → 从已有/市场专家中选一位开始  

### 已有专家时（会话中）



![主栏 · 专家：与「创业教练」对话](/images/experts.png)

典型结构：

| 区域 | 作用 |
|------|------|
| 左侧列表 | 已添加的专家（如「创业教练」） |
| **+ 创建专家** | 新建自定义专家 |
| **+ 新会话** | 在同一专家下开新对话 |
| 介绍 / 资料 | 查看专家说明与资料 |
| 主对话区 | 多轮协作；可用 `@` 引用文件、`/` 调用技能 |
| 输入区 | 权限模式与模型切换（同首页会话） |

### 使用步骤（推荐）

1. 主栏点 **专家**  
2. 若列表为空 → **选择专家** 或先去市场安装  
3. 点选专家 → **新会话**（或继续旧会话）  
4. 用**领域目标**描述任务，例如：  

```text
你是创业教练。请根据我下面的业务背景，给出本周 3 个优先级最高的验证实验，
每个实验写：假设、最小动作、成功指标。写入 notes/startup-weekly.md。
```

5. 需要材料时先 [导入文件](./files)，再 `@` 引用  
6. 验收产物时到 **文件** 页查看（专家相关产物可按来源筛选）  

### 提示词小技巧

| 更有效 | 避免 |
|--------|------|
| 点名角色 + 交付物路径 | 只说「帮我想想」 |
| 给约束（受众、篇幅、格式） | 一次塞 10 个无关目标 |
| 分步：先大纲再成稿 | 要求一次写完又改方向 |

## 4. 创建自己的专家

入口（任选）：

- 主栏 **专家** → **+ 创建专家**  
- 市场顶栏 **+ 创建专家**  



![创建专家：左侧专家教练对话](/images/experts-create.png)

### 创建界面：专家教练

创建页标题为 **专家教练**（不是业务专家本身）。教练会：

1. 自我介绍并问：你希望这个专家主要帮你做什么？  
2. 给出选项（也可直接打字）：  
   - 帮你分析和做决策  
   - 帮你处理具体任务  
   - 帮你写内容  
   - 帮你沟通和表达  
3. 按阶段澄清：定位 → 能力 → 规则 → 禁止行为 → 流程 → 交付结构 → 沟通风格  
4. 方案完整后，请你在对话里回复 **「确认」**，再把草案同步到右侧配置（名称、简介、角色提示词、专家记忆等）  

输入框提示示例：「说出你的想法，我帮你创建专家」。

### 右侧会沉淀的配置（确认后）

| 字段 | 用途 |
|------|------|
| **名称 / 简介** | 列表与市场展示 |
| **角色提示词** | 七段式运行时角色（专家简介、核心能力、关键规则、禁止行为、工作流程、内容结构、沟通风格） |
| **专家记忆** | 稳定事实（项目、受众、偏好），**不要**把整段角色提示词塞进记忆 |
| **技能** | 挂载该专家需要的 Skill |
| **知识**（若有） | 补充资料范围 |

也可在配置就绪后用 **试试效果** 预览，再点 **完成** 保存。

### 创建示例对话

```text
我想做一个「周会纪要专家」：帮产品经理把零散会议记录整理成决议、待办（负责人+日期）、风险。
输出固定为 Markdown，默认中文，不编造没出现过的决议。
```

确认方案后，再在主栏专家列表里开会话实战。

## 5. 推荐路径（第一次用）

| 步骤 | 做什么 | 截图位置 |
|------|--------|----------|

## 6. 专家 vs 技能 vs 会话

| | 专家 | 技能 | 首页会话 |
|--|------|------|----------|
| 适合 | 固定岗位/方法论 | 单次能力调用 | 临时任务、探索 |
| 入口 | 市场 · 专家 / 主栏 · 专家 | 市场 · 技能、`/` | 首页 · 新建任务 |
| 产出 | 专家会话 + 文件（可归因） | 由当前会话执行 | 任务产物 |

---

## 7. 生命周期与安全

- 只有 **我的专家**（已安装 / 自建）可以永久删除。市场内置与产品内置（如创建教练）会直接拦住。
- 删除会清掉该专家绑定的真实会话与本机包材料，但不会误删创建流程中的 `draft:*` 草稿。
- 删除按专家身份匹配，不依赖包名是否写成 `包名:包名` 这种复合形式。
- 个人专家写入本机 profile；组织专家通常来自只读企业目录。
- 专家记忆、知识目录和技能仍受工作区、文件和审批权限约束。
- 安装包内出现专家资源不等于它已安装到当前 profile；以“我的专家”和真实会话为准。
