# 专家

专家是带**角色、方法论与工具偏好**的配置，用于特定领域任务（如财务、法务、运营、物流等）。

![市场中的专家卡片与分类](/images/marketplace.png)

## 专家中心 vs 我的专家

| 入口 | 说明 |
|------|------|
| **市场 · 专家** | 浏览分类、搜索职称/描述、安装使用 |
| **我创建的专家 / 创建专家** | 沉淀团队自己的专家配置 |

## 主栏「专家」

左侧主栏 **专家** 用于进入专家相关会话与列表（与市场安装配合使用）。

![专家相关界面](/images/experts.png)

## 使用方式

1. 在市场安装需要的专家  
2. 新建任务时指定专家角色，或从其入口发起  
3. 用领域目标描述任务（比泛泛「写一下」更有效）  

## 状态说明

专家目录会持续扩展；**未打磨完成的垂类不当作试点主承诺**。优先选与真实岗位匹配、已验证的专家。
