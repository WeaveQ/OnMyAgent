# 高效使用技巧（10 条）

新手上手的 10 条高频习惯，落到 **OnMyAgent** 的界面与能力上。

一句话：先掌握这 10 条，才能更快把**模糊想法 → 可执行任务 → 工作区可验收产物**。

## 适合谁

- 第一次用 OnMyAgent，不知道怎么下任务  
- 已经在用，但结果时好时坏  
- 希望真正进日常工作，而不是「只问一问」  

建议先完成 [快速开始](../quickstart) 与 [第一个任务](../first-task)，再回来巩固习惯。

## 1）说清楚任务：做什么 + 有什么 + 怎么样

别让 Agent 猜意图。可用「三要素」：

| 要素 | 写清什么 | OnMyAgent 怎么给 |
|------|----------|------------------|
| **做什么** | 目标与交付物 | 「整理成表格 / 写入某路径」 |
| **有什么** | 材料在哪 | 先 [导入文件](./files)，再用 `@` 引用；或写工作区相对路径 |
| **怎么样** | 格式、受众、篇幅、禁忌 | 「表格输出、不要开场白、中文」 |

**反面：** 帮我把上次的会议纪要整理一下。  

**正面：**

```text
把工作区 notes/0320-产品评审.md（或 @该文件）整理成清单：
1）每个议题的结论；2）责任人与截止日期；3）标出有争议/未决项。
用表格输出，写入 notes/0320-行动项.md，不要开场白。
```

**小贴士：** 不确定时先问——「我想做 XX，你需要我提供哪些信息？」再正式执行。

---

## 2）小步快跑：一次只推进一步

大任务整包丢进去，容易又长又偏。拆成可验收的小步：

**反面：** 读完 50 页报告，做 PPT，再发领导邮箱。  

**正面（三轮）：**

1. 读 `报告/行业.pdf`，提炼 5 条结论 + 页码  
2. 基于 5 条结论写 15 页汇报**大纲**  
3. 大纲确认后，再扩某一页的正文 / 生成 [PPT](./skills)

每步在 [文件](./files) 里能打开产物，再进入下一步。

---

## 3）不满意就改：第一轮只是起点

对话默认是多轮的。常见调法：

- 直接指出：「太长 / 太正式 / 第三段重写」  
- 换具体场景：「给合作三年的老朋友，像微信语气」  
- 补限制：受众、字数、格式  
- 换视角：老板 / 客户 / 分析师  

可配合 [专家](./experts) 固定角色，或 [个人 / 自定义指令](./memory) 写死常驻规矩。

---

## 4）先桌面、后远程：先看得见再放手

1. **先在桌面端**看执行过程、权限弹窗、文件落点  
2. 摸清习惯后，再考虑自动化无人值守、或外部 IM 触达（若你环境已接）  
3. 涉及移动/删除/归档：先要「列出待操作清单，我确认后再执行」  

示例：

```text
列出工作区 downloads/ 下文件，按类型分组。
再给出将 pdf → notes/归档/pdf、xlsx → notes/归档/xlsx 的移动清单，
等我确认后再执行。不要直接改。
```

高风险动作见 [审批与权限](./approvals)。

---

## 5）给它一个身份：用好专家

- 在市场安装岗位专家，或 [创建专家](./experts)
- 用领域任务描述，而不是泛泛「写一下」  
- 专家会话与首页任务分开，避免上下文搅在一起  

详见 [专家](./experts)。

---

## 6）给例子比堆要求更管用

语气、版式、结构很难说清时：**贴一个满意样本**。

```text
参照 @notes/周报-好样本.md 的结构和语气，
根据本周 notes/daily/ 内容写本周周报，写入 notes/weekly/本周.md。
```

或：`/` 调用已装 [技能](./skills)，固定流水线。

---

## 7）多开任务，别在烂上下文里死磕

| 做法 | OnMyAgent |
|------|-----------|
| 一事一会话 | 首页 **+ 新建任务**，或专家下 **+ 新会话** |
| 写方案 / 洗表 / 回邮件分开 | 多个任务并行，互不污染 |
| 越聊越飘 | 新开任务，用 5 行重述背景 + `@` 关键文件 |

[设置 · 偏好](./settings) 里也可了解会话压缩、闲置自动新开等选项。

---

## 8）先备份，再让 Agent 改文件

Agent 可能改过头。成熟用法是**可回退**：

- 改重要文档前：复制一份 `xxx-备份-日期`  
- 默认让 Agent **另存新文件**，不覆盖原件（可在提示词写死）  
- 需要时用 [归档](./settings#归档) / 工作区版本习惯  

```text
基于 @方案.docx 改一版更短的对外稿，另存为 方案-对外简版.docx，不要覆盖原文件。
```

---

## 9）用好自动化，让重复劳动自己跑

1. 先在会话里**手动跑通**同一提示词  
2. 主栏 **自动** → 添加 / 从模板添加  
3. 写死调度时间 + 输出路径  

适合：每日早报、周五周报、固定巡检。见 [自动化](./automation) · [定时汇总场景](../scenarios/automation-digest)。

```text
每周五 17:00：汇总 notes/ 下本周相关 md，生成周报草稿 notes/weekly/。
```

---

## 10）「偷懒」做对：机械劳动外包 + 角色激发质量

- **偷懒（正确）：** 格式化表格、统一字段、套模板、批量重命名 → 交给 Agent + [办公技能](./skills)
- **激发质量：** 明确角色与标准（「按优秀研报标准，缺数据就标注假设」），而不是空喊「写好一点」  

精力留给**决策与判断**；执行与整理尽量外包。
