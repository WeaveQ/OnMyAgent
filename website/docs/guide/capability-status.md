# 功能与平台状态

本页说明手册如何使用“正式、条件、预览、隐藏、占位”等状态，避免把源码存在或一个绿色状态误写成已交付能力。

## 1. 状态图例

| 状态 | 含义 |
|------|------|
| 正式可用 | 从正常产品入口可达，并有真实运行链路 |
| 条件可用 | 需要平台、账号、权限、连接或打包环境 |
| 预览 | 已实现部分链路，但平台或发布承诺有限 |
| 隐藏 / 开发者 | 只通过 deep link 或开发模式使用，不属于普通导航 |
| Stub | 有壳、注册项或相邻实现，但核心链路不完整 |
| Coming Soon | 明确占位，不可作为工作功能 |
| Blocked | 代码保留接口或配置，但当前实现明确不可用 |

## 2. 当前重要状态

| 能力 | 当前状态 | 说明 |
|------|----------|------|
| 首页会话、专家、自动化、文件、市场 | 正式可用 | 仍需模型、工作区等基础前提 |
| 消息渠道 | 条件可用 | 微信、飞书、Telegram、Discord 需真实账号和平台 E2E |
| 企业 | 条件可用 | 仅连接 OnMyCompany 后显示 |
| 项目 | 隐藏 + Coming Soon | 主栏入口已隐藏；文件页「项目」分类仍不能作为正式项目管理使用 |
| 用量 | 隐藏 deep link | 当前不在设置普通导航中 |
| Debug / UI control | 开发者能力 | 不按普通用户功能宣传 |
| Windows 桌面 | 未签名开发者预览 | Computer Use 与 macOS 不完全等价 |
| Linux 桌面 | 非产品目标 | CI/沙箱使用 Linux 不等于客户端支持 |
| Postgres、DuckDB/Quack Archive | Blocked | 不应演示成已连接后端 |

## 3. 验证强度

| 结论 | 至少需要 |
|------|----------|
| UI 存在 | 真实页面截图或 DOM/导航证据 |
| 本地功能可用 | 实际启动、执行、持久化/恢复或产物验证 |
| 外部集成可用 | 真实平台请求与响应，必要时双向消息闭环 |
| 跨平台支持 | 对应平台构建/设备 smoke，不用另一平台推断 |

Typecheck、单元测试、Fake API、服务进程存活和 `WebSocket open` 都不能单独替代用户路径验证。

## 4. 版本与工作树

手册和视频应标注录制版本或 commit。若当前工作树包含未提交变更，画面可能与已发布安装包不同；正式发布前必须基于目标版本重跑截图和用户路径。
