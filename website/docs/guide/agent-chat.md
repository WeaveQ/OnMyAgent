# Agent 对话

**Agent 对话**是面向本机 **CLI / ACP 智能体** 的专用聊天入口：在 OnMyAgent 里直接对 Claude Code、Codex、OpenCode、OpenClaw、Hermes 等（以及自定义 Agent）下发任务，而不是走首页「通用会话」那条链路。

产品导航文案：左下账号菜单里的 **Agent 对话**（`nav.local_agent`）。

## 和「首页会话」有什么区别

| | 首页 [会话](./sessions) | **Agent 对话** |
|--|------------------------|----------------|
| 对话对象 | OnMyAgent 内置办公助手 | 本机已安装 / 已配置的 **本地 Agent**（CLI/ACP） |
| 典型用途 | 一句话派活、读写工作区、装技能专家后的日常办公 | 用本机 coding agent / 专用 CLI 做开发、排障、脚本与长跑任务 |
| 上下文 | 任务会话列表（最近任务） | **按 Agent 分会话**；切换 Agent 会换上下文窗口 |
| 入口 | 主栏 **首页** | 左下 **账号菜单 → Agent 对话** |

两者都会落在本机、都可能写文件；差别在**谁在执行**、以及审批/模型是否走该 Agent 的原生配置。

## 从哪里打开

1. 点击左下角 **账号 / 头像区**（齿轮上方常见入口）  
2. 菜单中选择 **Agent 对话**  

也可在 Agent 对话页内跳到 **管理 Agent**，进入 [Agent 管理](./agent-management) 修连接、装技能矩阵。

## 界面结构（概念）

| 区域 | 作用 |
|------|------|
| **Agent 列表 / 选择** | 选用某个本机 Agent；可筛选可用 / 离线 / 需登录 / 未安装 |
| **对话列表** | 该 Agent 下的多会话；支持 **新建对话**、继续历史 |
| **主对话区** | 消息时间线、运行状态、产物入口 |
| **输入区** | 给本地 Agent 发任务；支持换行、模型选择（若 Agent 支持覆盖） |
| **状态** | 在线 / 离线 / 需登录 / 未安装；可 **测试连接**、**重新检测** |

检测本机 Agent 时，常见目标包括 **OpenCode、Codex、OpenClaw、Hermes** 等；慢的检测不会无限阻塞其它结果。

## 能做什么

| 操作 | 说明 |
|------|------|
| 选 Agent 再聊 | 先选在线 Agent，再发任务；窗口只保留该 Agent 的上下文 |
| 新建 / 切换对话 | 同一 Agent 下开多个会话，避免话题混在一起 |
| 发任务 | 自然语言描述目标；可绑定工作区目录（按界面选择） |
| 切换模型 | 若 Agent 支持模型覆盖，可在页内改目标模型 |
| 审批 | 底层 Agent 发起审批时，可在对话中 **允许一次 / 本会话允许 / 拒绝** |
| 看产物 | 运行结果中的文件变化可打开；也可到 [文件](./files) 验收 |
| 定时任务 | 部分 Agent 支持按间隔对**当前选中对话**发送固定 prompt（心跳式任务） |

### 审批模式（概念）

在本地 Agent 侧常见策略（具体选项以产品文案为准）：

| 模式 | 含义 |
|------|------|
| **自动批准** | 自动同意 Agent 原生审批，适合无人值守 |
| **原生请求时询问**（推荐默认） | 仅当底层 Agent 请求审批时弹出确认 |
| **只读自动** | 明确只读请求自动放行；写入 / 命令 / 高风险仍询问 |

更广的权限与确认说明见 [审批与权限](./approvals)。

## 使用建议

1. **先保证 Agent 健康**：离线或「需登录」时，先 [Agent 管理](./agent-management) 里测试连接 / 登录 / 修复。  
2. **一个对话一个目标**：长跑任务单独开会话，方便归档与定时任务绑定。  
3. **权限按任务收紧**：写仓库、装依赖、改系统配置前用「询问」类模式。  
4. **产物回文件区核对**：不要只依赖对话气泡里的摘要。  
5. **与首页分工**：日常办公派活优先首页会话；要调用本机 coding CLI 时用 Agent 对话。

## 常见状态

| 状态 | 含义 | 建议 |
|------|------|------|
| 在线 / 健康 | 可对话 | 直接发任务 |
| 离线 | 无法建立 ACP/CLI 会话 | 查环境、网络与配置后重测 |
| 需登录 | CLI 未授权 | 在对应 CLI 完成登录后「重新检测」 |
| 未安装 | 找不到可执行文件 | 按安装引导安装 CLI，或纳入管理后再用 |
