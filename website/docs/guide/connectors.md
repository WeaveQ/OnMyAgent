# 连接器与托管工具

连接器让 Agent 访问外部应用、云文档或本机命令行工具。OnMyAgent 中的“连接器”并非只有一种技术，配置和权限边界也不同。

产品入口：**市场 → 连接器**；部分工具也会出现在设置、技能或会话能力菜单中。

![市场 · 连接器](/images/marketplace-connectors.png)

<p class="oma-shot-caption">连接器目录。飞书/企微等条目是连接能力，不等于对应消息渠道已经能收发。</p>

## 1. 四类扩展不要混淆

| 类型 | 作用 | 常见管理位置 |
|------|------|--------------|
| MCP | 用标准协议向 Agent 暴露工具和资源 | 市场 / 设置 / 会话能力 |
| 托管工具 | OnMyAgent 帮你检测、下载或连接本机 CLI | 连接器详情页 |
| 云服务连接器 | 通过 OAuth、Token、验证码或服务 API 访问云数据 | 连接器详情页 |
| 消息渠道 | 从 IM 接收任务并把结果回复原聊天 | 主栏 **消息渠道** |

“飞书连接器”可以用于文档或开放平台工具；“飞书消息渠道”用于聊天收发。两者都配置成功，才表示两条链路分别可用。

## 2. 当前常见托管能力

产品代码包含 OfficeCLI、Lark CLI、腾讯文档、百度网盘、金山文档、钉钉、企业微信和腾讯会议等连接入口。它们的实际可用性取决于平台、网络、账号、工具安装状态和当前版本。

| 类型 | 可能需要 |
|------|----------|
| 本机 CLI | 下载或找到可执行文件、版本检测、登录状态 |
| OAuth | 浏览器授权、回调成功、允许的 scope |
| Token / App 凭据 | 平台控制台创建应用并保存密钥 |
| 验证码 / 扫码 | 用户在平台侧完成一次人工确认 |
| 企业服务 | 组织管理员开放应用、文档或网关权限 |

源码或市场里出现一个插件，不等于本机已经安装，也不等于当前账号能访问真实云数据。

## 3. 安装与连接

1. 打开连接器详情，先阅读平台、账号和权限要求。
2. 检测本机工具；如需下载，核对来源、版本和安装路径。
3. 完成 OAuth、Token、扫码或验证码登录。
4. 运行连接测试；测试应访问一个专门的无敏感资源。
5. 回到会话，确认连接器只在需要时出现在能力菜单中。

安装托管 CLI 会改变本机工具状态。断开账号与卸载工具是两个不同动作，不要把“断开”当成清理所有本地文件。

## 4. 在会话中使用

- 用自然语言说明目标和目标平台，例如“读取测试文件夹里的文档并生成摘要”。
- 第一次调用时检查 Agent 准备使用哪个连接器、哪个账号和哪个资源。
- 写入、发布、共享或外发前保留审批。
- 产物应回到工作区或文件页独立验收，不能只相信工具调用成功提示。

## 5. 权限与凭据

- 只授权任务需要的最小 scope。
- API Key、Token、Cookie 和验证码不得出现在公开视频、调试报告或 Git diff 中。
- 企业 Gateway 的真实凭据不应返回桌面进程。
- 连接器配置变化可能触发运行时 reload；正在运行的任务可能需要重新打开或重试。

## 6. 常见状态

| 状态 | 含义 | 下一步 |
|------|------|--------|
| 未安装 | 本机没有所需 CLI/组件 | 核对平台后安装或选择别的实现 |
| 已安装未登录 | 工具存在，没有可用会话 | 完成平台登录 |
| 已连接 | 认证检查成功 | 再做一个真实、只读资源测试 |
| 需要授权 | OAuth/验证码/扫码未完成 | 在平台侧人工确认 |
| 连接失败 | 网络、凭据、scope 或版本不匹配 | 查看脱敏错误和平台控制台 |
| 已断开 | OnMyAgent 不再使用当前账号 | 如需彻底清理，按该工具说明单独处理 |
