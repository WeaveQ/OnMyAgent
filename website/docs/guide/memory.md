# 记忆与个人

用于沉淀跨会话的**个人偏好、人设与可确认的记忆**（工程上对应 awareness / 工作记忆路径）。

## 能存什么

- 称呼、沟通风格、固定指令  
- 工作习惯与手册类说明  
- Agent 学到的、经你确认的条目（视版本能力）  

## 原则

- 记忆正文在**本机**路径，便于审计  
- 危险删除/清空操作会有确认  
- 与「单次会话上下文」不同：记忆跨任务生效  

## 入口

在 [设置](./settings) 中的 **个人 / 记忆** 相关页（以当前版本菜单为准）。
