# 记忆与个人

跨会话生效的**个人偏好、人设与事实记忆**，都在 [设置](./settings) 的 **个人** 分组里。

## 个人

告诉助手你是谁、希望怎么被称呼、默认怎么说话。

![设置 · 个人](/images/settings-memory.png)

| 区块 | 用途 |
|------|------|
| **个人信息** | 你的名字、助手名字 |
| **个性** | 语气（如高效务实）、自定义指令（始终注入的协作规则） |
| **用户画像** | MBTI、职业角色等可选信息，贴合工作语境 |

自定义指令适合写：默认中文、先结论后细节、涉及代码先给结论等固定规矩。

## 记忆

管理对话中提炼或手动维护的事实记忆，以及本机记忆文件。

![设置 · 记忆](/images/settings-conversation-memory.png)

| 能力 | 说明 |
|------|------|
| **启用工作记忆** | 已保存的长/短期记忆会注入后续主会话 |
| **自动写入** | 对话中匹配到的要点自动写入记忆（可关） |
| **本机记忆文件** | 协作风格、工作手册、用户画像、长期记忆等，仅存本机，可在文件夹中直接编辑 |

路径示例：本机用户目录下的 OnMyAgent 数据区（界面中有「打开所在文件夹」）。

## 原则

- 记忆与人设正文在**本机**，便于审计与备份  
- 与「单次会话上下文」不同：这里跨任务生效  
- 危险清空类操作会有确认
