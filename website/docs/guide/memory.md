# 记忆与个人

跨会话生效的**个人偏好、人设与事实记忆**，都在 [设置](./settings) 的 **个人** 分组里。

## 1. 个人

告诉助手你是谁、希望怎么被称呼、默认怎么说话。



![设置 · 个人](/images/settings-memory.png)

| 区块 | 用途 |
|------|------|
| **个人信息** | 你的名字、助手名字 |
| **个性** | 语气（如高效务实）、自定义指令（始终注入的协作规则） |
| **用户画像** | MBTI、职业角色等可选信息，贴合工作语境 |

自定义指令适合写：默认中文、先结论后细节、涉及代码先给结论等固定规矩。

## 2. 记忆

管理对话中提炼或手动维护的事实记忆，以及本机记忆文件。



![设置 · 记忆](/images/settings-conversation-memory.png)

| 能力 | 说明 |
|------|------|
| **启用工作记忆** | 已保存的长/短期记忆会注入后续主会话 |
| **自动写入** | 对话中匹配到的要点自动写入记忆（可关） |
| **本机记忆文件** | 协作风格、工作手册、用户画像、长期记忆等，仅存本机，可在文件夹中直接编辑 |

路径以界面当前显示和“打开所在文件夹”为准。运行态 session/cache/log 应位于应用数据或专用 runtime 根，不应写进项目仓库；工作记忆正文与任务产物也要分开管理。

## 3. 和会话上下文、Archive 的区别

| | 作用 | 是否自动跨任务 |
|--|------|----------------|
| 当前会话上下文 | 当前任务里的消息、工具结果和附件 | 否，受上下文窗口限制 |
| 个人 / 工作记忆 | 用户偏好、长期事实和协作规则 | 是，启用后可注入后续主会话 |
| Session Archive | 已知来源的历史会话、搜索、分析和导入 | 保存历史，但不等于自动注入每次 prompt |
| Personal Agent 原生记忆 | Codex/Claude/Hermes 等各自维护的机制 | 由对应 Agent 决定，OnMyAgent 不应冒充统一存储 |

## 4. 自动写入与审阅

自动写入开启后，仍应定期检查错误、过时或不该长期保存的事实。对密码、Token、验证码、医疗/财务隐私和客户机密，不要依赖自动提炼来判断是否可保存。

## 5. 原则

- 记忆与人设正文在**本机**，便于审计与备份  
- 与「单次会话上下文」不同：这里跨任务生效  
- 危险清空类操作会有确认  
- 企业策略或个人记忆不能覆盖系统安全边界与组织 deny。
- 备份前确认文件是否包含隐私；公开视频只使用虚构 demo 画像。
