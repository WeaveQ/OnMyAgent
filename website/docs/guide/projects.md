# 项目（预告）

**项目目前不是可用的正式模块。** 主栏中的项目入口和文件页中的项目分类仍是 Coming Soon / 禁用状态。

## 1. 当前能做什么

目前请用以下正式能力组织工作：

- 用 [工作区](./workspaces) 隔离不同客户或主题的文件；
- 用 [会话](./sessions) 保持单个交付目标的上下文；
- 用 [专家](./experts) 固定岗位能力；
- 用 [自动化](./automation) 固化重复执行；
- 用 [文件与产物](./files) 验收任务和专家文件。

## 2. 为什么手册仍保留此页

源码中出现路由名、图标、Tab 或占位文案，并不等于产品功能已经完成。本页用于明确状态，避免把可见占位误写成已交付能力。
