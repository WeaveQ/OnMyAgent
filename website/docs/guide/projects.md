# 项目（预告）

**项目目前不是可用的正式模块。** 主栏**不再显示**项目入口（书签或深链会回到首页）。文件页里的 **项目** 分类仍是 Coming Soon / 禁用，不能当项目管理用。

## 1. 当前能做什么

目前请用以下正式能力组织工作：

- 用 [工作区](./workspaces) 隔离不同客户或主题的文件；
- 用 [会话](./sessions) 保持单个交付目标的上下文；
- 用 [专家](./experts) 固定岗位能力；
- 用 [自动化](./automation) 固化重复执行；
- 用 [文件与产物](./files) 验收任务和专家文件。

## 2. 为什么手册仍保留此页

源码中出现路由名、图标、Tab 或占位文案，并不等于产品功能已经完成。主栏入口已拿掉，避免把它当成可用模块；本页仍保留，用来说明文件页分类和深链的真实状态。
