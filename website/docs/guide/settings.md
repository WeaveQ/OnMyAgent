# 设置

集中管理模型、外观、Agent、更新与可选的公司连接。

## 打开方式

点击左下角 **齿轮**，展开菜单：

![设置菜单：外观、设置、更新等](/images/settings.png)

常见项：

| 项 | 说明 |
|----|------|
| **设置** | 进入完整设置页（模型、工作区、权限等） |
| **外观** | 浅色 / 深色 |
| **Agent 管理 / Agent 对话** | 管理本机 Agent 相关入口 |
| **检查更新** | 桌面更新 |
| **退出程序** | 退出应用 |

## 建议优先配置

1. 工作区路径  
2. 默认模型（BYOK）  
3. 权限与通知偏好  
4. （可选）[连接公司](../platform/onmycompany)
