# 设置

完整设置页用于管理模型、公司连接、个人画像、外观偏好、系统与运行环境、更新与数据。进入后左侧是分组导航，右侧是当前分区内容。

## 打开方式

任选其一：

1. 左下角 **齿轮** → 菜单里点 **设置**
2. 快捷键 **⌘ ,**（macOS）/ **Ctrl ,**（Windows）

![齿轮菜单入口](/images/settings.png)

菜单里还会有外观切换、Agent 管理、检查更新、退出等快捷项；**完整配置请进入设置页**。

## 设置总览

进入后默认落在 **总览**：按「工作区 / 个人与记忆 / 全局 / 数据」列出所有分区，点卡片即可跳转。

![设置总览](/images/settings-page.png)

| 分组 | 分区 | 用途 |
|------|------|------|
| （顶栏） | **总览** | 所有设置项入口预览 |
| 工作区 | **模型** | 连接 / 管理 AI 模型服务商 |
| 工作区 | **公司** | 连接 OnMyCompany，同步组织技能与专家 |
| 个人与记忆 | **个人** | 名字、语气、自定义指令、职业画像 |
| 个人与记忆 | **记忆** | 对话提炼的事实记忆与本机记忆文件 |
| 全局 | **偏好** | 语言、主题、字体、对话宽度、会话压缩等（应用级，非工作区） |
| 全局 | **系统设置** | 开机自启、通知、系统权限；**本机运行环境与环境变量** 也在此页 |
| 全局 | **快捷键** | 自定义通用 / 任务 / 会话快捷键 |
| 全局 | **更新** | 版本号与检查更新 |
| 数据 | **用量** | 跨工作区 Token 用量与活跃度 |
| 数据 | **重置** | 重置入门引导或清除本地应用数据 |
| 数据 | **归档** | 已归档会话的恢复与删除 |

说明：

- **偏好** 在 **全局**，不在工作区（语言 / 主题等全应用生效）。
- 旧路径 `/settings/environment`、`/settings/permissions` 等仍可用，会进入 **系统设置**（环境已并入系统，不再单独占一行导航）。

左侧 **返回应用** 可退出设置，回到主界面。

## 工作区

### 模型

连接并管理 AI 模型服务商（BYOK / 本地 / 自定义）。

![模型](/images/settings-ai.png)

- 查看已连接服务商与可用模型数量  
- **连接模型服务商** / **自定义模型服务商配置**  
- 编辑或删除已添加的服务商  

详见 [模型](./models)。

### 公司

连接 [OnMyCompany](../platform/onmycompany)，同步组织内的技能与专家。

![公司](/images/settings-company.png)

填写服务地址，用企业邮箱 + 验证码登录；可用 **探活** 检查服务是否可达。

## 个人与记忆

### 个人

告诉助手「你是谁、希望怎么被称呼、默认怎么说话」。

![个人](/images/settings-memory.png)

- **个人信息**：你的名字、助手名字  
- **个性**：语气（如高效务实）、自定义指令（始终生效的协作规则）  
- **用户画像**：MBTI、职业角色等可选信息，帮助贴合工作语境  

### 记忆

管理对话中提炼或手动添加的事实记忆，以及本机记忆文件。

![记忆](/images/settings-conversation-memory.png)

- **启用工作记忆** / **自动写入**：控制是否把对话要点写入长期记忆  
- **本机记忆文件**：协作风格、工作手册、用户画像、长期记忆等，可在文件夹中直接编辑  

详见 [记忆](./memory)。

## 全局

### 偏好

语言、主题、字体与面板布局等应用级个性化选项（**不属于工作区**）。

![偏好](/images/settings-preferences.png)

常见项：

- **界面**：语言、主题（浅色 / 深色 / 跟随系统）
- **显示**：字体大小、对话宽度、是否展开模型推理轨迹、系统托盘图标
- **会话管理**：自动上下文压缩、长时间未对话自动新起会话等

### 系统设置

开机自启、通知、系统级权限，以及本机运行环境。

![系统设置](/images/settings-system.png)

- **应用选项**：开机自动启动、保持系统唤醒、桌面 / 任务完成 / 声音通知  
- **系统授权**：完全磁盘访问、屏幕录制、辅助功能、麦克风等（应用快照、自动化、通知依赖这些权限）  
- **本机环境**（原独立「环境」分区，现并入本页）：OpenCode 运行时、Node.js、Python 等安装状态；本机 API 密钥环境变量（仅存本机；`ONMYAGENT_` / `OPENCODE_` 为系统保留前缀）

![环境（系统设置内）](/images/settings-environment.png)

### 快捷键

自定义通用、任务与会话操作的快捷键。

![快捷键](/images/settings-shortcuts.png)

默认示例（可改）：

| 命令 | 默认 |
|------|------|
| 打开设置 | ⌘ , |
| 全局快捷对话 | ⌘ B |
| 切换侧栏 | ⌘ \\ |
| 创建新任务 | ⌘ N |
| 在当前任务中搜索 | ⌘ F |
| 发送消息 | ⌘ ↩ |
| 插入换行 | Shift ↩ |
| 捕获桌面 | ⌘ Shift A |

支持搜索与「全部恢复默认」。

### 更新

查看当前版本并检查更新。

![更新](/images/settings-updates.png)

显示当前版本号与 **检查更新**。桌面版通常通过 [GitHub Releases](https://github.com/WeaveQ/OnMyAgent/releases) 下载对应平台安装包。

## 数据

### 用量

跨工作区的 Token 用量与活跃度。进入后会先显示本地账号摘要，再异步拉取统计；截图为加载中状态（界面文案「正在加载用量…」），加载完成后会展示用量数据。

![用量页（加载中示意）](/images/settings-usage.png)

### 重置

重置首次引导或清除本地应用数据（确认后应用会重启）。

![重置](/images/settings-recovery.png)

| 操作 | 说明 |
|------|------|
| **重置入门** | 清除本地偏好与个人画像，重新进入引导；**工作区保留** |
| **重置应用数据** | 彻底清除本机 OnMyAgent 应用数据与偏好；**不会**删除 Claude / Codex / OpenCode 等 CLI 自身配置；需输入确认词 |

### 归档

管理会话归档策略，以及已归档任务的恢复与删除。

![归档](/images/settings-archived.png)

可按项目筛选、搜索已归档任务，并支持取消归档或永久删除。

## 建议优先配置

1. **模型**：接好默认服务商与密钥  
2. **偏好**（全局）：语言 / 主题 / 字体  
3. **个人**：名字与自定义指令  
4. **系统设置**：通知、必要权限，以及本机运行环境 / 业务 API 密钥  
5. （可选）**公司**：连接组织
