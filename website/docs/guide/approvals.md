# 审批与权限

本机 Agent 可能读写文件、执行命令或驱动浏览器/桌面。通过会话里的**权限模式**与执行中的**审批确认**控制风险。

## 在哪里切换权限

会话 / 任务输入区**底部工具栏**：

| 控件 | 作用 |
|------|------|
| **权限**（如「默认权限」） | 控制自动执行与敏感步骤是否需你确认 |
| **模型** | 选择当前会话模型（与权限独立） |
| `+` / 附件等 | 附加上下文（与权限模式配合使用） |

![主界面输入区：底部可见权限与模型选择](/images/home-session.png)

更严格的模式会在敏感步骤打断你，而不是静默执行。具体选项文案以输入区下拉为准。

## 系统级权限（另一层）

部分能力依赖操作系统授权（磁盘、屏幕录制、辅助功能、麦克风等），在 [设置 → 系统设置](./settings#系统设置) 中查看与引导授权。那是「系统是否允许应用访问」，与会话里的权限模式不同。

## 何时会打断你

常见会要求确认的情况包括：

- 删除 / 覆盖重要文件  
- 执行系统命令  
- 访问未授权路径  
- 其他产品标记为高风险的本机或外发动作  

被打断时：阅读说明 → 允许或拒绝 → 再继续对话。

## 组织策略

若已连接 [OnMyCompany](../platform/onmycompany)（设置 → **公司**）：

- 桌面应服从组织策略，**不得在本机擅自放宽**  
- 部分外发可能需企业 Gateway  

未连接公司时，仅本机审批与权限模式生效。密钥仍不要贴进聊天，见 [安全与数据](../security)。

## 建议

| 场景 | 建议 |
|------|------|
| 探索 / 草稿 | 可用较宽松权限，但仍指定输出路径 |
| 改生产相关文件 | 收紧权限，逐步确认 |
| 自动化定时任务 | 先手动跑通，再启用；提示词避免无范围删除 |
