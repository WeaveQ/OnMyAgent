# 审批与权限

本机 Agent 可能读写文件、执行命令或驱动浏览器/桌面。通过**权限模式**与**审批确认**控制风险。

## 权限模式

在会话输入区可切换权限相关选项（如默认权限等，以 UI 文案为准）。更严格的模式会在敏感步骤要求确认。

![会话输入区的权限与模型](/images/home-session.png)

## 何时会打断你

- 删除/覆盖重要文件  
- 执行系统命令  
- 访问未授权路径  
- 其他产品标记为高风险的动作  

## 组织策略

若已连接 [OnMyCompany](../platform/onmycompany)：

- 桌面应服从组织策略，**不得在本机擅自放宽**  
- 部分外发可能需企业 Gateway  

未连接公司时，仅本机审批规则生效。
