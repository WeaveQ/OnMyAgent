# 自动化

自动化用于**定时**办公任务：日报周报、提醒、汇总等，无需每次手动打开会话。

![自动化：任务列表、模板与调度详情](/images/automation.png)

## 界面结构

| 区域 | 作用 |
|------|------|
| 主栏 **自动** | 进入自动化 |
| 中栏 | **全部任务**、**推荐模板**、已创建的定时任务列表 |
| 右侧 | 当前任务详情：启用状态、提示词、调度时间、运行次数 |
| 顶栏 | **+ 添加** / **从模板添加** |

## 典型场景

- 每个工作日早晨汇总待办或业务早报  
- 每周五生成周报草稿  
- 固定时间检查某类文件是否更新  

## 使用步骤

1. 打开主栏 **自动**  
2. **从模板添加** 或 **+ 添加** 新建  
3. 写清：触发时间、提示词、输出位置（建议固定到工作区路径）  
4. 确认任务为 **已启用**  
5. 在运行历史中查看成败与产物（可到 [文件](./files) 验收）  

## 建议

- 先在普通 [会话](./sessions) 里手动跑通同一提示词，再交给自动化  
- 输出路径固定，便于查找  
- 涉及外发或高风险动作时配合 [审批](./approvals)
