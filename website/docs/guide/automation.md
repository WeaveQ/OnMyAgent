# 自动化

自动化用于**定时或触发**的办公任务：日报周报、提醒、汇总等，无需每次手动打开会话。

![自动化相关界面](/images/automation.png)

## 典型场景

- 每个工作日早晨汇总待办  
- 每周五生成周报草稿  
- 固定时间检查某类文件是否更新  

## 使用要点

1. 在 **自动** 主栏创建或管理任务  
2. 写清触发条件、提示词、输出位置  
3. 在运行历史中查看成败与产物  

## 建议

- 先手动跑通同一提示词，再交给自动化  
- 输出路径固定，便于 [文件](./files) 中查找  
- 涉及外发或高风险动作时配合 [审批](./approvals)
