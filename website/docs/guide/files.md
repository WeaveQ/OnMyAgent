# 文件与产物

文件页管理**工作区内的资料与 AI 产物**：导入、浏览、搜索、预览与外编。

![文件：类型筛选与列表](/images/files-list.png)

## 1. 顶部分类

常见 Tab：

| Tab | 含义 |
|-----|------|
| **文件 / 我的文件** | 用户导入到工作区的资料 |
| **任务** | 任务过程中产生的文件（历史兼容浏览） |
| **专家** | 专家会话相关产物 |
| **项目** | 按项目空间组织的内容 |

> 产品以「来源」区分展示，避免把用户上传与 AI 生成混为一谈。

## 2. 常见操作

| 操作 | 说明 |
|------|------|
| 导入 / 上传 | 将本机文件复制进工作区 |
| 搜索 | 按名称过滤文件或文件夹 |
| 类型筛选 | 表格、幻灯片、图片等 |
| 打开 / 预览 | 应用内预览或系统应用打开 |
| 排序 | 名称、类型、更新时间、大小 |

## 3. 与 Agent 协作

1. 先把资料导入工作区  
2. 在会话中 `@` 引用或描述路径  
3. 生成结果后回文件页验收  

## 4. 注意

- 默认改的是**工作区副本**，不是随意改你磁盘上任意路径  
- 大文件（如 pptx）请留意磁盘与同步工具占用
