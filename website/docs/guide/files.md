# 文件与产物

文件页管理**工作区内的资料与 AI 产物**：导入、浏览、搜索、预览与外编。



![文件：类型筛选与列表](/images/files-list.png)

## 1. 顶部分类

常见 Tab：

| Tab | 含义 |
|-----|------|
| **文件 / 我的文件** | 用户导入到工作区的资料 |
| **任务** | 已带任务来源标记、可回溯到主会话的文件 |
| **专家** | 专家会话相关产物 |
| **项目** | 当前禁用 / Coming Soon，不是可用分类 |

> 产品正在收敛三类来源。当前本地 Agent 和自动化产物并不一定都能归入“任务”来源；找不到时请同时检查工作区目录和对应运行历史。

## 2. 常见操作

| 操作 | 说明 |
|------|------|
| 导入 / 上传 | 将本机文件复制进工作区 |
| 搜索 | 按名称过滤文件或文件夹 |
| 类型筛选 | 表格、幻灯片、图片等 |
| 打开 / 预览 | 应用内预览或系统应用打开 |
| 排序 | 名称、类型、更新时间、大小 |
| 新建文件夹 | 在当前授权目录创建文件夹 |
| 收藏 | 把常用文件标记为收藏 |
| 移动 | 在工作区允许范围内移动 |
| 复制路径 | 获得工作区路径，供会话引用 |
| 加入任务 | 把文件带入主会话上下文 |
| 让 Agent 处理 | 从文件直接发起相关任务 |
| 查看来源会话 | 回到创建该产物的已知会话 |
| 删除 | 需要确认；先区分工作区副本和原始文件 |

## 3. 预览与打开方式

| 类型 | 常见处理 |
|------|----------|
| Markdown / 文本 / 代码 | 应用内阅读，部分支持语法或 diff 展示 |
| 图片 | 应用内预览 |
| HTML / 网页产物 | 安全预览或浏览器打开，视内容而定 |
| 表格 | 应用内表格预览或交给系统应用 |
| Word / 演示 / PDF | 使用产品预览能力；不支持时外部打开或下载 |
| 音频 / 视频 | 使用原生媒体预览或系统播放器 |

预览成功不等于文件内容正确。重要文档、表格和演示应使用独立应用重新打开，并检查页数、公式、字体、图表和媒体播放。

## 4. 与 Agent 协作

1. 先把资料导入工作区  
2. 在会话中 `@` 引用或描述路径  
3. 生成结果后回文件页验收。
4. 需要修改时，从来源会话继续，或用“让 Agent 处理”新开明确任务。

不要只告诉 Agent“处理这个文件”；同时说明目标输出、不能改变的内容、保存位置和验收方式。

## 5. 文件安全与冲突

- 导入通常处理的是**工作区副本**，不是随意修改磁盘任意路径。
- Server 只允许授权根内的路径；只读模式、协作者权限和审批可能阻止写入。
- 写入、改名、删除和批量操作使用 revision/冲突保护时，文件已经变化会要求重新读取，而不是盲目覆盖。
- 大文件请留意磁盘、远程上传时间和同步工具占用；不支持内联预览时改用下载或系统应用。
- 不要把 token、`.ssh`、浏览器 Profile、客户原件或系统目录复制进公开视频的演示工作区。

## 6. 来源和恢复限制

- “任务”来源主要对应 OpenCode 主会话及已完成的来源打标。
- Personal Local Agent 使用独立 conversation store；其产物不会自动变成主 Session Archive 的文件记录。
- 自动化使用独立任务目录和运行历史；文件页暂时可能无法完整表达所有来源。
- 删除文件、归档任务、删除会话和清空归档是四种不同动作，恢复边界也不同。
