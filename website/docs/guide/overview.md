# 界面与工作区

了解主界面分区，才能快速找到「派活、看文件、装能力、改设置」。

## 1. 整体布局



![主界面布局：主栏、最近会话、欢迎与输入区](/images/home-session.png)

| 区域 | 作用 |
|------|------|
| **左侧主栏** | 首页 / 专家 / 自动 / 文件 / 市场 / 企业（连接后）/ 项目（预告） |
| **中栏列表** | 最近任务/会话，或文件树、市场筛选 |
| **主内容区** | 对话、文件表格、专家卡片等 |
| **输入区** | 自然语言、`@` 引用、`/` 技能、模型与权限 |
| **主栏底部** | **消息渠道**，以及账号菜单（Agent 管理 / Agent 对话、设置、外观等） |

## 2. 工作区（Workspace）

工作区可以是本机文件夹，也可以连接远程 OnMyAgent Server。它作为：

- Agent 读写的默认范围  
- 导入文件的落点（通常复制为工作区副本）  
- 产物归档位置  

本地与远程创建、重命名、分享、授权和安全边界见 [工作区](./workspaces)。在 [设置](./settings) 中可配置模型、公司连接与全局偏好等。

## 3. 市场

市场用于浏览与安装 **专家 / 技能 / 连接器**：

![市场：专家卡片与分类](/images/marketplace.png)



顶栏切换 **专家 · 技能 · 连接器**；可按行业分类筛选与搜索。连接器包含 MCP、托管 CLI 和云服务等不同实现，见 [连接器与托管工具](./connectors)。

## 4. 条件入口与状态

| 入口 | 当前状态 |
|------|----------|
| **企业** | 只有成功连接 OnMyCompany 后才出现；本地模式无需登录 |
| **项目** | Coming Soon，占位入口，不是可用的项目管理模块 |
| **消息渠道** | 位于主栏底部；微信、飞书、Telegram、Discord 需真实账号和平台权限 |

详见 [企业连接](./company)、[项目（预告）](./projects)、[消息渠道](./channels) 和 [功能与平台状态](./capability-status)。

## 5. 设置入口

- 左下角 **齿轮** → 菜单中点 **设置**（完整设置页）  
- 或快捷键 **⌘ ,**（macOS）/ **Ctrl ,**（Windows）  

账号菜单里还有：

| 入口 | 说明 |
|------|------|
| **Agent 管理** | 本机 CLI/ACP 智能体舰队、连接与技能矩阵，见 [Agent 管理](./agent-management) |
| **Agent 对话** | 直接对本机 Agent 下发任务，见 [Agent 对话](./agent-chat) |
| **设置** | 完整设置页（模型、偏好、公司等） |
| 外观 | 浅色 / 深色 |
| 检查更新、退出 | 有新版本时点提示才会开始下载 |



![齿轮菜单](/images/settings.png)

进入后默认是设置 **总览**，左侧按工作区（模型 / 公司）、个人、全局（偏好 / 系统 / 快捷键 / 更新）、数据分组。本机环境已并入 **系统设置**。详见 [设置](./settings)。

![设置总览](/images/settings-page.png)
