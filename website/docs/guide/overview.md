# 界面与工作区

了解主界面分区，才能快速找到「派活、看文件、装能力、改设置」。

## 整体布局

![首页布局：主栏、会话列表、对话区](/images/home-session.png)

| 区域 | 作用 |
|------|------|
| **左侧主栏** | 首页 / 专家 / 自动 / 文件 / 市场 / 项目 |
| **中栏列表** | 最近任务/会话，或文件树、市场筛选 |
| **主内容区** | 对话、文件表格、专家卡片等 |
| **输入区** | 自然语言、`@` 引用、`/` 技能、模型与权限 |
| **左下** | Agent 对话入口、设置菜单 |

## 工作区（Workspace）

工作区是本机文件夹，作为：

- Agent 读写的默认范围  
- 导入文件的落点（通常复制为工作区副本）  
- 产物归档位置  

在设置中可切换或重新选择工作区路径。
