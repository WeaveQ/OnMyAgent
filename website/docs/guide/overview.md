# 界面与工作区

了解主界面分区，才能快速找到「派活、看文件、装能力、改设置」。

## 整体布局

![首页布局：主栏、会话列表、对话区](/images/home-session.png)

| 区域 | 作用 |
|------|------|
| **左侧主栏** | 首页 / 专家 / 自动 / 文件 / 市场 / 项目 |
| **中栏列表** | 最近任务/会话，或文件树、市场筛选 |
| **主内容区** | 对话、文件表格、专家卡片等 |
| **输入区** | 自然语言、`@` 引用、`/` 技能、模型与权限 |
| **左下** | Agent 对话入口、设置（齿轮） |

## 工作区（Workspace）

工作区是本机文件夹，作为：

- Agent 读写的默认范围  
- 导入文件的落点（通常复制为工作区副本）  
- 产物归档位置  

在 [设置](./settings) 中可配置模型、公司连接与全局偏好等；首次启动会引导选择工作区文件夹。

## 市场

市场用于浏览与安装 **专家 / 技能 / 连接器**：

![市场：专家卡片与分类](/images/marketplace.png)

顶栏切换 **专家 · 技能 · 连接器**；可按行业分类筛选与搜索。

## 设置入口

- 左下角 **齿轮** → 菜单中点 **设置**（完整设置页）  
- 或快捷键 **⌘ ,**（macOS）/ **Ctrl ,**（Windows）  

齿轮菜单里还有外观（浅/深色）、Agent 管理、检查更新、退出等快捷项。

![齿轮菜单](/images/settings.png)

进入后默认是设置 **总览**，左侧按工作区（模型 / 公司）、个人、全局（偏好 / 系统 / 快捷键 / 更新）、数据分组。本机环境已并入 **系统设置**。详见 [设置](./settings)。

![设置总览](/images/settings-page.png)
