# 技能（Skills）

技能是可安装的**能力包**：封装脚本、工作流或专用提示，让 Agent 在授权下完成具体动作。

## 在哪里管理

1. 打开 **市场**  
2. 切换到 **技能** Tab  
3. 浏览、搜索、安装  

![从市场进入技能等能力](/images/marketplace.png)

也可在对话中使用 `/` 唤起技能与指令（以当前版本 UI 为准）。

## 典型用途

- 办公文档处理、固定格式输出  
- 浏览器自动化、搜索与抓取（视已安装技能而定）  
- 领域流程（与专家配合）  

## 使用建议

| 建议 | 原因 |
|------|------|
| 安装来源可信 | 技能可执行动作，注意权限 |
| 提示词写明「用哪个技能」 | 提高调用成功率 |
| 先小范围试跑 | 避免一次授权过大范围 |
