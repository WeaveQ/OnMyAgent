# 技能（Skills）

技能是可安装的**能力包**：封装工具调用、工作流或专用提示，让 Agent 在授权下完成具体动作（读网页、处理办公文件、做自动化等）。

本文说明：如何安装与调用，以及常见「浏览器 / 办公 / 搜索 / 找技能」等能力在 OnMyAgent 里**叫什么、怎么用**。

## 在哪里管理

1. 打开主栏 **市场**  
2. 顶栏切换到 **技能** Tab  
3. 浏览、搜索、安装（部分为**内置/捆绑**，安装后即可用）  

![市场：专家 / 技能 / 连接器](/images/marketplace.png)

也可在对话输入框用 **`/`** 唤起技能与指令。

## 怎么调用

| 方式 | 说明 |
|------|------|
| 自然语言 | 直接说目标（如「打开这个网页并截图摘要」），Agent 会匹配已装技能 |
| `/` 指令 | 显式点名技能或工作流 |
| 先找再干 | 用 **Find Skills** 类能力问「我该用哪个技能」 |

**建议：** 安装来源可信；敏感动作配合 [审批](./approvals)；先小范围试跑再批处理。

## 常见能力对照（上手优先）

下表按**任务类型**对照 OnMyAgent **当前产品能力**（内置技能、市场插件或等价入口）。

| 任务类型 | 作用（摘要） | OnMyAgent 对应 | 状态 | 怎么用 |
|----------|--------------|----------------|------|--------|
| **浏览器操作** | 打开页、滚动、点击、截图、读内容 | **browser-automation**（应用内浏览器）+ **browser-skill**（本机 Chrome/Edge + 扩展） | ✅ 具备（双路径） | 见下文 [浏览器](#浏览器-agent-browser) |
| **办公文档** | PDF / DOCX / PPTX / XLSX 读写生成 | **document-processing** + **pptx** + 可选 **OfficeCLI** 插件 | ✅ 具备 | 见 [办公文档](#办公文档四件套) |
| **语音转写** | 本地语音转文字 | 无同名捆绑技能；可走连接器/外部 ASR 或市场技能 | ⚠ 无内置同款 | 会议纪要可先转写再 [报告与纪要](../scenarios/office-docs) |
| **视频下载** | 下载视频/音频/字幕并摘要 | 无同名捆绑；注意版权与平台 ToS | ⚠ 无内置同款 | 勿默认爬取受版权内容；摘要可对已有本地文件进行 |
| **联网搜索** | 先搜索再整理 | 依赖模型联网或 **MCP / 连接器** 中的搜索类服务 | ⚠ 非单一捆绑名 | 见 [联网搜索](#联网搜索-web-search) |
| **本地知识库** | 读写笔记目录 | 工作区可指向笔记库；记忆/本机 md 可编辑 | △ 等价路径 | 将库目录设为工作区或 `@` 路径；见 [记忆](./memory) |
| **技能安全** | 安装前审查第三方 Skill | 市场与安装来源提示；无独立 scanner 捆绑名 | △ 部分 | 优先可信源；高风险配合 [审批](./approvals) |
| **自我进化** | 记录偏好与修正 | **self-improving** + [设置 · 个人/记忆](./memory) | ✅ 具备 | 纠正一次后写入记忆/偏好 |
| **视觉/页面设计** | 海报或有设计感的页面 | **canvas-design** + 会话写前端 | ✅ 相关 | 「活动海报 / 落地页」类需求 |
| **查找技能** | 按任务推荐 Skill | **find-skills** | ✅ 具备 | 「帮我找适合网页采集的技能」 |

> 「✅」= 能力已可用；「△」= 用其它入口覆盖；「⚠」= 当前无同款捆绑，文档不假装已有。以你客户端 **市场 · 技能** 列表为准。

## 浏览器

网页自动化在 OnMyAgent 拆成两条表面，避免混用：

| 技能 ID | 表面 | 适合 |
|---------|------|------|
| **browser-automation** | 应用**内置浏览器**（右侧 Browser 面板） | 不依赖本机 Chrome 登录态；应用内预览 |
| **browser-skill** | 本机 **Chrome / Edge** + `bsk` 扩展 | 已登录站点、要真实 Cookie 的流程 |
| **computer-use** | 桌面原生应用 UI | 操作本地 App，**不是**网页自动化 |

### 使用方式

1. 确认相关技能已启用（市场 / 扩展里可见 **BrowserSkill** 引导时按 3 步完成）  
2. 在会话中说明目标，例如：  

```text
请用应用内浏览器打开 https://example.com，展开需要滚动才能看到的内容，
整理成结构化摘要，并为关键区域截图留档到工作区 notes/web-summary.md。
```

3. 若站点必须本机登录：改用 **browser-skill**，并说明「用我本机 Chrome 里已登录的会话」。  
4. 纯 API 能完成时，优先 [连接器 / MCP](./mcp)，不要强行点网页。

### 示例指令

```text
请打开这个网页，完整阅读需要展开和滚动后才能看到的内容，整理成结构化摘要，并为关键页面截图留档。
```

### 注意

- 内置浏览器**没有**「随便连 9222 CDP」的运维路径；按技能说明使用官方工具。  
- 登录、验证码等人机步骤按提示在浏览器内完成后再继续。  
- 高风险点击/提交受 [权限与审批](./approvals) 约束。

## 办公文档四件套

PDF / Word / PPT / Excel 相关任务：

| 能力 | OnMyAgent |
|------|-----------|
| 统一入口 | **document-processing**（Word / Excel / CSV / PPT / PDF 任务路由） |
| 演示文稿 | **pptx**（创建、解析、编辑、合并拆分） |
| 增强引擎 | 可选安装 **OfficeCLI** 插件（市场/设置中的办公运行时，优先于轻量 runtime） |

### 示例

```text
把工作区里的 应收台账模板.xlsx 清洗重复行，按客户汇总金额，另存为 notes/台账-汇总.xlsx。
```

```text
根据 notes/方案大纲.md 生成 10 页以内的 PPT，输出 deliverables/方案汇报.pptx。
```

文件验收见 [文件与产物](./files)。

## 联网搜索（Web Search）

无单独名为 `web-search` 的捆绑技能时：

1. 使用支持联网的模型（[设置 · 模型](./models)）  
2. 或在 **市场 → 连接器** 接入搜索类 MCP  
3. 对「必须打开页面才能看全」的内容，改用 [浏览器](#浏览器-agent-browser)  

```text
检索 2026 年办公 Agent 产品动态，整理成要点摘要并附来源链接，写入 notes/research/agent-news.md。
```

## Find Skills / 自我进化 / 设计类

| 需求 | 技能 | 示例 |
|------|------|------|
| 不知道装哪个 | **find-skills** | 「我想做网页采集和截图，先帮我找出合适技能并说明区别」 |
| 越用越懂你 | **self-improving** + [个人/记忆](./memory) | 纠正偏好后写入记忆 |
| 海报 / 视觉稿 | **canvas-design** | 「做一张活动海报，现代专业风」 |
| 写结构化文档 | **doc-coauthoring** | PRD、方案、决策文档协作流程 |
| 创建/改技能本身 | **skill-creator** | 自定义新技能与评估 |
| 定时任务 | **create-automation** | 「每周五生成周报草稿」→ [自动化](./automation) |
