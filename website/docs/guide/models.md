# 模型与 BYOK

OnMyAgent **不绑定单一模型厂商**。你在设置里接入自己的密钥或兼容端点（Bring Your Own Key），也可使用本机模型。

## 配置入口

1. 打开 [设置](./settings)（左下角齿轮 → **设置**，或 **⌘ ,**）  
2. 左侧 **工作区 → 模型**（总览里也可点「模型」卡片）  
3. **连接模型服务商** 或 **自定义模型服务商配置**  
4. 填写 API Key、Base URL，或本机模型地址  
5. 回到会话，在输入区右侧选择当前模型  

![设置 · 模型：已连接服务商列表](/images/settings-ai.png)

## 会话内切换

输入区右侧可切换模型（不同厂商或推理强度）。新会话默认使用你最近选择或设置中的默认模型。

## 建议

| 场景 | 建议 |
|------|------|
| 草稿与头脑风暴 | 较快、成本较低的模型 |
| 长文与复杂规划 | 更强推理模型 |
| 内网 / 离线 | 本机（如 Ollama）或私有化端点 |

## 排障

| 现象 | 处理 |
|------|------|
| 无响应 / 鉴权失败 | 检查 Key、Base URL、代理与额度 |
| 列表为空 | 确认服务商已连接且未禁用 |
| 本机模型连不上 | 确认本地服务已启动，地址与端口正确 |
