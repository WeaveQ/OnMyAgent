# 模型与 BYOK

OnMyAgent **不绑定单一模型厂商**。你在设置中接入密钥或兼容端点（Bring Your Own Key）。

## 配置入口

1. 打开 [设置](./settings)  
2. 找到模型 / 供应商 / API 相关页  
3. 填写 API Key、Base URL 或本机模型地址  
4. 在会话输入区选择默认或当前模型  

![设置入口](/images/settings.png)

## 会话内切换

输入区右侧可切换模型（例如不同推理强度或厂商）。新会话默认使用你在设置中指定的默认模型。

## 建议

| 场景 | 建议 |
|------|------|
| 草稿与头脑风暴 | 较快、成本较低的模型 |
| 长文与复杂规划 | 更强推理模型 |
| 内网/离线 | 本机或私有化端点 |
