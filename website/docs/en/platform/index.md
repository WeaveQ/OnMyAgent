# Three Products: OMA · OMB · OMC

OnMyAgent is not “one app with every form factor packed inside.” It is a platform with three tracks that can be combined:

```text
IM: Feishu/Lark, DingTalk, etc.        Employee computer                Private network (optional)
       OnMyBuddy        ← pairing/work →   OnMyAgent    ← connect →       OnMyCompany
  digital employee · reminders · commands   workspace · files · Skills     policy · Gateway · audit
```


## 1. Responsibility in one line

| Product | Responsibility |
|---------|----------------|
| [OnMyAgent](/en/platform/onmyagent) | Complete the work on the computer |
| [OnMyBuddy](/en/platform/onmybuddy) | Be reachable and keep work moving in IM |
| [OnMyCompany](/en/platform/onmycompany) | Provide optional company credentials and rules |

## 2. Principles

- **No company connected:** all local capabilities remain available, with no sign-in wall
- **OnMyBuddy does not replace the desktop:** file-heavy and execution-heavy work stays in OnMyAgent
- **Credentials do not go into chat:** enterprise egress goes through the control plane
