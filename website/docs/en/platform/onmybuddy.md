# OnMyBuddy: IM Digital Employee

A digital employee in IM services such as Feishu/Lark and DingTalk: event-driven tasks, reminders, and commands, with the option to assign execution-heavy work to OnMyAgent on the computer.

## 1. Status: stated explicitly

| Item | Status |
|------|--------|
| Vertical Feishu solutions, such as a growth assistant | Validated in real scenarios |
| Platform runtime + multiple Packs | Planned / in progress |
| One-click pairing and assignment to local OnMyAgent | Roadmap |

## 2. Relationship to the local desktop

| Side | Responsibility |
|------|----------------|
| **OnMyBuddy (IM)** | Reach people, send reminders, and provide a workflow entry point |
| **OnMyAgent (local)** | Hold the file source of truth, perform heavy execution, and deliver artifacts |

OnMyBuddy **does not replace** the desktop. Long documents, spreadsheets, and complex execution should still be completed in OnMyAgent.

## 3. Pilot recommendation

See [Pilot combinations A/B/C](/en/platform/pilot-combos). Start with A, which uses only the local desktop, then consider adding B for IM.
