# Install on Windows

Windows is a **developer preview**. Features and stability may lag behind macOS.

## 1. Steps

1. Download the NSIS installer from [GitHub Releases](https://github.com/WeaveQ/OnMyAgent/releases), if the release provides one, or build it locally by following `BUILD.md` at the monorepo root
2. Run the installer, then launch **OnMyAgent** from the Start menu
3. An unsigned build may trigger **SmartScreen**; choose **Run anyway**
4. After launch, continue with [Quickstart](/en/quickstart)

## 2. Compatibility

For detailed known limitations and compatibility notes, see `docs/windows-compat.md` in the repository.
