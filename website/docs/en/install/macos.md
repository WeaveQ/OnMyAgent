# Install on macOS

macOS is the **primary supported platform**, on both Apple Silicon and Intel.

## 1. Steps

1. Download the macOS package (`.dmg` or the package for your architecture) from [GitHub Releases](https://github.com/WeaveQ/OnMyAgent/releases)
2. Open the installer and drag OnMyAgent into **Applications**
3. If the first launch is blocked, open System Settings → **Privacy & Security** → **Open Anyway**
4. After launch, follow [Quickstart](/en/quickstart) to configure the workspace and model

## 2. System permissions you may need

| Capability | Permission |
|------------|------------|
| Read and write workspace files | Files and Folders |
| Notifications | Notifications |
| Screenshots / Computer Use | Screen Recording and Accessibility |
| Voice | Microphone |

Review authorization status in OnMyAgent under [Settings → System](/en/guide/settings#system).
