# Interface and workspace

Learn how the main interface is divided so you can quickly delegate work, inspect files, install capabilities, and change settings.

## 1. Overall layout


| Area | Purpose |
|------|---------|
| **Left main rail** | Home / Experts / Auto / Files / Market / Company after connection / Projects as a preview |
| **Middle list** | Recent tasks and sessions, or a file tree and Market filters |
| **Main content** | Conversations, file tables, expert cards, and other module content |
| **Composer** | Natural language, `@` references, `/` skills, model selection, and permissions |
| **Bottom of the rail** | **Channels**, plus the account menu for Agent management, Agent chat, Settings, appearance, and other items |

## 2. Workspace

A workspace can be a local folder or a connection to a remote OnMyAgent Server. It provides:

- the default scope the Agent can read and write
- the destination for imported files, which are usually copied into the workspace
- the location in which deliverables are stored

For creating, renaming, sharing, and authorizing local and remote workspaces, see [Workspaces](/en/guide/workspaces). Use [Settings](/en/guide/settings) to configure models, Company connection, and global preferences.

## 3. Market

Market lets you browse and install **experts, skills, and connectors**:


Switch between **Experts · Skills · Connectors** in the top bar, then filter by industry category or search. Connectors can be implemented as MCP servers, managed CLIs, cloud services, and other types; see [Connectors and managed tools](/en/guide/connectors).

## 4. Conditional entries and status

| Entry | Current status |
|-------|----------------|
| **Company** | Appears only after OnMyCompany connects successfully; local mode does not require sign-in |
| **Projects** | Coming Soon placeholder, not a usable project-management module |
| **Channels** | Located at the bottom of the main rail; WeChat, Feishu, Telegram, and Discord require real accounts and platform permissions |

See [Company connection](/en/guide/company), [Projects preview](/en/guide/projects), [Messaging channels](/en/guide/channels), and [Feature and platform status](/en/guide/capability-status).

## 5. Opening Settings

- Select the **gear** in the lower-left corner, then choose **Settings** from the menu to open the complete settings page.
- Or press **⌘ ,** on macOS or **Ctrl ,** on Windows.

The account menu also includes:

| Entry | Description |
|-------|-------------|
| **Agent management** | Manage the local CLI and ACP Agent fleet, connections, and skill matrix; see [Agent management](/en/guide/agent-management) |
| **Agent chat** | Delegate work directly to a local Agent; see [Agent chat](/en/guide/agent-chat) |
| **Settings** | Open the complete settings page for models, preferences, Company, and more |
| Appearance | Switch between light and dark themes |
| Check for updates and Quit | Click the notice to start a download when a new version is found |


Settings opens to **Overview**. The left side groups pages under Workspace, including Models and Company; Personal; Global, including Preferences, System, Shortcuts, and Updates; and Data. Local environment settings are now part of **System**. See [Settings](/en/guide/settings).
