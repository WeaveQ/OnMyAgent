# Projects preview

**Projects is not currently a usable production module.** The Projects entry on the main rail and the Projects category in Files remain Coming Soon or disabled.

## 1. What to use today

Use the following production capabilities to organize work:

- [Workspaces](/en/guide/workspaces) to isolate files for different clients or subjects
- [Sessions](/en/guide/sessions) to preserve the context for one deliverable
- [Experts](/en/guide/experts) to keep role-specific capabilities stable
- [Automation](/en/guide/automation) to make repeatable execution persistent
- [Files and deliverables](/en/guide/files) to accept task and expert files

## 2. Why this page remains in the handbook

A route name, icon, tab, or placeholder string appearing in the source code does not mean the product capability is complete. This page states the current status explicitly so that a visible placeholder is not documented as a delivered feature.
