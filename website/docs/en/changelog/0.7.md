# 0.7

0.7 turns Knowledge into local folders you can switch and edit as blocks, and adds prompt enhance in the composer. The desktop package version is already 0.7.0; there is no tag yet.

For the complete assets, use [GitHub Releases](https://github.com/WeaveQ/OnMyAgent/releases).

## 0.7.0

### Knowledge, now easier

The Knowledge rail can attach more than one local folder. Notes you open land in **Recent**. `.md` files open in a block editor (type `/` for headings, lists, and to-dos).

- The sidebar groups **My vaults / Project library / Expert library**. The last two show **Not available yet** when there is no matching scope
- **New** can create a note or a table, upload files, or bookmark a web page
- **Save to knowledge** in the session header writes the current conversation as a note (desktop only)

### Enhance prompt

The composer has a sparkle button, **Enhance prompt**. Write a short draft first; it rewrites the prompt so it is clearer to run. Use **Restore original** if you do not like the result. A usable model must be selected. The embedded expert-creation composer does not show this button.

### Suggested follow-ups can be turned off

**Settings → Preferences** adds **Suggested follow-ups**. Turn it off and the chips after a reply disappear in both Home and Expert chats.

### Fixes

- After a packaged install, the in-session terminal can open
- Desktop errors show the real reason instead of a wrapped remote-invoke message
- Home workspace and permission popovers are tighter. Access is now an **Allow full access** switch
