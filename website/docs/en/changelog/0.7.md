# 0.7

0.7 turns Knowledge into local folders you can switch, notes you can edit as blocks, and a way to save a session as a note. The desktop package version is already 0.7.0; there is no tag yet.

For the complete assets, use [GitHub Releases](https://github.com/WeaveQ/OnMyAgent/releases).

## 0.7.0

### Multiple vaults and Recent

The Knowledge sidebar groups **My vaults / Project library / Expert library**. Notes you open show up under **Recent**.

- On a personal vault you can **Add folder**. That only adds it to the list; files on disk stay put. Removing a folder works the same way
- You can point a personal vault at an existing Obsidian directory
- **Project library** and **Expert library** show **Not available yet** when there is no matching scope

### Block editor

`.md` notes now open in a block editor by default. Type `/` to insert headings, lists, to-dos, quotes, and code blocks without memorizing Markdown first.

- Note properties cover title, tags, and related notes. Extra fields you added in the note header are kept on save
- You can still switch to **source** when you need to edit the markup by hand

### New, upload, and bookmarks

The toolbar **New** menu is more than a blank Markdown note.

- Create a note or a table, or **Upload files** / **Upload folder**
- `.html` opens as a read-only preview. The page is sanitized and is not an editor
- **Add link** saves a web page as a Markdown note and stores the URL in properties

### Save a session to knowledge

When a conversation is worth keeping, use **Save to knowledge** in the session header to write it as a note.

- You can change the file name and pick where it is saved
- Desktop only. After save, Knowledge opens that note

### Fixes

- After a packaged install, the in-session terminal can open
- Desktop errors show the real reason instead of a wrapped remote-invoke message
- Home workspace and permission popovers are tighter. Access is now an **Allow full access** switch; turn it off when you want approvals
