# 0.6

The 0.6 line focuses on the desktop configuration foundation, dual-runtime boundaries, expert/session cold-start stability, and the local-skills and model-provider experience.

For the complete assets, use [GitHub Releases](https://github.com/WeaveQ/OnMyAgent/releases).

## 0.6.0

### Take your experts with you

Experts you create or import now live under a **Mine** category, with package-level export, import, and cross-machine migration.

- Export as zip: persona, knowledge, avatar, and declared skills only — **no sessions or credentials**
- Import a zip or folder; on collision choose **Reset (overwrite)** or **Keep as copy**; successful import auto-summons the expert
- Mine cards expose **Edit / Export / Delete / Open chat**

### Toggle model providers in one click

Provider rows in **Settings → AI** now have a **Power toggle** that disables a provider without deleting its credentials; a successful toggle applies live without a restart prompt. The session model picker footer button is now **Go to settings**, which opens `/settings/ai` directly.

### Computer Use runs in the background

On macOS, Computer Use now uses window-directed background input, so you can keep using your own mouse and frontmost app while it runs. The virtual cursor only appears inside the controlled window.

### Queue follow-up prompts while a session is busy

No more waiting for the run to finish before you type the next question. Write it and press **Send** while the assistant is still working — the prompt is queued and sent automatically, in order, once the current turn ends.

- A queue bar appears above the composer, holding up to **20 messages**; each row shows a text preview and attachment count
- Per-item actions: **drag to reorder**, **Send next** (promote to the front), **Edit** (load back into the composer), and **Remove**
- A prompt that fails to send is restored to the front of the queue instead of being dropped
- Pressing **Stop** pauses automatic draining; it resumes on the next successful send
- The queue is in-memory only; closing/deleting the session or restarting the app clears it
