# Quickstart

Finish the essential setup in about five minutes: install → workspace → model → first task.

## What you will complete

1. Install the desktop app
2. Open the app—local capabilities work **without signing in**
3. Confirm or select a local workspace
4. Connect at least one model using BYOK
5. Send your first office task and receive a response

## 1. Install

See [Download and install](/en/download).

- **macOS**: primary support, for Apple Silicon and Intel
- **Windows**: developer preview

## 2. Launch

After installation, launch **OnMyAgent**. It opens to the Home session area by default, where you can select **+ New task** immediately.


## 3. Workspace

A workspace is the default local directory in which a task can read and write files. Choose a folder during first-run guidance. You can continue configuring workspace sections such as **Settings → Workspace → Models** later.

- Imported files enter the workspace as copies
- Documents, spreadsheets, and other deliverables created by an Agent appear in [Files](/en/guide/files)

## 4. Connect a model

1. Open [Settings](/en/guide/settings) from the gear in the lower-left corner → **Settings**, or press **⌘ ,**.
2. Go to **Workspace → Models**.
3. Select **Connect model provider**, then enter an API key, a compatible Base URL, or a local model configuration.

You control the key; OnMyAgent does not require it to be uploaded to a central service. See [Models and BYOK](/en/guide/models).


## 5. Send your first prompt

Describe a clear goal in the composer. For example:

```text
In three sentences, explain what you can help me do, then suggest two office tasks I should try next.
```

You can use:

- `@` to reference a conversation or file
- `/` to invoke skills and commands
- the **Permissions** mode and **Model** selector at the bottom

## 6. Review the result

- Read the process and conclusion in the conversation
- If the Agent created a file, open **Files** to preview it or edit it in a system application
