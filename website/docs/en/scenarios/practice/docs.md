# Practice 2: Create and Edit Documents

Turn source material into an editable Word, Markdown, or PowerPoint deliverable saved in the workspace.

## 1. Scenario and goal

| Scenario | Goal |
|----------|------|
| You have an outline or notes and need a formal draft | Generate a structured document and save it to disk |
| A long draft must be shortened or its tone changed | Save a new version without overwriting the original |
| You need presentation slides | Generate a pptx, or create an outline before expanding it |


## 2. Create a document from scratch

```text
Using the following points, write a one-page proposal with background, goal,
a three-step plan, and risks. Write in Chinese for a business lead and keep it
under 800 Chinese characters. Save it to notes/proposal-client-a.md.
Points: …
```

## 3. Rewrite an existing file

```text
Follow the structure and tone of @notes/weekly-report-good-example.md.
Use this week's material under notes/daily/ to draft the weekly report.
Save it as notes/weekly/this-week.md. Do not overwrite the example.
```

## 4. Generate a presentation

```text
Based on notes/proposal-client-a.md, create a presentation of no more than ten
slides and save the pptx to deliverables/client-a-presentation.pptx.
Each slide should have a title and three key points.
```

For document capabilities, see [Skills · Office documents](/en/guide/skills) (`document-processing` / `pptx` / OfficeCLI).

## 5. Work in small steps

1. Request only the **table of contents or outline** first
2. After confirming it, expand one section at a time
3. Convert to PowerPoint or apply a template only at the end

## 6. Acceptance checks

- [ ] The deliverable opens from Files
- [ ] The original file was not overwritten unintentionally
- [ ] The agreed format is correct: heading levels, tables, and length
