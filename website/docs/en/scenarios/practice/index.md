# Practice Examples

These end-to-end examples turn common office tasks into workflows you can follow. The goal is not only to know what a feature does, but to produce a file you can verify.


Start with the general method: [How to use the scenarios](/en/scenarios/usage-guide).

## 1. Examples at a glance

| # | Topic | Guide | What you will do |
|---|-------|-------|------------------|
| 1 | Identify and organize files | [Identify and organize files](/en/scenarios/practice/files) | Preview renames and organize meeting notes |
| 2 | Create and edit documents | [Create and edit documents](/en/scenarios/practice/docs) · [Reports and meeting minutes](/en/scenarios/office-docs) | Save md/docx/pptx deliverables |
| 3 | Analyze and summarize spreadsheets | [Analyze and summarize spreadsheets](/en/scenarios/practice/data) | Clean, aggregate, and conclude |
| 4 | Plan and distribute content | [Plan and distribute content](/en/scenarios/practice/content) | Topics, scripts, and channel variants |
| 5 | Automate daily/weekly briefs | [Automate daily/weekly briefs](/en/scenarios/practice/daily-brief) · [Scheduled digests](/en/scenarios/automation-digest) | Hand work over to Automation |
| 6 | Create and improve Skills | [Create and improve Skills](/en/scenarios/practice/skills-evolve) · [Skills](/en/guide/skills) | find-skills / Memory |
| 7 | Keep work moving with Automation | [Continuous execution](/en/scenarios/practice/self-drive) | Self-contained prompts + schedules |
| 8 | Meeting minutes and action items | [Meeting minutes and action items](/en/scenarios/practice/meetings) | Save structured minutes |
| 9 | Cloud document collaboration (optional) | [Tencent Docs collaboration](/en/scenarios/practice/tencent-docs) | Requires the matching installed and authorized Skill |

Workflows such as “remotely control this computer” and “build a local app without code” are not covered here. OnMyAgent is primarily a **desktop workspace for local deliverables**.

For working habits, see [Tips for effective use](/en/guide/efficient-tips). For capability details, see [Skills](/en/guide/skills).

## 2. Recommended reading order

1. [Identify and organize files](/en/scenarios/practice/files) — start by working safely with local files
2. [Create and edit documents](/en/scenarios/practice/docs) — produce files on disk
3. [Analyze and summarize spreadsheets](/en/scenarios/practice/data) — clean and aggregate data
4. [Automate daily/weekly briefs](/en/scenarios/practice/daily-brief) — learn Automation
5. [Create and improve Skills](/en/scenarios/practice/skills-evolve) — make capabilities reusable

## 3. Common structure

Each practice guide normally includes:

- **Scenario and goal**
- **Preparation** (workspace, permissions, Skills)
- **Example request** you can copy
- **Expected result and acceptance checks**
- **Safety notes** (preview, backup, approval)
