# Practice 4: Plan and Distribute Content

For operations, production, and content teams: create topic packages, scripts, and channel-specific rewrites, with every **deliverable saved to disk**.

## 1. Scenario and goal

| Scenario | Deliverable |
|----------|-------------|
| Weekly topic planning | Topic table + hook + format |
| One script | A 60–90 second spoken script |
| One source, multiple channels | Three variants for Xiaohongshu / short video / WeChat Official Account |

You can pair this with a content or creator-operations [Expert](/en/guide/experts), or create your own “Content Producer” Expert.


## 2. Example: weekly topics

```text
Creator/account: beauty niche, conversational product-review style.
This week: three Xiaohongshu posts + two short videos.
Create a topic table with pain point, hook, format, and estimated difficulty.
Also write one complete 60–90 second spoken script.
Save everything to notes/content/topics-WXX.md.
```

## 3. Example: adapt one draft for multiple channels

```text
Based on @notes/content/source-draft.md, create:
1. Xiaohongshu recommendation copy (title + body + suggested tags)
2. A 45-second short-video script
3. A WeChat Official Account version under 800 Chinese characters with subheadings
Write three separate files under notes/content/distribution/.
Preserve the facts and do not invent data.
```

## 4. Recommendations

- Define the persona and channel before writing the body ([Tips · the three-part formula](/en/guide/efficient-tips))
- For brand work, use a strategy-brief or creator-evaluation prompt with a fixed template and output path
- Keep human confirmation in the loop for bulk publishing or ad-placement actions
