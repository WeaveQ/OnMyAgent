# OnMyAgent Introduction

OnMyAgent is a **local-first office Agent workbench**. Describe what you need in natural language; it plans and runs on your machine and writes deliverables into your workspace—not just chat suggestions.

![Home: new task, recent sessions, and input](/images/home-session.png)

## Core capabilities

| Capability | What it does |
|------------|----------------|
| **One-shot tasks** | Describe a goal in a home session; the Agent breaks it down and executes |
| **Local files** | Read/write authorized workspace files; preview sheets, slides, images, and more |
| **Skills & Experts** | Install Skills and call domain Experts to extend what can be run |
| **Automation** | Scheduled or trigger-based office jobs (reports, reminders, digests) |
| **Approvals** | High-risk local actions can require confirmation |
| **BYOK models** | Bring your own API or local model; you keep the keys |
| **Marketplace** | Browse and install Experts, Skills, and connectors |

## Typical use cases

- Work reports, meeting notes, draft proposals  
- Spreadsheet cleanup and light analysis  
- Materials for presentations  
- Scheduled digests and office automation  
- Role-based Experts and skill packs  
- (Optional) IM digital employees + org control — see Chinese docs: [平台三分](../platform/)

## Not just another chatbot

| Chat-only AI | OnMyAgent |
|--------------|-----------|
| Suggestions and draft text | **Actually runs** multi-step work on your machine |
| You copy-paste files by hand | Read/write **inside the workspace** |
| Mostly single-turn Q&A | Resumable sessions + automation |
| Results stuck in the thread | **Files** you can preview, edit outside, and archive |
