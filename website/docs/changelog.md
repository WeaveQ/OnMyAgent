# 更新日志

完整资产与说明以 [GitHub Releases](https://github.com/WeaveQ/OnMyAgent/releases) 为准。以下摘录近期用户可见变更。当前桌面发布均为 **pre-release**。

## Unreleased

- **最近** 只列出主任务；Agent 拆出的子任务不再单独占一行
- 并行子任务在对话里收成 **N/M 个子任务**；返回正文可直接阅读，相同说明的连续重试折成一条
- 上下文用量优先取模型目录窗口（百万级显示为 **1M**），并拆开占用与上一轮生成
- 市场 **创建技能** 预填 `/skill-creator …`；点 **新建任务** 清草稿时这份预填会保留
- 专家挂载的技能不再出现在 **已安装**；沙箱里仍可用 `/` 调核心捆绑技能
- 主栏隐藏 **项目** 入口（文件页分类仍为预告）
- 对话正文支持右键剪切 / 复制 / 粘贴 / 全选
- 会话里的 Markdown 产物按文件链接打开，不再显示成「打开产物」药丸

## 0.5.4

- 设置 · 更新：检查时不再误显示「只能去 GitHub 下载」
- Windows 标题栏改为应用内绘制
- macOS 公证成功后不再被二次打包覆盖

## 0.5.3

## 0.5.2

## 0.5.1

- 安装包更小：去掉未使用的内置 Node/Python 附件、重复 sidecar，以及 artifact-runtime 的 map/类型文件

- 不会在检查到更新后自动后台下载，也不会静默安装
