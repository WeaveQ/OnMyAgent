# 更新日志

完整资产与说明以 [GitHub Releases](https://github.com/WeaveQ/OnMyAgent/releases) 为准。以下摘录近期用户可见变更。当前桌面发布均为 **pre-release**（未公证）。

## Unreleased

- 发现新版本后需点击提示或「下载更新」才开始下载；冷启动会自动检查一次
- 不会在检查到更新后自动后台下载，也不会静默安装

## 0.5.0

- 正式包不再显示任务中心入口（本地开发仍可见）

## 0.4.29

- 新增任务中心：后台持久编排、对齐确认、审批与运行历史
- Windows 托盘图标与应用图标一致（圆角品牌标）
- 任务栏右键快捷菜单「计算机控制」使用应用图标
- 专家市场列表不再被拖拽选中文字

## 0.4.28

- 欢迎页不再被启动遮罩挡住（冷启动后可继续入门）
- 专家页身份快照缓存，避免界面卡死 / 白屏
- 删除专家后创建浮层会收起
- 专家包名与本机用户主目录解析更稳

## 0.4.27

- 打包版后台自动更新：下载完成后点 **重启并安装**（不会静默安装）
- 专家永久删除不再因包名格式对不上而失败
- 设置里模型服务商的删除 / 断开统一为 **移除**

## 0.4.26

- 专家 / 会话界面稳定性（避免白屏或界面卡死）
- 本机会话归档与本地 Agent 扫描使用真实用户主目录

## 0.4.25

- 系统通知与快速捕获可在会话页以外使用
