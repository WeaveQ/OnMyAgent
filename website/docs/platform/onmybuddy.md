# OnMyBuddy（IM 数字员工）

飞书 / 钉钉等 IM 中的数字员工：事件驱动、催办、指令；可选把重活派到本机 OnMyAgent。

## 状态（诚实）

| 项 | 状态 |
|----|------|
| 飞书垂直样板（如成长助手） | 已在真实场景验证 |
| Runtime + 多 Pack 平台化 | 规划 / 进行中 |
| 与本机 OMA 一键配对派活 | 路线图 |

## 和本机的关系

| 侧 | 职责 |
|----|------|
| **OnMyBuddy（IM）** | 触达、催办、流程入口 |
| **OnMyAgent（本机）** | 文件真相、重执行、产物交付 |

Buddy **不替代**桌面：长文档、表格与复杂执行仍应在 OnMyAgent 完成。
