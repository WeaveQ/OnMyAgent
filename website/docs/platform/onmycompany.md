# OnMyCompany（内网管控）

组织侧可选组件：身份、组织配置下发、Gateway 出口、审计。

## 状态（诚实）

| 项 | 状态 |
|----|------|
| 内网管控试点主路径 | 服务端较成熟 |
| 桌面连接与配置镜像 | 最小路径可用 |
| 全链路强制企业出口 | 持续加强中 |

## 桌面如何连接

在 OnMyAgent [设置 → 公司](../guide/settings#公司)：

1. 填写组织服务地址  
2. 企业邮箱 + 验证码登录  
3. 可用 **探活** 检查服务是否可达  

![设置 · 公司](/images/settings-company.png)

## 原则

- **连接公司 = 可选**，不是使用本机的前提  
- 未配置公司地址时，不发起企业 HTTP  
- 已连接时：桌面应服从组织策略，**不得在本机擅自放宽**
