# 平台三分：OMA · OMB · OMC

OnMyAgent 不是「一个 App 塞进所有形态」，而是三条可组合轨道：

```text
飞书 / 钉钉等 IM                 员工本机                      内网（可选）
   OnMyBuddy      ←──配对/派活──►  OnMyAgent    ←──连接──►  OnMyCompany
   数字员工 · 催办 · 指令          工作台 · 文件 · Skill         策略 · Gateway · 审计
```

![本机工作台是交付主场](/images/home-session.png)

## 一句话分工

| 产品 | 一句话 |
|------|--------|
| [OnMyAgent](./onmyagent) | 在电脑上把活干完 |
| [OnMyBuddy](./onmybuddy) | 在 IM 里找得到、催得动 |
| [OnMyCompany](./onmycompany) | 公司钥匙与规矩（可选） |

## 原则

- **未连接公司**：本机完整可用（无登录墙）  
- **Buddy 不替代桌面**：重文件与重执行仍在 OMA  
- **密钥不进聊天**：企业出口走管控面
