# OnMyAgent（本机工作台）

桌面端主产品：会话、文件、专家/技能、自动化、审批与 BYOK。

![首页会话](/images/home-session.png)

## 你在这里做的事

- 派发与跟进办公任务  
- 管理工作区资料与产物  
- 安装专家与技能、连接外部工具  
- 配置模型、个人画像、全局偏好、系统权限与本机环境（环境在系统设置内）
