# 快速开始

约 5 分钟完成：安装 → 工作区 → 模型 → 第一句任务。

## 你将完成

1. 安装桌面端  
2. 打开应用（**无需登录**即可用本机能力）  
3. 确认 / 选择本机工作区  
4. 接入至少一个模型（BYOK）  
5. 发起第一条办公任务并看到回复  

## 1. 安装

见 [下载与安装](./download)。

- **macOS**：主支持（Apple Silicon / Intel）  
- **Windows**：开发者预览  

## 2. 启动

安装后启动 **OnMyAgent**。默认进入首页会话区，可直接 **+ 新建任务**。

![首页与新建任务](/images/home-session.png)

## 3. 工作区

工作区是任务读写文件的默认本机目录。首次使用按引导选择文件夹；之后可在 **设置 → 工作区 → 模型** 等分区继续配置。

- 导入文件会进入工作区（复制为工作区副本）  
- Agent 生成的文档、表格等出现在 [文件](./guide/files) 中  

## 4. 接入模型

1. 打开 [设置](./guide/settings)（左下角齿轮 → **设置**，或 **⌘ ,**）  
2. 进入 **工作区 → 模型**  
3. **连接模型服务商**，填写 API Key 或兼容 Base URL / 本机模型  

密钥由你保管，不会以「必须上云」为前提。详见 [模型与 BYOK](./guide/models)。

![设置 · 模型](/images/settings-ai.png)

## 5. 发起第一句

在输入框描述清晰目标，例如：

```text
请用三句话介绍你能帮我做什么，并建议两个适合办公的下一步任务。
```

可使用：

- `@` 引用对话或文件  
- `/` 调用技能与指令  
- 底部 **权限** 模式与 **模型** 选择  

## 6. 查看结果

- 对话区查看过程与结论  
- 若生成了文件，到 **文件** 页预览或用系统应用打开  

![文件区产物列表](/images/files.png)
