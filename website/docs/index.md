# OnMyAgent 简介

OnMyAgent 是**本地优先的办公 Agent 工作台**。你用自然语言描述目标，它在本机规划、调用技能与工具、读写授权工作区，并把可验收的结果落到文件里——不只是聊天建议。

![主界面：新建任务、最近会话与输入区](/images/home-session.png)

## 一句话理解

| 你要的 | OnMyAgent 怎么做 |
|--------|------------------|
| 写报告 / 纪要 / 方案 | 在会话里说清目标与材料，Agent 生成文档类产物 |
| 整理表格、对账、汇总 | 读写工作区内表格，输出可打开的结果文件 |
| 定时早报 / 提醒 | 用**自动化**挂调度，按模板重复执行 |
| 岗位专长 | 在**市场**装专家或技能，在主栏**专家**里对话 |
| 密钥与模型自己管 | **BYOK**：接兼容 API 或本机模型，凭证留在本机 |

数据默认留在本机工作区；联网仅在你接入的模型、市场与连接器需要时发生。更完整的安全边界见 [安全与数据](./security)。

## 核心能力

| 能力 | 说明 |
|------|------|
| **一句话派活** | 首页会话描述目标；Agent 拆解步骤并执行，可中途补充材料 |
| **本机文件** | 在授权工作区读写、导入；文件区按类型浏览、预览、外编 |
| **技能与专家** | Skill 扩展动作；专家是带人设与场景的对话入口 |
| **自动化** | 定时或触发类办公任务（汇报、提醒、汇总） |
| **审批与权限** | 高风险本机动作可要求确认，再继续执行 |
| **模型自选（BYOK）** | 接入兼容 API 或本机模型；密钥与端点你自己管 |
| **市场** | 浏览并安装专家、技能、连接器（如办公组件、IM 机器人） |

## 界面怎么走

左侧主栏切换主模块，中栏是列表/目录，右侧是对话与输入（或模块主内容）。

| 主栏 | 做什么 |
|------|--------|
| **首页** | 新建任务、最近会话、欢迎与输入区 |
| **专家** | 已安装/创建的专家列表与对话 |
| **自动** | 自动化任务、模板与调度 |
| **文件** | 工作区与任务产物：筛选、搜索、预览 |
| **市场** | 专家 / 技能 / 连接器 |
| **项目** | 按项目组织的工作上下文（视版本与配置） |

底部可打开 **Agent 对话** 与 **设置**（模型、偏好、公司、记忆、系统权限等）。

## 一次任务大致怎么跑

1. **说清目标**：在首页或会话输入区用自然语言写要什么（可 @ 文件、/ 技能）。  
2. **授权与模型**：选择工作区、权限档位与模型（首次需在设置里接好服务商）。  
3. **执行与追问**：Agent 多步执行；可补充材料、改方向、要求重出一版。  
4. **验收产物**：在**文件**区打开、预览或用系统应用外编；不满意就在会话里继续改。  
5. **固化习惯**（可选）：稳定流程做成**自动化**或沉淀为**技能 / 专家**。

更细的操作见 [第一个任务](./first-task) 与 [场景使用说明](./scenarios/usage-guide)。

## 适用场景

- 工作报告、会议纪要、方案草稿  
- 表格整理与数据分析辅助  
- 演示文稿相关材料整理  
- 定时汇总、提醒类办公自动化  
- 按岗位使用专家与技能包  
- （可选）飞书/钉钉等数字员工 + 组织侧管控，见 [平台三分](./platform/)

## 与「只会聊天」的 AI 有何不同

| 只会聊天的 AI | OnMyAgent |
|---------------|-----------|
| 给建议、给草稿文字 | 在本机**实际执行**多步任务 |
| 文件靠你手动复制粘贴 | **工作区内**读写、导入、交付 |
| 单轮问答为主 | 可恢复会话 + 自动化 |
| 结果散落在对话里 | **文件区**可预览、可外编、可归档 |
| 能力固定在对话窗口 | 可用技能、专家、连接器**扩展动作** |

## 本地优先，不等于不能联网

- **本地优先**：会话状态、工作区文件、多数配置默认在本机。  
- **按需联网**：调用云端模型、打开市场、使用 IM/办公连接器时会访问对应服务。  
- **你可关掉或换源**：换模型端点、不用某连接器即可缩小外联面。

企业要把「个人工作台 / 数字员工 / 组织管控」分开看时，从 [平台三分](./platform/) 读起。
