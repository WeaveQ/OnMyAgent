# OnMyAgent 简介

OnMyAgent 是**本地优先的办公 Agent 工作台**。你用自然语言描述需求，它在本机规划、执行，并把可验收的结果落到工作区文件里——不只是聊天建议。

![主界面：新建任务、最近会话与输入区](/images/home-session.png)

## 核心能力

| 能力 | 说明 |
|------|------|
| **一句话派活** | 在首页会话描述目标，Agent 拆解并执行 |
| **本机文件** | 读写授权工作区；预览表格/幻灯片/图片等产物 |
| **技能与专家** | 安装 Skill、召唤领域专家，扩展可执行动作 |
| **自动化** | 定时或触发类办公任务（汇报、提醒、汇总） |
| **审批与权限** | 高风险本机动作可要求确认 |
| **模型自选（BYOK）** | 接入兼容 API 或本机模型，密钥自己管 |
| **市场** | 浏览专家 / 技能 / 连接器并安装 |

## 适用场景

- 工作报告、会议纪要、方案草稿  
- 表格整理与数据分析辅助  
- 演示文稿相关材料整理  
- 定时汇总、提醒类办公自动化  
- 按岗位使用专家与技能包  
- （可选）飞书/钉钉数字员工 + 内网管控，见 [平台三分](./platform/)

## 与「只会聊天」的 AI 有何不同

| 只会聊天的 AI | OnMyAgent |
|---------------|-----------|
| 给建议、给草稿文字 | 在本机**实际执行**多步任务 |
| 文件靠你手动复制粘贴 | **工作区内**读写、导入、交付 |
| 单轮问答为主 | 可恢复会话 + 自动化 |
| 结果散落在对话里 | **文件区**可预览、可外编、可归档 |

## 界面一览
