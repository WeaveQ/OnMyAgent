# OnMyAgent 简介

**OnMyAgent** 是本地优先的办公 Agent 工作台：用一句话描述需求，在本机规划、执行并交付可验收的结果。模型自选（BYOK），工作区与产物默认在你的电脑上。

## 核心能力

- **理解自然语言**：一句话下达任务
- **自主规划执行**：拆解步骤、调用技能与工具
- **办公交付**：文档、表格、报告与可预览产物
- **本地文件操作**：在授权工作区内读写与交付

## 与传统 AI 对话

| 传统 AI 对话 | OnMyAgent |
|--------------|-----------|
| 主要提供建议 | 在本机实际执行任务 |
| 需手动操作文件 | 工作区内自动读写与交付 |
| 偏单步问答 | 多步骤任务与自动化 |
| 输出以文字为主 | 交付可验收的文件与结果 |
