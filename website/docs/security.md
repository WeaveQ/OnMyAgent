# 安全与数据

## 数据落点

| 类型 | 默认位置 |
|------|----------|
| 工作区文件与产物 | 你指定的本机文件夹 |
| 本地配置 | 本机 OnMyAgent 配置目录 |
| 连接公司后的组织配置镜像 | 本机 profile（策略真相源在企业服务端） |

## 密钥（BYOK）

- API Key 由你或组织配置，不作为「必须托管给公有云」的前提  
- 不要在对话中粘贴长期密钥  

## 未连接公司

- 无企业地址 / 无企业会话时，**不发起企业 HTTP**  
- 本机能力完整可用  

## 审批

高风险本机动作可要求确认。见 [审批与权限](./guide/approvals)。
