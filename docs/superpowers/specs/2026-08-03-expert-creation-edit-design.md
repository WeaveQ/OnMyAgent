# 创建专家模块专家编辑设计

## 目标

允许通过“创建专家”模块创建的专家从已召唤专家列表的三个点菜单进入同一创建专家页面，回填基本信息、专家记忆和技能，修改后通过“更新”保存。市场专家、内置专家以及没有创建模块来源标记的专家不提供编辑入口。

## 方案

- 用 `AgentRecord.marketplaceSource === "mine"` 作为编辑资格，解析 registry 时保留该标记。
- 专家列表行菜单仅在该专家记录满足资格时显示“编辑”，点击后由 session 页面控制器打开创建专家页并传入目标记录。
- 创建专家页编辑模式使用现有 `createWizardDraftFromAgent` 初始化草稿；创建模式的本地草稿存储、coach 会话和退出清理不影响编辑模式。
- 编辑模式沿用现有四个页签，顶部标题与提交按钮使用编辑态文案，提交调用更新流程。
- 更新流程沿用原专家 ID、packageName、创建时间、来源及包路径，仅更新表单字段、专家包中的 role prompt / memory / skill IDs 和 registry 记录；知识目录不回填，但更新时保留包内已有知识文件。
- 更新成功后更新 registry store、关闭编辑页并提示成功；失败则留在编辑页显示错误。

## 验证

- 纯函数测试覆盖编辑资格、registry 来源标记解析、草稿回填和更新记录的不可变字段保留。
- 应用类型检查、边界检查、国际化检查、文件体量检查和 `git diff --check` 通过后，再进行功能点分提交。
