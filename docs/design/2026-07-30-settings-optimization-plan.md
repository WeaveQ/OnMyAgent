## 信息架构建议（待用户拍板）

### #3 应用快照 vs #2 快捷键 — 要不要放快捷键里？

**推荐：快捷键里挂一项（键位可搜可改），完整说明与权限用独立「应用快照」页/区块 — 不要只做成快捷键列表普通一行。**

| 方案 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| **A · 推荐** | 导航独立 **应用快照**（能力说明 + 键盘示意 + 权限 CTA + 全局键）；**快捷键**列表增加「应用快照」一行，展示当前键，点击跳转或展开同源配置 | 权限文案不被列表挤扁；快捷键里仍搜得到 | 两处入口，状态需同源 |
| B | 整页嵌在快捷键底部（大卡片 = 参考图） | 入口少 | 快捷键页过重；与 #2 列表+录制布局打架 |
| C | 只独立页，快捷键列表不出现 | 实现简单 | 用户在快捷键心智下找不到双 Command |

**理由：** 参考 UI 主体是 **能力说明 + 系统权限（辅助功能 / 屏幕录制）+ 特殊全局键（左右 Command）**，不是普通应用内 keymap 行。键位属于快捷键心智，权限与能力说明需要独立空间。

**对用户原问的直接回答：**  
- 「是不是也放到快捷键里面？」→ **键位相关：要挂进去**；**整页体验：建议独立（或快捷键二级全页），别只当普通快捷键行。**

默认文档按 **方案 A** 收集，你可改成 B/C。

### 需求 #3：应用快照（App Snapshot）

**参考 UI 全文录入**

| 字段 | 参考内容 |
|------|----------|
| 标题 | **应用快照** |

#### 能力定义（收集稿）

1. 用户触发全局快捷键 → 捕获 **当前最前（frontmost）应用** 的截图 + 可读文本。
2. 结果作为 **对话上下文** 注入（具体注入 Composer / 新会话 / 当前会话 **待确认**）。
3. 依赖 OS 权限：**辅助功能**、**屏幕录制**（macOS 首次授权可能较慢）。
4. 快捷键保存后，**权限未齐时不静默失败**：提示已保存、授权后自动生效，并提供打开系统设置入口。

#### 与 #2 关系

- 见上文 **信息架构建议**；默认 **方案 A**。
- 快捷键表增加 `appSnapshot`，默认 `左右 Command`。
- 特殊点：双 Command 不是常规 modifier+key，录制器/展示需单独支持。

### 需求 #4：偏好设置 · 对话宽度

**参考 UI**

| 字段 | 参考内容 |
|------|----------|
| 标题 | **对话宽度** |
| 说明 | 对话区与输入框的最大宽度。 |
| 控件 | 下拉，当前值 **默认** |

**用户口述（理解确认）**

> 偏好里这项功能：如果选「加宽」，就按外侧（主内容区 / 窗口可用宽度）来布局，**不再用固定最大宽度**。

#### 理解复述（请用户确认是否一致）

| 模式 | 行为 |
|------|------|
| **默认** | 对话消息列 + 底部输入框使用 **固定 max-width**（常见如 ~720–960px 居中），两侧留白；窗口再大，内容列也不再变宽。 |
| **加宽**（或下拉中非默认项） | **去掉 / 放宽固定上限**，对话列与输入框 **随外侧容器宽度** 伸缩（fill 主栏可用宽度，可仍有左右 padding，但不再「锁死一档 max-width」）。 |

- 作用范围：会话/对话主列 + Composer 输入框（与参考文案「对话区与输入框」一致）。
- **不**改变侧边栏宽度；侧栏仍独立。
- 偏好持久化，切换会话/重启后保持。

> 若理解有误（例如加宽仍是更大一档固定 px，而不是跟外侧 fluid），请直接纠正。

#### 选项枚举（待确认）

参考图只露出「默认」一项。可能方案：

| 方案 | 选项示例 |
|------|----------|

| B | `默认` / `较宽` / `全宽`（多档固定 max，最后一档才 fluid） |
| C | 仅「默认 | 全宽」二选一 |

- [ ] 默认：宽窗口下内容列宽度不再随窗增长（有固定上限）

| R2 | 录屏与系统录音 | 屏幕截取，用于屏幕内容识别、反馈截图等 | 未授权 → 去授权 |
| R3 | 辅助功能 | 监听全局快捷键，用于快捷唤起等 | 未授权 → 去授权 |
| R4 | 麦克风 | 访问麦克风，语音输入等 | 未授权 → 去授权 |
| R5 | 自动化 | 与系统应用协作（提醒/日历/备忘录等） | 已授权 |
| R6 | 通知 | 桌面通知，任务完成、消息提醒 | 未授权 → 去授权 |
| R7 | 位置服务 | 获取位置，处理与地理相关的任务 | 未授权 → 去授权 |

**OnMyAgent 现状（`system-authorizations-view` + `SystemPermissionType`）**

| 类型 ID | 中文 | 在系统授权页？ | 检测/跳转 |
|---------|------|----------------|-----------|
| `full-disk-access` | 完全磁盘访问权限 | ✅ 有 | main 可检测 FDA |
| `accessibility` | 辅助功能 | ✅ 有 | `isTrustedAccessibilityClient` |
| `automation` | 自动化 | ✅ 有 | 状态常为 unknown，可 trigger prompt |
| `notifications` | 通知 | ✅ 有 | renderer `Notification.permission` 补齐 |
| （无统一项） | 屏幕录制 | ❌ **不在系统授权列表** | Computer Use 配置里有 `screenRecording` 检测 |
| （无） | 系统录音 / 录屏合并项 | ❌ 无 | — |
| （无） | 麦克风 | ❌ 无 | 会话语音相关可能另有 media，但未进授权总表 |
| （无） | 位置服务 | ❌ 无 | — |

**对照结论**

| 结果 | 项 | 说明 |
|------|-----|------|
| ✅ 已有 | 完全磁盘 / 辅助功能 / 自动化 / 通知 | 与参考对齐；文案可再贴近参考用途描述 |
| ⚠️ 分散 | 屏幕录制 | **能力在 Computer Use**，**未进系统授权总表**；参考是总表一项「录屏与系统录音」 |
| ❌ 缺少 | **录屏与系统录音**（作为系统授权正式项） | 应用快照 / 截图 / CU 都依赖；应提升到授权中心 |

## Windows 平台矩阵（#6 · 专轮）

**原则（用户 2026-07-30 拍板）**

1. Windows **单独做一轮**，不与 mac 假共用「全 granted」。
