# Word 文档

## 使用范围

- 新建报告、合同、通知、简历、说明书或带封面目录的文档。
- 读取、提取、搜索、替换和修改现有 `.docx`。
- 按一份模板和一张数据表批量生成多份文档。
- 保留原有样式的批注、修订、段落、表格、图片和页眉页脚处理。

## 操作要求

1. 使用 `documents` 技能提供的运行时和检查流程。
2. 编辑前先检查章节、样式、表格、图片、页眉页脚及修订状态。
3. 套模板时复用现有样式名称和版式，不擅自统一成另一套格式。
4. 全局替换前确认替换范围，避免误改正文中同名但不同含义的内容。
5. 批量生成时先做一份样稿并校验，再扩展到全部数据。
6. 交付前渲染预览，检查分页、表格越界、字体替换、目录和编号。

## 注意

- 合同和正式文件中的名称、金额、日期、主体和签章位置应单独核对。
- 超过 50 页的复杂文档可按章节处理，但最终仍要做整份文档检查。
- 若用户要求从 DOCX 转成 PDF，只有当前运行时具备可靠转换能力时才执行；否则交付 DOCX 并说明可用的转换方式。
