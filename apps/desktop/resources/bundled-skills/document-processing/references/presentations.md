# PowerPoint 文件

## 使用范围

- 从零制作 `.pptx` 汇报材料。
- 按现有模板替换标题、正文、图片、表格和数据。
- 提取演示文稿的文字、结构和页面信息。
- 批量更新多页或多份演示文稿中的重复内容。

## 操作要求

1. 使用 `pptx` 技能提供的运行时和检查流程。
2. 先检查页面尺寸、母版、版式、字体、主题色和占位符。
3. 编辑模板时优先替换既有占位符，不随意移动品牌元素。
4. 每页只保留支撑这一页结论的内容，长表格应拆分或改为更合适的展示方式。
5. 批量替换名称和数据时检查文本框、图表、备注及隐藏页面。
6. 交付前生成缩略图或逐页预览，检查溢出、遮挡、错位、字体和图片清晰度。

## 注意

- 不把网页截图或整页图片当作可编辑演示文稿交付。
- 若需要 PPTX 转 PDF，只有当前环境存在可靠转换能力时才执行。
- 用户提供品牌模板时，以模板的字号、色彩和版式为准。
