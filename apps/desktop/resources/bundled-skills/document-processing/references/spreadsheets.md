# 表格文件

## 使用范围

- 新建或编辑 `.xlsx`、`.xls`、`.csv`、`.tsv`。
- 合并多张表、统一字段、清洗数据、去重、匹配和汇总。
- 编写公式、设置格式、制作图表和可筛选的业务表。
- 从其他文档提取信息后整理成表格。

## 操作要求

1. 使用 `spreadsheets` 技能提供的运行时和检查流程。
2. **优先一等命令，禁止会话根目录落过程脚本：**
   - 读内容：`read` / `inspect`
   - 拆 sheet / 导出业务表：`extract-sheets`
   - 从 JSON/CSV 建表：`write-xlsx`
   - 复杂样式/图表才允许写 helper，且只能写在 `os.tmpdir()` 或 `.opencode/tmp/`
3. 先识别工作表、表头、主键、日期和金额口径，再决定如何合并。
4. 尽量保留公式、数据类型、数字格式、列宽、筛选和冻结窗格。
5. 合并时记录无法匹配、重复、缺失和疑似错误的数据，不静默丢弃。
6. 公式引用必须检查范围和错误值；不能可靠重算时，不声称已得到最终计算结果。
7. 交付前 `verify` 业务文件，并检查行列数、表头、公式、日期和金额。

## 交付合同

| 可以进产物卡 | 禁止当作交付物 |
|-------------|----------------|
| 本轮新生成的业务 `.xlsx` / `.csv` / `.tsv` | 用户上传原件、`session-uploads` 原件 |
| 用户明确要求的最终表格 | `extract_*.cjs`、`gen_*.py`、tmp 脚本 |
| | 调试 JSON、中间预览、空 `.txt` 中转 |

正文只简要说明结果；**不要**写 `文件路径：…`（与产物卡重复）。

## CSV 编码

- 给中文 Excel 使用的 CSV 默认写为带 BOM 的 UTF-8。
- 原文件编码不明时先检测或试读，不用乱码内容继续处理。
- CSV 不支持工作表、样式和公式；用户需要这些能力时交付 `.xlsx`。

## 注意

- 业务编号、手机号、证件号等可能有前导零的字段应按文本保存。
- 金额、税率、里程和重量要保留原单位，并在单位不一致时先统一或明确标注。
- 数据透视表等高级能力只有在专用运行时确实支持时才承诺。
