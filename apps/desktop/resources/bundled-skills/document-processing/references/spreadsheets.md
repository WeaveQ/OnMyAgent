# 表格文件

## 使用范围

- 新建或编辑 `.xlsx`、`.xls`、`.csv`、`.tsv`。
- 合并多张表、统一字段、清洗数据、去重、匹配和汇总。
- 编写公式、设置格式、制作图表和可筛选的业务表。
- 从其他文档提取信息后整理成表格。

## 操作要求

1. 使用 `spreadsheets` 技能提供的运行时和检查流程。
2. 先识别工作表、表头、主键、日期和金额口径，再决定如何合并。
3. 尽量保留公式、数据类型、数字格式、列宽、筛选和冻结窗格。
4. 合并时记录无法匹配、重复、缺失和疑似错误的数据，不静默丢弃。
5. 公式引用必须检查范围和错误值；不能可靠重算时，不声称已得到最终计算结果。
6. 交付前预览关键工作表，并检查行列数、表头、公式、日期和金额。

## CSV 编码

- 给中文 Excel 使用的 CSV 默认写为带 BOM 的 UTF-8。
- 原文件编码不明时先检测或试读，不用乱码内容继续处理。
- CSV 不支持工作表、样式和公式；用户需要这些能力时交付 `.xlsx`。

## 注意

- 业务编号、手机号、证件号等可能有前导零的字段应按文本保存。
- 金额、税率、里程和重量要保留原单位，并在单位不一致时先统一或明确标注。
- 数据透视表等高级能力只有在专用运行时确实支持时才承诺。
