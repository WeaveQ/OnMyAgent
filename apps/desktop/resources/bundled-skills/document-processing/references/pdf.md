# PDF 文件

## 使用范围

- 读取或提取 PDF 中可访问的文字、页面和表格。
- 新建 PDF，或合并、拆分、重排、旋转页面。
- 填写可编辑 PDF 表单。
- 从 PDF 提取图片或把多张图片合成 PDF。

## 操作要求

1. 使用 `pdf` 技能提供的运行时和检查流程。
2. 先判断 PDF 是文本型、表单型还是扫描图片型。
3. 合并或拆分时记录原文件、页码范围和最终顺序。
4. 填表时检查字段名称、选项、字体显示和是否需要扁平化。
5. 提取表格时核对跨页表头、合并单元格和数字列，不能只相信自动识别结果。
6. 交付前渲染关键页面，检查页数、方向、裁切、字体和内容完整性。

## OCR 与转换

- `pdf` 技能不等于 OCR。扫描件无法直接提取文字时，只有存在可用 OCR 工具或技能时才执行识别。
- OCR 结果必须标记低置信度、模糊字符和需要人工复核的字段，不承诺固定准确率。
- PDF 转 Word、Excel 或 PowerPoint 可能丢失结构和样式；先说明预期损失，再选择提取内容或重建文档。
