# 写好派车信息

把已经确认的内容一次写清楚，让司机和现场人员可以直接查看和确认。

## 输入

- 确认订单；
- 已选车辆和司机；
- 装卸、时效、进仓、回单和异常上报要求；
- 用户自己的派车单模板或说话语气（可选）。

## 处理

1. 只保留司机真正需要执行和确认的信息。
2. 分清已经确定、需要司机回复和需要现场确认的事项。
3. 检查地址、时间、联系人、货物、车型和费用约定有没有对不上。
4. 有用户模板时照模板填写；没有模板时写成简洁的司机任务消息。

## 输出

- 派车单或司机任务消息；
- 司机确认话术；
- 装货、卸货和回单交接要点；
- 异常上报与下一次反馈要求。
