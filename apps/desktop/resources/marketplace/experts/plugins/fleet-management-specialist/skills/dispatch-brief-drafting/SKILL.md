# 写好派车信息

把已确认内容一次写清，让司机和现场能直接执行。

## 输入

- 确认订单；
- 已选车辆和司机；
- 装卸、时效、进仓、回单、异常上报要求；
- 用户模板或语气（可选）。

## 处理

1. 只保留司机要执行和确认的信息。
2. 分清已确定 / 需司机回复 / 需现场确认。
3. 检查地址、时间、联系人、货物、车型约定是否一致。
4. 有模板照模板；无模板写简洁任务消息。
5. 需要派车单文件时用 `write-xlsx`/`write` 真写入。

## 输出

- 派车单或司机任务消息；
- 司机确认话术；
- 装货、卸货、回单要点；
- 异常上报与下次反馈要求。

## 文件交付

- **跟进轮同样必须真写入**：用户说「合并/继续/再导出」时，本轮仍要 `write-xlsx`/write，禁止只在正文宣称生成了文件。
- 禁止只宣称已生成；禁止「已生成 **xlsx**」开场；不要 `文件路径：`；外发由用户决定。

## 边界

- 不替用户发送给司机
- 不重新挑车（车已定）；车未定 → `vehicle-candidate-ranking`
- 不报价、不盯在途、不结账
