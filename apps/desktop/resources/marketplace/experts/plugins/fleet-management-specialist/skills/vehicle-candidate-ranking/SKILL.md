# 按订单挑合适的车

先排除明显不合适的车，再把更值得联系的排在前面。本技能针对**已有具体订单**的配车，不是整车队调度总览。

## 输入

- 已确认订单与特殊运输要求（吨方、温控、多点、时效等）；
- 车辆、司机、位置、空闲时间；
- 公司偏好：距离、价格、熟线等（可选）。

## 处理

1. 硬过滤：车型、载重、容积、设备/温区、证件、时间是否满足。
2. 软排序：空驶、位置、熟线、空闲时段、用户给的历史表现。
3. 分成 `优先 / 备选 / 不建议`，逐辆写原因和还要向司机确认什么。
4. 资料不够时说明缺什么，不凑数推荐。
5. 导出推荐表时用 `write-xlsx`/`write` 真写入。

## 输出

- 优先、备选、不建议清单与原因；
- 需向司机确认的问题；
- 需要时的推荐结果表（产物卡）。

## 文件交付

- 禁止只宣称「已生成」而无写入工具；禁止「已生成 **xlsx**」开场；不要 `文件路径：`。

## 边界

- 无具体订单、只要多车调度总览 → 用货运调度分析 / `fleet-efficiency-analysis`
- 不做派车前全项检查 → `dispatch-readiness-audit`
- 不写司机任务全文 → `dispatch-brief-drafting`
- 不报价、不盯在途、不结账
