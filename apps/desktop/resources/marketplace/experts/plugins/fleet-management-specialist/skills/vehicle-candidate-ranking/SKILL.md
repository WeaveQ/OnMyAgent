# 帮你挑合适的车

先帮调度人员排除明显不合适的车，再把更值得联系的车辆排在前面。

## 输入

- 已经确认的订单和特殊运输要求；
- 车辆、司机、当前位置和空闲时间；
- 公司更看重距离、价格、熟悉线路等要求（可选）。

## 处理

1. 先检查车型、载重、容积、设备、证件和时间是否满足订单。
2. 再比较离装货地多远、要空跑多少、是否熟悉线路、什么时候有空，以及用户提供的历史表现。
3. 分成 `优先 / 备选 / 不建议`，逐辆说明原因和还要向司机确认什么。
4. 资料不够时说明缺什么，不为了凑数量推荐不合适的车。

## 输出

- 优先、备选和不建议的车辆清单；
- 每辆车为什么合适或不合适；
- 需要向司机确认的问题；
- 用户有模板时，按模板整理推荐结果。
