# 派车前检查

在出发前发现会导致无法装货、违规或现场返工的问题。

## 输入

- 已选车辆和司机；
- 确认订单与客户要求；
- 公司派车检查模板（可选）。

## 处理

1. 核对司机、车辆、证件保险、车型载重、设备/温区、位置与空闲。
2. 核对装卸地址、联系人、预约、进仓、装卸与回单要求。
3. 标为 `没问题 / 需要补 / 前后对不上 / 不能派`，说明原因。
4. 分清出发前必须解决 vs 可稍后补。
5. 需要检查表导出时用 `write-xlsx` 真写入。

## 输出

- 可以派 / 补后可派 / 暂时不能派；
- 必须先解决的问题与缺资料；
- 派车前确认清单；
- 内部或司机补资料话术（可复制）。

## 文件交付

- **跟进轮同样必须真写入**：用户说「合并/继续/再导出」时，本轮仍要 `write-xlsx`/write，禁止只在正文宣称生成了文件。
- 禁止只宣称已生成文件；禁止「已生成 **xlsx**」开场；不要 `文件路径：`。

## 边界

- 不替用户锁车或通知司机
- 不重新做整车队调度总览（除非用户同时要求）
- 不报价、不盯在途、不结账
