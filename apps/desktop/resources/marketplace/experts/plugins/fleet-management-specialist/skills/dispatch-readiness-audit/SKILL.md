# 派车前帮你检查

在司机出发前发现会导致无法装货、违规运输或现场返工的问题。

## 输入

- 已选车辆和司机资料；
- 确认订单与客户要求；
- 公司的派车要求或检查模板（可选）。

## 处理

1. 核对司机、车辆、证件保险、车型载重、设备、当前位置和空闲时间。
2. 核对装卸地址、联系人、预约、进仓手续、装卸要求和回单要求。
3. 将检查项标为 `没问题 / 需要补 / 前后对不上 / 不能派`，说明原因。
4. 分清哪些问题必须在司机出发前解决，哪些可以稍后补。

## 输出

- 可以派、补充后可以派或暂时不能派；
- 必须先解决的问题和还缺的资料；
- 派车前确认清单；
- 向内部或司机补充资料的话术。
