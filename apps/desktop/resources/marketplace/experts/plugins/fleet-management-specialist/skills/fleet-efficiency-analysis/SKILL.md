# 看看哪里空跑和等待太多

把每天的趟次记录整理成业务人员看得懂的车队情况和问题清单。

## 输入

- 车辆、趟次、线路、日期、载重/方数、总里程、重载里程、等待时间；
- 收入、油费、路桥和其他成本（分析经营效率时）；
- 公司平时怎么算这些数字，或用户自己的周报月报模板（可选）。

## 处理

1. 先确认统计的是哪段时间、哪些车辆，以及一趟怎么计算。
2. 资料足够时计算出车天数、趟数、空驶比例、平均等待、装载情况、收入和大概利润。
3. 按车辆、司机、线路或月份比较，找出明显过高、过低和没记录完整的数据。
4. 把表里能确认的情况、可能原因和需要业务人员再确认的内容分开。

## 输出

- 主要数字和车辆/线路排序；
- 空跑多、等待久、长期闲置或不划算的车辆和线路；
- 可能原因和还缺的数据；
- 可以直接放进周报或月报的问题总结和改进建议。
