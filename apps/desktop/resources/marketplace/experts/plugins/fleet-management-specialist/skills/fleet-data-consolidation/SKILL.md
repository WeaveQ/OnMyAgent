# 整理车辆和司机表

把分散的车辆和司机资料整理成一张调度人员能直接查看的表。

## 输入

- 车辆、司机、证照保险、当前位置、当前任务等文件或描述；
- 用车牌号还是司机手机号来对应同一辆车或同一个人；
- 用户自己的车队表模板（可选）。

## 处理

1. 统一车牌、司机姓名、车型、载重、日期和车辆状态的写法。
2. 按车牌号或手机号合并同一辆车或同一个人，并保留资料来源和更新时间。
3. 标出重复、前后对不上、缺少、证件过期和很久没更新的内容。
4. 分成“可以拿来调度 / 还要补资料 / 暂时不能用”。
5. 标准 CSV 可使用 `scripts/consolidate_fleet.py` 批量合并。

## 输出

- 整理好的车辆司机表；
- 重复、前后对不上、缺少和过期的内容；
- 哪些车辆资料可以直接使用、哪些需要补；
- 按用户模板导出的一个 CSV/JSON 文件（如需要）。
