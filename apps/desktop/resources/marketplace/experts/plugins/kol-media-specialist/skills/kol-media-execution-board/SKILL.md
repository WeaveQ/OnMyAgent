# 达人邀约报价排期台账

## 输入

- 达人池、邀约记录、聊天截图、报价单和档期回复；
- 项目交付形式与关键时间节点；
- 用户现有台账模板（可选）。

## 处理

1. 按达人合并邀约状态、回复时间、报价、可用档期和交付形式。
2. 状态只使用：待邀约、已邀约待回复、有意向待确认、已确认、暂不合作、信息不足。
3. 多份材料冲突时并列保留来源，不静默覆盖。
4. 根据项目时间节点生成待推进事项、负责人和截止时间；没有负责人的写“待指定”。

## 输出

- 执行台账：达人、平台账号、邀约状态、报价、档期、交付形式、反馈、终选结果、下一步、负责人、截止时间、来源；
- 逾期和冲突清单；
- 已确认达人摘要。

## 边界

- 不发送邀约、不承诺合作、不替用户锁定达人；
- 报价和档期没有来源时不得补写；
- 用户模板优先。

## 文件交付

表格交付使用 `document-processing` 写入并验证。
