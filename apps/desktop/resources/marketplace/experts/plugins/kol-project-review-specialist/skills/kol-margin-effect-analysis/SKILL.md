# 项目毛利与效果分析

## 明确口径

| 指标 | 公式 |
|---|---|
| 总金额 | K 金额 + 广告金额 |
| 自然 CTR | 自然阅读量 / 自然曝光量 |
| 纯 K CPC | K 金额 / 自然阅读量 |
| 互动量 | 点赞量 + 评论量 + 收藏量 |
| 广告占比 | 广告金额 / 总金额 |
| 搜索进店成本 | 总金额 / 搜索进店 UV |

总阅读成本、总互动成本等未由业务材料定义的公式先进入“口径缺失”，不得自行补公式。零分母、空值、重复记录和字段冲突统一输出“数据不足/待确认”，不得产生无穷值或伪精确结果。

## 输出

1. 指标明细与源行追溯；
2. 按返点档、毛利率、达人量级、笔记类型的分组分析；
3. 公式口径表、数据清洗日志和风险提示；
4. 行级标签仅允许“优先保留、可加测、谨慎、数据不足”；没有业务阈值或样本不足时只能标“数据不足”；
5. 可复投建议及其证据来源。

## 确定性脚本

```bash
python3 scripts/analyze_kol_performance.py --input 项目数据.xlsx --output 毛利效果分析.xlsx
```

可通过 `--column-map`、`--thresholds` 传入用户口径。脚本不修改源文件、不安装依赖；运行环境缺依赖时说明缺失能力和可用降级方式。

## 边界

- 不替代财务正式核算；金额和毛利结论保留人工复核。
- 不根据相关性声称投流动作导致效果变化。
- 用户模板和口径始终优先。
