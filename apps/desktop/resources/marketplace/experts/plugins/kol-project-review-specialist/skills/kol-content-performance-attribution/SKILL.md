# 内容效能归因

## 输入

- 本周与上周的投入、曝光、阅读、互动、进店和调整动作；
- 内容类型/切角、目标人群、搜索词、达人和笔记标识；
- 用户提供的目标、投放口径及历史对照材料。

## 工作流

1. 输出周环比投入、效果和动作变化，区分事实、观察和建议。
2. 生成内容×人群、搜索词×内容效能矩阵，保留样本数和源行。
3. 对内容切角打标，整理 TA 画像、优质内容模型和放大建议。
4. 样本不足、缺数或口径冲突时标记“数据不足/待确认”。
5. 所有解释统一标为“相关性观察”；不得把相关性写成因果。

## 确定性脚本

```bash
python3 scripts/build_content_matrix.py --input 投放明细.xlsx --output 内容效能矩阵.xlsx
```

脚本不修改源文件、不静默安装依赖；外部知识库和平台 AI 仅作可选增强并标明来源。

## 输出

- 周环比表、内容×人群矩阵、搜索词×内容矩阵；
- 内容切角、TA、内容模型和建议；
- 清洗/缺数/样本量风险清单；
- 可追溯的相关性观察。
