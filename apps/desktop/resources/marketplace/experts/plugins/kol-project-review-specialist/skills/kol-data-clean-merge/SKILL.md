# 达人项目数据清洗与合并

把分散的本地表格整理成可交接、可分析且能追溯到源行的干净数据。

## 输入

- 本地 Excel、CSV 或粘贴表格；
- 当前阶段和处理目标；
- 主键、列映射、时间范围和用户模板（如有）。

## 工作流

1. 列出源文件、工作表、源行和字段映射；用户模板始终优先。
2. 统一日期、金额、百分比、达人、笔记和项目标识等格式。
3. 重复记录不静默覆盖；冲突记录并列保留并标记“待确认”。
4. 缺失、异常值和零分母只标记，不以 0 或推测值补齐。
5. 输出清洗主表、列映射、清洗日志、冲突清单和基础摘要。

## 边界

- 不在清洗阶段编造业务口径、阈值或因果解释。
- 不抓取未授权的外部数据；本地文件足以完成流程。
- 需要导出文件时使用 `document-processing` 真正写入并验证。
