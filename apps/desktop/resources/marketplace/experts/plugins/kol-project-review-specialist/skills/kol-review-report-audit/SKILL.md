# 复盘报告终检

## 检查范围

1. 每个数字、图表和结论能否追溯到源文件、工作表和口径；
2. 公式是否已由用户或业务材料定义，零分母和缺数是否正确处理；
3. 相关性是否误写为因果，样本不足是否出现确定性结论；
4. 八维复盘、目录、逐页建议、缺失数据和初稿是否齐全；
5. 历史复盘、知识库和平台 AI 的内容是否标明来源；
6. 金额、合同、毛利和因果判断是否保留人工复核。

## 输出

按“位置—问题类型—证据—风险等级—修改建议—人工复核”输出终检表，并给出“可交付 / 修改后交付 / 资料不足”的结论。资料不足时不补写推测内容。

## 边界

- 本技能只做报告终检，不重复脚本/平台内容风控。
- 不替代财务、法务或客户最终确认，不自动提交报告。
