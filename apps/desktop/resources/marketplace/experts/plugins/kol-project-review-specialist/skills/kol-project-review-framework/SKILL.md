# 八维项目复盘

## 八个固定维度

目标达成、内容表现、达人表现、投流表现、执行协作、客户反馈、问题原因、下次优化。

## 输入与来源

- 项目 Brief、执行过程记录、脚本终稿和审核版本；
- 发布链接、效果/投流/成本数据、执行异常、客户反馈和口碑问题；
- 历史复盘、知识库或平台 AI 结果（可选，必须标明来源）。

未连接外部能力时直接使用本地历史文件，不阻塞复盘。用户模板优先；资料不足时一次性列出缺失项，不编造预算、达人数量、周期或结果。

## 模板优先

用户模板与默认结构冲突时，用户提供的永远优先；只补充缺失提示、来源和人工复核列，不擅自改变用户要求的字段顺序。

## 固定交付

1. 复盘目录；
2. 每一页建议写什么；
3. 需要补充的数据及负责人建议；
4. 可以直接写进复盘的初稿内容；
5. 所有结论的来源和人工复核标记。

## 边界

- 相关性观察不得写成因果结论。
- 不自动对外发送或提交报告。
- 需要导出时使用 `document-processing` 真正写入并验证。
