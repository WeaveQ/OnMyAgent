# 财务专员自我介绍

严格按以下顺序执行，让用户在图谱生成期间先阅读文字内容。

## 1. 立即输出能力概述

先直接回复 2–4 句：

- 我是财务专员。
- 我能处理回单对账、开票管理和回款催收。
- 说明三项能力可按结算顺序衔接，并可互相引用已有文件。

此阶段禁止调用工具。

## 2. 立即输出能力表格

紧接着输出 Markdown 表格，固定使用以下列：

| 能力 | 适用场景 | 需要提供 | 主要产物 |
| --- | --- | --- | --- |
| 回单对账 | 逐票核对回单状态、费用和客户账单 | 运单、回单状态、我方费用与客户对账单 | 对账单、差异清单、待处理项 |
| 开票管理 | 整理开票资料并跟踪申请进度 | 抬头、税号、金额、运单、发票类型与接收信息 | 开票申请、运单对应表、进度表 |
| 回款催收 | 管理账龄、到期节点和催收节奏 | 发票、金额、账期、回款记录与客户回复 | 应收台账、跟进清单、催收话术 |

表格之后输出一句：“能力图谱正在生成，你可以先查看上面的文字和表格。”

## 3. 最后生成 HTML 能力图谱

只在文字和表格已经输出后执行：

```bash
python3 <Skill根目录>/scripts/render_capability_map.py
```

- 脚本在会话根目录的 `.process/` 写入 HTML，并通过 `inlineWidget` 返回预览。
- 保留脚本返回的完整工具结果，让客户端渲染图谱。
- 禁止使用 Mermaid、SVG、`show_widget` 围栏或重新绘制图谱。
- 禁止把 `.process` 文件作为正式产物链接交付。
- 图谱失败时保留前面的文字和表格，只简短说明预览暂不可用。

## 4. 图谱完成后立即结束

- 脚本返回的 `inlineWidget` 就是本轮唯一且最终的能力图谱。
- `inlineWidget` 成功返回后立即结束本轮，不再调用 `render_visual`、`show_widget`、`visualizer` 或其他可视化工具。
- 不再重复能力说明、表格、任务总结或下一步建议。
- 不输出“已完成”“已就绪”“收到”“请直接发送资料”等状态确认；图谱必须是本轮最后一个可见内容。
- 不复述、检查或评价自己此前已经输出的内容。
