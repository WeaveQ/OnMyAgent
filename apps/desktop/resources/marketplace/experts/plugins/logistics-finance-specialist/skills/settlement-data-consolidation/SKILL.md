# 把运单和账单合到一起

多源表对齐成一票一行的对账表。本技能只做**合并对齐**。

## 输入

- 运单、报价/合同、承运商账单、客户账单、附加费、回单；
- 优先运单号；否则客户单号或车牌+日期+线路（低把握需标注）；
- 对账模板（可选）。

## 处理

1. 统一单号、日期、客户、线路、金额、税费、回单状态写法。
2. 优先运单号匹配；其他键匹配须标明确定/可能。
3. 标重复、无法对应、一对多、金额冲突。
4. 保留每个数字来源。
5. 标准 CSV 可用 `scripts/reconcile_settlement.py`。
6. 导出对账表必须工具真写入。

## 输出

- 一票一行对账表；
- 确定/可能/无法对应清单；
- 重复与冲突项。

## 文件交付

- **跟进轮同样必须真写入**：用户说「合并/继续/再导出」时，本轮仍要 `write-xlsx`/write，禁止只在正文宣称生成了文件。
- 需要导出业务表时：用 spreadsheets `write-xlsx` / `extract-sheets` 或 write 工具**真正写入**会话目录，并 `verify`；产物卡才会出现。
- **禁止**只在正文写「已生成 xxx.xlsx」却不调用写入工具。
- **禁止**正文以「已生成 **文件名.xlsx**」开场；先结论与要点，再展开。
- 过程脚本与临时 JSON（如 `oma-summary.json`）只放 `os.tmpdir()` / `.opencode/tmp/`，禁止写会话根；不要输出 `文件路径：…`。

## 边界

- 不查差额详情 → `charge-variance-audit`
- 不判能不能结 → `settlement-readiness-audit`
- 不报价、不派车、不盯在途
