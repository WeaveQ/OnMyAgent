# 把运单和账单合到一起

把不同人发来的几张表按同一票货对齐，整理成一票一行的对账表。

## 输入

- 运单、报价/合同、承运商账单、客户账单、附加费和回单数据；
- 优先用运单号；没有运单号时，可以用客户单号或车牌、日期和线路尝试对应；
- 用户自己的对账表模板（可选）。

## 处理

1. 统一运单号、日期、客户、线路、金额、税费和回单状态的写法。
2. 优先按运单号对账；用其他信息尝试对应时，说明只是确定对应还是可能对应。
3. 找出重复运单、无法对应、一张账单对应多票或金额前后对不上的情况。
4. 保留每个数字来自哪张表以及为什么这样对应，方便回头查。
5. 可使用 `scripts/reconcile_settlement.py` 处理标准 CSV。

## 输出

- 一票一行的对账表；
- 确定能对应、可能对应和无法对应的记录；
- 重复、前后对不上和缺少的内容；
- 按用户模板导出的一个 CSV/JSON 文件（如需要）。
