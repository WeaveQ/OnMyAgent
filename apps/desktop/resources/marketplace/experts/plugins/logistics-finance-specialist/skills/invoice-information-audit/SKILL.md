# 检查开票资料并写申请

减少反复复制开票信息、手工加总金额和来回补资料的工作。

## 输入

- 客户开票资料、合同或截图识别文字；
- 已确认的运单与金额清单；
- 票种、税率、服务名称和交付要求；
- 用户开票申请模板（可选）。

## 处理

1. 找出公司名称、税号、发票类型、税率、服务名称、地址电话、开户行账号和收票方式。
2. 检查公司名称是否和合同一致，开票金额是否等于运单合计，金额是否含税，税率是否正确。
3. 标成 `确定没问题 / 可能是同一信息 / 前后对不上 / 缺少`。
4. 把需要业务人员或客户确认的问题一次整理出来。

## 输出

- 整理好的开票信息；
- 缺少、前后对不上和金额不一致的内容；
- 客户补充资料话术；
- 可复制到财务审批中的开票申请初稿。
