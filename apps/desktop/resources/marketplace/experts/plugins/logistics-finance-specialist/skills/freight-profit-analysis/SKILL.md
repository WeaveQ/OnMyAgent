# 算每票和每条线路赚不赚钱

把收入成本算清，标出亏损或毛利过低。

## 输入

- 单票收入、承运成本、附加费、税费、调整；
- 客户、线路、承运商、日期；
- 利润口径与最低毛利要求（可选）。

## 处理

1. 确认收入/成本口径、税费、有无重复漏记。
2. 算单票毛利与毛利率；按客户/线路/承运商/月汇总。
3. 标亏损、低于要求、突变、高收低利。
4. 可能原因：报价变、成本升、漏附、数据缺——需再确认的分开写。
5. 导出必须工具真写入。

## 输出

- 单票与汇总毛利；
- 亏损/低利清单；
- 对比与月报要点。

- 需要导出业务表时：用 spreadsheets `write-xlsx` / `extract-sheets` 或 write 工具**真正写入**会话目录，并 `verify`；产物卡才会出现。
