# 算每票和每条线路赚不赚钱

把收入和成本算清楚，找出哪些单子、客户或线路赚钱少或者在亏钱。

## 输入

- 单票收入、承运成本、附加费、税费和调整项；
- 客户、线路、承运商和日期；
- 公司怎么算利润、最低希望赚多少，或用户自己的模板（可选）。

## 处理

1. 先确认哪些算收入、哪些算成本、税费怎么处理，并检查金额有没有重复或漏记。
2. 计算每票赚多少钱和利润比例，再按客户、线路、承运商和月份汇总。
3. 找出亏损、低于公司要求、利润突然变化，以及收入高但赚得少的业务。
4. 把报价变化、成本变高、额外费用漏收和数据缺失列为可能原因，并说明还要确认什么。

## 输出

- 每票和汇总后赚多少钱、利润比例是多少；
- 赚钱少、亏损和利润突然变化的单子；
- 客户、线路和承运商对比；
- 可能原因、还要确认的内容，以及可以直接放进月报的问题总结。
