# 检查每票能不能结账

按照公司的结算要求逐票检查，避免缺回单、缺凭证或还没审批就进入付款。

## 输入

- 已经整理好的对账表和回单状态；
- 费用凭证、异常处理和审批材料；
- 客户、承运商或公司的结算要求，也可以提供自己的检查模板。

## 处理

1. 分清哪些资料每票都必须有，哪些情况可以例外。
2. 逐票核对回单、费用依据、异常关闭、金额确认和审批状态。
3. 分成 `可以结 / 暂时不能结 / 需要补资料 / 有争议`，并说明原因。
4. 汇总暂时不能结的金额、该找谁补资料，以及先处理哪些单。

## 输出

- 每票能不能结账；
- 为什么不能结、缺什么凭证、该找谁补；
- 分类金额汇总；
- 批量催补清单和可以直接发送的催补消息。
