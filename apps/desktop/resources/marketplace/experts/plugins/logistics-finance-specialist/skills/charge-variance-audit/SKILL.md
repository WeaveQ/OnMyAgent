# 找出哪些金额对不上

在结账前找出少收、多付和其他金额差额，并说明可能原因和还缺什么凭证。

## 输入

- 已经整理好的对账表；
- 合同或报价规则、额外费用依据和公司怎么算账；
- 用户只想关注多大金额以上的差额，或自己的检查模板（可选）。

## 处理

1. 先确认金额是否含税、是什么币种、按什么单位计算，以及加钱还是减钱。
2. 比较应该向客户收多少、准备收多少、应该付承运商多少，以及合同或报价写了多少。
3. 检查重复收费、漏收附加费、超合同收费、无凭证费用和金额对应错误。
4. 分成有明确原因、需要补凭证、需要业务人员确认和金额风险较大，并计算差多少钱。

## 输出

- 每票有哪些金额对不上、可能原因和差多少钱；
- 漏收、重复收费和没有凭证的费用；
- 还要补什么凭证、找谁确认；
- 一段可以发给客户或承运商询问差额的消息。
