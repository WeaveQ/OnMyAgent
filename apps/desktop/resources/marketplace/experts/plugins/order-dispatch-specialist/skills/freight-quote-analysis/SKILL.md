# 帮你算怎么报价

把已有成本和价格算清楚，给出业务人员看得懂、能继续确认的报价建议。

## 输入

- 线路、货物吨方、车型、时效和服务范围；
- 企业成本、底价、合同价、历史成交价、客户目标价中的任意组合；
- 税费、额外费用和公司希望赚多少（可选）。

## 处理

1. 先确认价格是否含税，是按一票、吨、方还是整车计算，避免把不同算法直接比较。
2. 分开列出基础运费和提送、等待、装卸、进仓、回单、保险等额外费用。
3. 计算每个价格之间差多少、预计能赚多少钱和利润比例；没有成本时明确还算不出利润。
4. 数据足够时给出稳妥价、建议价和更有竞争力的价格，并说明各自适合什么情况。
5. 把公司内部计算和发给客户的内容分开，写好可以直接确认的报价消息。

## 输出

- 这次报价用了哪些成本和价格；
- 每个方案大概能赚多少、会不会低于最低可报价格；
- 建议报多少以及原因；
- 一段可以发给客户的报价消息和还要确认的内容。
