# 检查订单有没有写错

在订单提交或交给调度前，找出可能导致少收钱、现场做不了或客户争议的问题。

## 输入

- 客户最后确认的聊天、文件或邮件；
- 报价消息或报价单；
- 合同/长期协议和订单草稿（可选）；
- 用户自有检查模板（可选）。

## 处理

1. 逐项比较线路、发收货信息、货物重量体积、车型、时间、服务内容、价格、税费、回单和付款约定。
2. 标出完全一样、可能是同一意思但需要确认、明确对不上，以及不知道从哪里来的内容。
3. 说明这些差异可能造成少收费用、派车困难、现场返工或后面对账争议。
4. 告诉用户应该改订单、再问客户，还是找公司内部确认。

## 输出

- 哪些内容一致、哪些对不上；
- 每个问题可能造成什么影响；
- 提交前还需要确认什么；
- 一段可以发给客户或内部审批人的确认消息。
