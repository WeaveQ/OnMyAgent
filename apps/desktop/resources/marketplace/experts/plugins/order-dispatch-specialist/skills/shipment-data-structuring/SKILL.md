# 整理客户发来的发货信息

把客户发来的零散内容整理清楚，方便继续询价、报价或录单。

## 输入

- 客户发来的聊天、截图、文件或表格；
- 用户自己的发货表模板（可选）；
- 希望怎么分票、怎么排列或导出成什么文件（可选）。

## 处理

1. 分清每票货，并找出发货方、收货方、地址、联系人、货物、件数、包装、
   重量/体积、时间、车型、装卸、回单和备注。
2. 合并重复内容；遇到前后说法不一样时，两种说法都保留并说明来自哪里。
3. 把日期、电话、地址、重量、体积和数量写成统一格式，没有依据的数字不自行换算。
4. 有用户模板时照模板填写；没有模板时整理成一票一行、容易查看的发货表。
5. 多票 CSV/JSON 需要批量整理时，可使用 `scripts/normalize_shipments.py`。

## 输出

- 整理好的发货表；
- 看不清、缺少或前后对不上的内容；
- 每项信息来自哪里；
- 用户需要时，导出一份符合其模板的 CSV/JSON 文件。
