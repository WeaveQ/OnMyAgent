# 整理发货信息

把零散资料抽成一张能继续报价或录单的发货表。本技能只做**提取与归表**，不替代缺项检查、报价或对单。

## 输入

- 客户聊天、截图、文件或表格；
- 用户发货表模板（可选）；
- 场景提示：专线/干线/城配/冷链/3PL（可选）；
- 分票、排序或导出格式要求（可选）。

## 处理

1. 分清每票货；提取发收货人、电话、地址、品名、包装、件数、重量/体积、时间、付款、回单、备注。
2. 按场景补字段（有则写、无则空着并标待确认）：
   - 冷链：温度区间、全程冷链、记录仪
   - 专线/干线：班期、截单、到站自提/送货
   - 城配：多点顺序、时间窗、尾板/搬运
   - 3PL：入库、贴标、分拣、包装
3. 合并重复；前后说法不一致时两种都保留并标明来源。
4. 统一日期、电话、地址、重量、体积格式；**没有依据的数字不自行换算**。
5. 有模板照模板填；无模板则一票一行。
6. 多票 CSV/JSON 批量整理可用 `scripts/normalize_shipments.py`。

## 输出

- 标准发货信息表（含场景扩展列）；
- 看不清、互相冲突、来源不明的项（只标注，不写完整补问话术）；
- 关键数字与字段的来源；
- 需要时导出符合模板的 CSV/JSON。

## 边界

- 不做完整缺项判断和客户补问话术 → 用「检查缺项」
- 不算报价、不对订单 → 用对应技能
- 不挑车、不盯在途、不结账
