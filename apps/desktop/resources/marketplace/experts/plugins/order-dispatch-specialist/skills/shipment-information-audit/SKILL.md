# 看看发货信息还缺什么

在进入报价或建单前，一次找齐真正影响下一步的信息。

## 输入

- 客户发来的聊天、截图、文件，或已经整理好的发货表；
- 现在准备做什么：询价、报价、录单还是派车；
- 公司要求或用户自己的检查模板（可选）。

## 处理

1. 根据下一步工作，分清哪些信息必须现在有、哪些可以后补。
2. 检查地址是否可定位、时间是否明确、吨方/包装是否可判断车型，以及货物是否
   涉及冷链、危化、超限、保险、进仓或特殊装卸。
3. 把问题分成 `缺少 / 前后对不上 / 说不清 / 需要业务人员确认`，并说明会影响什么。
4. 把问题合并成一次提问，避免反复打扰客户。
5. 根据聊天场景和语气，写一段可以直接发给客户的补问消息。

## 输出

- 现在能不能继续询价、报价、录单或派车；
- 已经确认的内容、还缺什么、哪里对不上，以及建议怎么补；
- 一段可以直接发给客户的补问消息；
- 按用户模板整理的检查结果。
