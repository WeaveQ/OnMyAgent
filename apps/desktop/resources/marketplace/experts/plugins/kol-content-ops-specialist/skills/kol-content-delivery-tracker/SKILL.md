# 内容履约与发布验收台账

## 输入

- 达人名单、脚本版本、沟通记录和客户反馈；
- 项目排期、交付要求和验收标准；
- 发布链接、发布时间和异常记录。

## 处理

1. 按达人和内容项合并版本、审核状态、修改轮次、排期和发布结果。
2. 状态使用：待交初稿、内部审核、客户审核、待修改、已定稿、待发布、已发布待验收、已验收、异常待处理。
3. 冲突记录并列保留，注明来源；缺失字段统一标“待确认”。
4. 识别逾期、版本不一致、缺链接、未验收和返点状态缺失。

## 输出

- 履约台账：达人、内容形式、脚本版本、审核状态、修改轮次、计划/实际发布时间、发布链接、验收结果、异常、客户反馈、返点状态、负责人、下一步、来源；
- 逾期与异常清单；
- 达人运营 → 项目复盘交接摘要。

## 边界

- 不替用户催稿、发送文件、发布内容或确认验收；
- 不把“已发链接”自动视为“已验收”；
- 用户模板优先。

## 文件交付

使用 `document-processing` 生成并验证台账文件。
