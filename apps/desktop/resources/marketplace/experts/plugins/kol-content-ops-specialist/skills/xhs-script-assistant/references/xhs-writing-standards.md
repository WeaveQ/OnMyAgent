# 小红书写作规范与质检标准

## 一、平台内容规范

### 违禁/敏感词类别

| 类别 | 典型词汇 | 处理方式 |
|---|---|---|
| 最高级 | 最好、第一、全网最低、唯一、No.1 | 删除或替换为"非常好用"等相对表达 |
| 医疗声称 | 治疗、消炎、抗菌、修复受损（皮肤）、改善疾病 | 改为"舒缓"、"滋养"、"调理"等护肤功效词 |
| 夸大承诺 | 100%有效、立竿见影、永久持久 | 删除或改为"体感明显"、"持续使用后" |
| 竞品贬低 | 比XX品牌好、某大牌的平替 | 删除竞品名，改为"同类产品中" |
| 虚假数据 | 90%用户反馈、临床验证、实验室证明（无来源） | 删除或注明数据来源 |
| 低俗/擦边 | 直接描述身体部位的敏感词（视品类而定） | 替换为专业护肤/美容术语 |

### 小红书平台习惯用语（近期活跃，可适量使用）

- "真的绝了" → 已老化，少用
- "姐妹们" → 可用，但不要每段都出现
- "冲" → 口语化感强，适合结尾 CTA
- "入手了" / "种草" → 天然融入即可
- "平替" → 可用，但不要降低品牌调性
- "显白" / "提气色" → 美妆高频需求词，可用
- emoji：📌 🌟 ✅ 💡 适合信息型内容；😭 😍 适合情感型内容

## 二、去AI腔实操指南

### AI腔识别特征

**句式层面：**
- 过多排比："不仅A，还有B，更有C"
- 假设+转折："虽然X，但是Y，所以Z"
- 并列堆砌：三个以上形容词修饰同一名词

**词汇层面：**
- 连续四字词组（超过2个算堆砌）
- 书面化连词：不仅如此、与此同时、值得注意的是、此外、综上所述
- 无意义加强语气词：非常非常、真的真的、超级超级

**逻辑层面：**
- 每段落都是"先说问题 → 然后介绍产品 → 最后夸优点"的固定套路
- 优点过多且全部正面，缺乏真实使用体验感

### 口语化改写技巧

**技巧1：加入具体时间/场景**
- 之前：用完之后皮肤很水润
- 之后：早上洗完脸涂上去，到中午脸颊摸起来还是软的

**技巧2：加入主观感受/情绪**
- 之前：这款产品效果非常好
- 之后：说实话我买的时候没抱期待，用了一周觉得这钱没白花

**技巧3：用口语词替换书面词**
| 书面词 | 口语词 |
|---|---|
| 购买 | 买、入手 |
| 使用 | 用、抹 |
| 表示 | 说 |
| 非常 | 挺、蛮、特别（选其一，别全用） |
| 但是 | 但、不过 |
| 然而 | 结果（转折更口语） |

**技巧4：断句处理**
- 长句拆成短句
- 适当使用省略号表示语气停顿：用完皮肤……真的很软
- 口播稿每句以"。"结尾，不要用分号

## 三、视频脚本时长参考

| 时长 | 字数参考 | 备注 |
|---|---|---|
| 15秒 | 40-50字 | 开场+卖点+CTA，无废话 |
| 30秒 | 80-100字 | 问题+产品+使用感受 |
| 60秒 | 150-180字 | 完整结构 |
| 90秒 | 220-260字 | 可加测评/对比 |
| 3分钟 | 650-700字 | 教程/深度种草 |

## 四、图文笔记质检标准

### 标题
- 长度：15-20字
- 结构：关键词 + 钩子（疑问/数字/反常识/利益点）
- 示例：
  - ✅ "戴了15年近视眼镜，换了渐进片之后后悔没早换"
  - ✅ "成熟肌用摩洛哥油100天的真实感受"
  - ❌ "XX品牌护肤油使用体验分享"（无钩子，无情绪）

### 正文
- 第一段：直接切入痛点或使用场景，不要自我介绍
- 分段：每段不超过4行
- 卖点数量：3个以内，每个卖点有具体描述
- 结尾：明确 CTA（评论互动/收藏/点击链接）

### 话题标签
- 3-5个为宜
- 包含：产品词 + 场景词 + 泛需求词
- 示例：#渐进片 #近视眼镜 #护眼好物 #上班族护眼
