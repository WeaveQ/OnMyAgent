# 小红书脚本模板库

## 模板一：视频口播脚本（30秒）

适用场景：单品种草、博主推荐、品牌自播

```
【开场钩子 0-5s】
[提出痛点/制造反常识/引发好奇]
示例：每天对着电脑8小时，眼睛干到……

【产品引入 5-10s】
最近发现了[产品名]，
[一句话概括它解决了什么问题]

【核心卖点 10-20s】
[卖点1]：[具体场景描述]
[卖点2]：[具体场景描述]
（最多2-3个卖点，不要超过3个）

【使用感受/结果 20-25s】
[真实感受/时间周期/可量化变化]
示例：用了三周，下午眼睛不那么酸了

【行动号召 25-30s】
[感兴趣的姐妹/朋友可以：评论/收藏/点主页链接]
```

## 模板二：视频口播脚本（60秒）

适用场景：完整测评、使用教程、对比种草

```
【开场钩子 0-5s】
[具体痛点场景/反问/数据冲击]

【背景/引入 5-15s】
[自己为什么会用/在什么场景下发现这个产品]
（增加真实感，不要直接进入广告感介绍）

【产品介绍 15-30s】
这个是[产品名]，
主要解决的是[核心问题]。
[卖点1 + 场景]
[卖点2 + 场景]

【使用过程/细节 30-45s】
用法很简单：[步骤]
[使用中的真实感受，可以加一个小细节]

【效果/结论 45-55s】
[使用后的变化，尽量具体/可量化]
[适合什么人用 / 不适合什么人]

【行动号召 55-60s】
[有需要的可以XXX]
```

## 模板三：剧情/故事脚本（60秒）

适用场景：痛点剧情、生活场景植入、情感共鸣

```
【情景开场 0-10s】
场景：[具体生活场景，如：深夜加班/周末外出/和朋友聚会]
台词/旁白：[引发共鸣的场景描述]

【冲突/痛点 10-20s】
[遇到了什么问题，强化痛苦感]

【产品出现 20-35s】
[自然引入产品的方式]
[产品如何解决这个问题，要接地气]

【效果呈现 35-50s】
[使用前后对比，或情绪变化]
（可以是视觉展示，也可以是台词表达）

【结尾 50-60s】
[情感收尾或行动号召]
```

## 模板四：图文笔记

```
标题（15-20字）：
[关键词] + [钩子：数字/反常识/痛点/利益]

---

正文第一段（直接切入，不自我介绍）：
[场景/痛点/使用契机，2-3句]

正文第二段（核心卖点1）：
✅ [卖点1]
[具体使用场景描述，不超过4行]

正文第三段（核心卖点2）：
✅ [卖点2]
[具体使用场景描述，不超过4行]

正文第三段（卖点3，可选）：
✅ [卖点3]
[...]

结尾（CTA）：
[互动引导/使用建议/收藏提醒]
感兴趣的可以[评论区聊/点主页/先收藏]～

---

话题标签：
#[产品词] #[场景词] #[泛需求词] #[人群词]（3-5个）
```

## 模板五：模板填充式脚本（品牌定制版）

使用方式：将 `[XXX]` 括号内容替换为实际品牌/产品信息

```
开场（5s内）：
对于[目标用户痛点]，有没有试过[产品类型]？

引入（10s）：
最近入手了[品牌名]的[产品名]，
专门针对[核心问题]研发的。

卖点1（10s）：
[卖点一名称]——
[场景化描述，不超过2句]

卖点2（10s）：
[卖点二名称]——
[场景化描述，不超过2句]

使用感（10s）：
实际用下来，[真实感受，时间+变化]

CTA（5s）：
[有同样烦恼的可以评论区告诉我/点主页看看]
```

---

## 填充说明

使用以上模板时，需要确认以下信息后再填充：

**必填项：**
- [ ] 产品名称（完整名）
- [ ] 核心卖点（1-3个，附具体描述）
- [ ] 目标用户痛点（1个最核心的）
- [ ] 使用感受/效果（真实的，哪怕是"期待中的效果"也要写清楚）

**选填项：**
- [ ] 品牌 tone of voice（活泼/专业/温暖/酷/…）
- [ ] 规避词（品牌不能说的词）
- [ ] 特殊强调点（品牌必须提到的）
- [ ] 达人人设（妈妈/职场女性/学生党/…）
