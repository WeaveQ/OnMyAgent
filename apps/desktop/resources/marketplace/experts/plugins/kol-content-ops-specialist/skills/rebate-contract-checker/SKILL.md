# 返点协议三方核对

## 输入

必须提供三类材料：开票申请 Excel、返点协议 PDF、项目计划单 Excel。可选提供列名映射、计划单 sheet 名和金额容差；默认容差为 ¥1。

## 处理

1. 开票申请与协议按发票抬头/甲方名称匹配，核对税号、金额、类型和内容。
2. 协议与计划单按达人名称匹配，核对渠道服务费和返点金额。
3. 保留来源文件、行/表位置和金额差异。
4. 多协议候选、重复达人、模糊匹配、材料缺失不得默认选择第一条，统一标“需人工确认”。
5. 使用 `scripts/check_rebate_contracts.py` 生成报告。

## 输出

- `核对清单`：逐达人核对字段、来源和结果；
- `核对摘要`：通过、不通过、未找到、需人工确认；
- `待处理事项`：缺失、冲突、重复和模糊匹配。

## 边界

- 不替代财务、法务和税务终审；
- 不自动提交开票、签署或修改源文件；
- 金额容差必须在报告中展示。

## 依赖与降级

脚本依赖 `openpyxl`、`pdfplumber`。缺失时明确提示使用产品文档处理环境，不静默安装依赖。
