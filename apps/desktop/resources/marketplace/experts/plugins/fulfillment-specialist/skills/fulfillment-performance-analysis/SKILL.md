# 看看哪些运输经常晚到或出问题

把每票货的时间和异常记录整理成业务人员看得懂的问题总结。

## 输入

- 业务编号、线路、承运方、承诺/实际提送时间、节点和异常原因；
- 等待时长、客户反馈或用户特别关心的数字（可选）；
- 用户自己的周报月报模板（可选）。

## 处理

1. 先确认统计哪段时间、什么算准时，以及哪些数据没有记录。
2. 资料足够时计算提货和到达准时情况、平均晚多久、出问题比例和等待时间。
3. 按客户、线路、承运商、问题类型和月份比较。
4. 找出经常发生的问题和集中在哪些地方，并把已确认情况和可能原因分开。

## 输出

- 主要数字和变化情况；
- 经常晚到或出问题的原因和重点单子；
- 客户、线路和承运商对比；
- 可以直接放进周报月报的问题总结、还缺的数据和改进建议。
