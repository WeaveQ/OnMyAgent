# 整理货现在到哪里了

把零散、重复、前后说法不一样的运输消息，整理成一份容易查看和继续跟进的进度。

## 输入

- 运单号和司机群聊、位置截图、表格或文件；
- 公司常用的运输状态或用户自己的进度表（可选）；
- 之前已经整理过的进度（继续更新时）。

## 处理

1. 找出运单号、发生了什么、地点、时间、消息来自谁、预计到达时间和下一站。
2. 分清已经发生、原计划、司机口头预计和还没确认的信息。
3. 按运单号和时间去掉重复消息并排好顺序，前后说法不一样时全部保留。
4. 汇总每票货的最新进度、停留多久、下一步要做什么，以及还要追问什么。
5. 批量 CSV/JSON 可使用 `scripts/build_transit_timeline.py` 去重并按时间排序。

## 输出

- 每票货按时间排好的运输进度；
- 现在到哪里、最后更新时间和消息来源；
- 前后对不上、缺少和还没确认的内容；
- 按用户模板整理的进度表，或一份 CSV/JSON 文件。
