# 整理货现在到哪里了

把零散运输消息整理成可查看、可继续跟进的进度。本技能只做**进度归表与时间线**。

## 输入

- 运单号与司机群聊、位置截图、表格或文件；
- 公司状态口径或进度表模板（可选）；
- 此前进度（继续更新时）。

## 处理

1. 抽取运单号、事件、地点、时间、消息来源、ETA、下一站。
2. 分清已发生 / 原计划 / 司机预计 / 未确认。
3. 按运单与时间去重排序；冲突说法并列表述。
4. 汇总最新进度、停留、下一步、待追问。
5. 批量可用 `scripts/build_transit_timeline.py`。
6. 导出进度表时必须工具真写入。

## 输出

- 每票时间线与最新状态；
- 前后冲突与待确认；
- 需要时的进度表（产物卡）。

## 文件交付

- 需要导出业务表时：用 spreadsheets `write-xlsx` / `extract-sheets` 或 write 工具**真正写入**会话目录，并 `verify`；产物卡才会出现。
- **禁止**只在正文写「已生成 xxx.xlsx」却不调用写入工具。
- **禁止**正文以「已生成 **文件名.xlsx**」开场；先结论与要点，再展开。
- 过程脚本只放 `os.tmpdir()` / `.opencode/tmp/`；不要输出 `文件路径：…`。

## 边界

- 不写客户通知全文 → `customer-update-drafting`
- 不整理货损定责 → `exception-evidence-review`
- 不查回单结账 → `pod-document-audit` / 货运财务
- 不报价、不派车
