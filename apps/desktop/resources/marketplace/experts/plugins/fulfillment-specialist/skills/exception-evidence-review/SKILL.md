# 整理运输异常和证据

把混乱的聊天、照片和各方说法整理清楚，方便继续处理和补资料。

## 输入

- 事情经过、现场消息、照片/视频说明和各方说法；
- 运单、运输约定、货值和保险材料（如适用）；
- 公司的异常处理模板或检查要求（可选）。

## 处理

1. 按时间整理已经确认的事情，并把司机、客户、现场等各方说法分开记录。
2. 把资料分成运输约定、装卸、包装、现场、路线、签收、损失和沟通记录。
3. 检查时间、地点、涉及人员、损失情况和照片记录还缺什么。
4. 对可能原因只说明依据和还不能确定的地方，不把猜测写成结论。
5. 列出还要补的照片或记录、现场先做什么，以及回复客户和内部上报的消息。

## 输出

- 按时间整理的事情经过和已有材料清单；
- 还缺什么、哪里前后对不上、有什么风险；
- 需要补的照片记录和下一步怎么做；
- 可以发给客户或内部人员的处理消息。
