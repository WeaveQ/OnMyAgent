# 整理运输异常和证据

把聊天、照片与各方说法理清，方便补资料与跟进。

## 输入

- 经过、现场消息、照片说明、各方说法；
- 运单、约定、货值/保险（可选）；
- 异常模板（可选）。

## 处理

1. 时间线：已确认事实 vs 各方说法。
2. 材料分类：约定、装卸、包装、现场、路线、签收、损失、沟通。
3. 列证据已有/仍缺；可能原因只写依据，不写死结论。
4. 下一步：补拍、现场处置、客户口径、内部上报。
5. 需要材料清单表时工具真写入。

## 输出

- 时间线与材料清单；
- 缺口、冲突、风险；
- 补证清单与可复制处理话术。

## 文件交付

- 需要导出业务表时：用 spreadsheets `write-xlsx` / `extract-sheets` 或 write 工具**真正写入**会话目录，并 `verify`；产物卡才会出现。
- **禁止**只在正文写「已生成 xxx.xlsx」却不调用写入工具。
- **禁止**正文以「已生成 **文件名.xlsx**」开场；先结论与要点，再展开。
- 过程脚本只放 `os.tmpdir()` / `.opencode/tmp/`；不要输出 `文件路径：…`。

## 边界

- 不擅自定责/赔付金额
- 不结账开票 → 货运财务
- 不派车、不报价
