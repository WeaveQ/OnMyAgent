# 检查签收回单

回单交财务前，先整理关键信息并标问题件。

## 输入

- 回单图片/识别文字、送达记录；
- 对应订单与客户回单要求；
- 检查模板（可选）。

## 处理

1. 抽取运单号、送达时间、签收人、件数、签章、异常备注、回单类型。
2. 与订单客户/货物/件数/类型交叉核对。
3. 标缺页、缺签、模糊、涂改、异常备注、号不对。
4. 分成 `没问题 / 需要补 / 有异常 / 找不到订单`；写催补话术。
5. 状态表导出必须工具真写入。

## 输出

- 回单关键信息表；
- 问题清单与催补消息；
- 可交接给货运财务的回单状态。

## 文件交付

- 需要导出业务表时：用 spreadsheets `write-xlsx` / `extract-sheets` 或 write 工具**真正写入**会话目录，并 `verify`；产物卡才会出现。
- **禁止**只在正文写「已生成 xxx.xlsx」却不调用写入工具。
- **禁止**正文以「已生成 **文件名.xlsx**」开场；先结论与要点，再展开。
- 过程脚本只放 `os.tmpdir()` / `.opencode/tmp/`；不要输出 `文件路径：…`。

## 边界

- 不直接结账开票 → 货运财务
- 不改派车辆、不报价
