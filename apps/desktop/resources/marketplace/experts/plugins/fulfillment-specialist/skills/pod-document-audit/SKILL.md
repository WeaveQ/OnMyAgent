# 检查签收回单

在回单交给财务前，先把关键信息整理出来并找出有问题的回单。

## 输入

- 签收单、回单图片或图片识别文字、送达记录；
- 对应订单和客户回单要求；
- 用户自己的检查模板或结账要求（可选）。

## 处理

1. 找出运单号、送达时间、签收人、件数、盖章/签字、异常备注和回单类型。
2. 与订单的客户、货物、件数、回单类型和送达要求交叉核对。
3. 标出缺页、缺签、模糊、涂改、有异常备注、运单号对不上和看不清的内容。
4. 分成 `没问题 / 需要补 / 有异常 / 找不到对应订单`，并写好催补消息。

## 输出

- 整理好的回单关键信息；
- 哪些回单没问题、哪些有问题；
- 问题原因和可以直接发送的催补消息；
- 可以继续交给货运财务专家使用的回单状态表。
