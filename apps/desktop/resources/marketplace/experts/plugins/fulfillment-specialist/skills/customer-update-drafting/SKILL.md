# 帮你写客户通知和催办消息

把已经确认的进度写成客户、司机或同事能直接看懂的消息。

## 输入

- 已经确认的当前进度、预计到达时间、异常情况和下一步；
- 发给客户、司机还是内部同事，以及希望的语气；
- 公司常用话术或不能随便承诺的内容（可选）。

## 处理

1. 分清哪些已经发生、哪些只是预计、哪些有风险、哪些还没确认。
2. 根据正常在途、临近到达、延误、等待装卸、异常处理中等场景组织重点。
3. 根据接收人调整说法，并明确希望对方做什么。
4. 检查有没有随便承诺时间、前后时间对不上、过早认定责任，或忘记说明下次什么时候回复。

## 输出

- 可以直接复制的客户进度通知；
- 延误或异常说明；
- 内部催办或向司机追问的消息；
- 还需要用户确认的时间、承诺和责任说法。
