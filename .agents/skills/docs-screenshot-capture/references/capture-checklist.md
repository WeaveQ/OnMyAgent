# Capture checklist by surface

| Surface | Entry | Notes |
| --- | --- | --- |
| 首页会话 | 主栏 首页 | Empty hero or recent list; avoid half-open menus |
| 文件 | 主栏 文件 | Prefer clean list; 文件 / 任务 Tab 与文案一致 |
| 市场 | 主栏 市场 | 专家/技能/连接器顶栏 |
| 专家 | 主栏 专家 | Empty vs 会话中两种可各一图 |
| 自动化 | 主栏 自动 | 任务列表或详情 |
| Agent 对话 | 账号菜单 → Agent 对话 | 左侧 Agent 列表 + 右侧对话；关菜单再截 |
| Agent 管理 | 账号菜单 → Agent 管理 或对话顶栏「管理 Agent」 | 默认 **本地** Tab（我的智能体），勿误截「会话」归档 |
| 设置 | 账号菜单 → 设置 / ⌘, | 总览 + 子页按需 |

## Theme switch

1. 设置 → **偏好** → **主题** → 浅色 / 深色  
2. Or account menu **外观** chips when visible  

Confirm with window mean luminance before saving.

## Avoid

- Account menu open over the shot (unless documenting the menu itself)  
- Captcha, free-translate overlays, system permission dialogs  
- Secondary display wrong scale—prefer primary display window
